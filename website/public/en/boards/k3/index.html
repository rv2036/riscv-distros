Specs
8× X100 @2.4GHz + 8× A100 AI cores, RVA23/RVV1.0 (up to 1024-bit), 60 TOPS general AI compute, 130 KDMIPS. Pico-ITX: 16/32GB LPDDR5-6400, UFS2.2 128/256GB, 10GbE SFP+ + 1GbE, 2× M.2 (M-Key Gen3 x4 / B-Key), 2× USB3.2 Type-C (full-featured 65W PD + 4K DP) + 4× USB2.0, 100×86mm. CoM260: a 260-pin compute module plus a reference carrier board, the carrier being hardware-compatible with Jetson Orin Nano.

Officially named K3-CoM260 (a 260-pin SO-DIMM compute module), which is the SOM260 form factor in the brief; the Pico-ITX and CoM260 share the SoC/SDK and system images. K3 went on global sale on 2026-04-30 and reached volume public sales in 2026-05.

Distros

  • Bianbu Official Ships with Bianbu Desktop 3.0; the archive is at 4.0.8 (built 2026-10-16, LXQt/Minimal, with a UEFI variant)
  • Ubuntu Official Official support starts with Ubuntu 26.10 — Canonical covers the CoM260, Pico-ITX and DeepComputing FML13V05; you must flash EDK2 firmware first and then install from a USB stick. The 26.04 preinstalled image in the SpacemiT archive uses the vendor kernel and is not supported by Canonical
  • Debian Official Debian 13 GNOME/XFCE/Minimal images (built 2026-07-30)
  • Buildroot Official The official SDK provides Buildroot configs and images
  • openKylin The spec page says OpenKylin is supported, but no public image download was found

  • Fedora The spec page says Fedora is supported, but there is no K3-specific official image

Pitfalls

  • The factory Bianbu 4.0.4 uses vendor kernel 6.18.3-generic, not mainline; K3 reference designs and SDKs have been released in batches since 2026-05, with docs and hardware validation moving together
  • The 16 cores come as two 8-core clusters (X100 and A100) and a single process can use only one cluster at a time; the mainline kernel (Ubuntu 26.10) enumerates just the 8 X100 cores, with the A100 cores invisible
  • KVM — on the vendor kernel modprobe kvm oopses outright (Bianbu 4.0.4 / 6.18.3; later builds were not re-checked); with the mainline-kernel Ubuntu 26.10 Linux guests do run
  • In the review the 10GbE SFP+ never linked and only the GbE port worked; 10GbE driver/transceiver compatibility needs testing
  • Reseller prices vary wildly and duty is extra; the Milk-V Jupiter2 docs are still a stub, so rely on SpacemiT's official docs
