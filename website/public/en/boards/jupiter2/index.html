The first RVA23-ready K3 single-board computer (per the vendor), in pico-ITX form with 10GbE SFP+, suited to desktop use or as a network test platform.

Distros

  • Bianbu Official Ships with Bianbu; RuyiSDK's on-device test rated 4.0.1 Desktop as good (2026-10-25)
  • Fedora Official The Fedora RISC-V hardware page lists the Milk-V Jupiter2 under the SpacemiT K3 entry
  • Ubuntu Partial The vendor product page lists Ubuntu 26.04 as a supported OS; Canonical's official RISC-V download page has no Jupiter2-specific build
  • openKylin Partial The vendor product page lists OpenKylin 2.0; this site found no Jupiter2 entry in OpenKylin's official channels
  • deepin Partial The vendor product page lists deepin 25; this site found no Jupiter2 entry in deepin's official channels

Pitfalls

  • The 10GbE port is an SFP+ optical port, not RJ45: on an ordinary switch you either fit an optical module or use the single GbE copper port
  • Dual display runs over USB-C DP Alt Mode and eDP; there is no standard HDMI port
  • Ships with Bianbu (RuyiSDK records 4.0.1 Desktop); before reinstalling, make sure the image is for the Jupiter2 and not a generic K3 image
  • The official page lists no price; the price and retail channels have not been verified
