K1 was one of the highest-volume high-performance RISC-V SBC chips in 2024-2025, and the BPI-F3 has the most varied ecosystem (official Bianbu plus community Armbian/Fedora/openSUSE/Arch/Gentoo images). The RuyiSDK support matrix covers the BPI-F3 too.

Distros

  • Bianbu Official Bianbu is the vendor's pick (SpacemiT K1 image; 16GB supported since v1.0.7)
  • Armbian Community Armbian Standard support with Debian/Ubuntu images (SD boot only)
  • Debian Community Provided via Armbian
  • Ubuntu Community Provided via Armbian (not Canonical official)
  • Fedora Community A third-party image linked from the Banana Pi docs
  • openSUSE Community As above, a third-party image

Pitfalls

  • Bianbu images come in SD (*.img.zip) and eMMC (*.zip) variants; the wrong one won't boot
  • The vendor pushes Bianbu only; Debian/Ubuntu come mainly from Armbian community images, and Armbian supports SD boot only
  • Early Bianbu (<v1.0.7) does not support the 16GB memory version
  • HDMI is 1.4/1080p only — not suitable for a 4K desktop
