Bottom line

An RISC-V base for server/enterprise use, moving fastest on RVA23 + Server Platform; unless you are validating server scenarios, RevyOS/Bianbu will save you trouble on a dev board.

Based on
openEuler 24.03 LTS (RPM/dnf, own repos) + RVCK 6.6 kernel; RISC-V ships as two separate builds, RVA20 and RVA23
Upstream
Independent distro (it is its own upstream): the openEuler community (OpenAtom Foundation) builds all architectures from one source tree, with RISC-V ported and maintained by the OERV SIG — not a Debian/Ubuntu customization.
Versions
24.03 LTS SP4 (released 2026-06-30; RISC-V RVA23 ISO 2026-09-08) · 24.03 LTS SP3 (moved to long-term maintenance 2026-03-09; both RVA20 and RVA23 builds)

Pitfalls

  • RVA20 and RVA23 images ship separately; 24.03 LTS SP4 offers RISC-V as RVA23 ISO only (there is no rva20 directory)
  • Needs UEFI/EDK2 firmware and a matching board DTB; older U-Boot boards may not boot
  • Docs are versioned by path and the RISC-V install page only exists under 24.03_LTS, so SP3/SP4 paths 404
  • Server-oriented: minimal install by default, with weaker desktop and multimedia support than vendor desktop distros
  • The everything ISO is around 20GB; most users should take dvd/netinst
