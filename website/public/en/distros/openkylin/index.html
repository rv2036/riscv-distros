Bottom line

The RISC-V branch of a domestic desktop OS, with board coverage split across versions (3.0 only knows K3/V100). Good for evaluating a domestic desktop stack, not as a daily driver on older TH1520/K1 boards.

Based on
Independent build (deb/APT + own repos, UKUI desktop); 3.0 uses a Linux 7.0 kernel, 2.0 SP2 is the long-term stable release
Upstream
Independent distro: the openKylin community builds its own deb repos and the UKUI desktop, positioning itself as an independent root community OS rather than a direct Ubuntu/Debian derivative; RISC-V is adapted by the openKylin RISC-V SIG.

Pitfalls

  • 3.0's RISC-V images only cover SpacemiT K3 (Server/Embedded) and V100; LicheePi 4A / Pioneer stay on 2.0 SP2
  • RISC-V images are board-specific rather than generic ISOs, so match them carefully; only 2.0 SP2 offers an RVA23 QEMU image
  • 3.0's RISC-V images lean server/embedded (Server, Embedded) and are not a desktop experience
  • Download links are download-smp.php?id=xxx redirects; the real files are on cdimage.openkylin.top
  • Docs are mostly Chinese and the English doc site is largely a shell; RISC-V questions get answered mainly by the Chinese community/SIG
