Bottom line

If you want the RHEL 10 userland on RISC-V without touching a Red Hat account, the riscv64 container images of Rocky 10 are the ready-to-use option today; running a real system still means waiting for installation media.

vendor
Rocky Enterprise Software Foundation
Based on
RHEL 10 (CentOS Stream 10 code base)
Upstream
Rocky Linux 10 officially supports riscv64 (riscv64gc builds), driven by the Rocky AltArch SIG and the Fedora RISC-V community. riscv64 is listed as an Alternative Architecture: its build failures do not block the release of other architectures.
Versions
10.2 (riscv64 container images published: Base / Minimal / Toolbox / UBI, built 2026-05-25) · 10.0 (the GA announcement lists riscv64 as a supported architecture; installation images and package repository are not online yet)

Pitfalls

  • Only container images can be downloaded right now: the installation ISO and dnf repository are not online yet — /pub/rocky/10/BaseOS/riscv64/os/ is empty, and the official announcement says images are "coming soon"
  • The board list is inherited directly from Fedora RISC-V (VisionFive 2 / QEMU / P550); Rocky itself has no board images
  • riscv64 is an Alternative Architecture, so build failures do not block releases of the primary architectures — package completeness is a matter of luck
