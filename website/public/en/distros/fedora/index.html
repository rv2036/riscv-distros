Bottom line

Fedora runs an official RISC-V SIG with continuous builds, but the project still labels riscv64 "not officially supported" and ships images through the alt channel. It works fine day to day; its support level is simply not the same as Debian or Ubuntu.

Based on
Independent
Upstream
The official Fedora wiki states: "riscv64 is currently not an officially supported Fedora architecture". Images are maintained by the Fedora RISC-V SIG under dl.fedoraproject.org/pub/alt/risc-v/ (an alt tree, not a primary architecture) and do not take part in release blocking.

Pitfalls

  • Most boards need the Omni kernel (...riscv64.omni.fcXX); the standard 7.x kernel only covers the VisionFive 2 / Orange Pi RV / Milk-V Mars class — "Most boards can only boot when using the Omni kernel"
  • Some Omni kernel patches are not upstream yet ("Some patches in this kernel are still under review upstream")
  • Headless only: mainline has no integrated GPU driver, and the project positions this as a build machine/server ("video output are pretty much completely ignored")
  • Installation requires a serial console (Requirements → Serial console access)
  • Some packages need RISC-V-specific patches and still differ from upstream sources
