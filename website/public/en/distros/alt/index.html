Bottom line

The most complete RISC-V support among Russian distros, with images that work out of the box; suited to QEMU and Unmatched users.

Based on
Independent (RPM/apt-rpm, ALT's own toolchain)
Upstream
Official riscv64 port: a riscv64 repo in Sisyphus plus Regular riscv64 test images (jeos-systemd/lxqt/mate/xfce, rv64gc), maintained by the ALT team with a riscv-devel mailing list.
Versions
Sisyphus (rolling, riscv64 port) · p11 (stable branch; riscv64 exists only in Sisyphus)
Doc languages
en / ru
Derivatives
Simply Linux / ALT Mobile (same repo family, no riscv64 builds)
Checked
2026-11-01

Boards

  • QEMU virt (virtual machine) Official The image is designed to boot directly in QEMU; the wiki has a QEMU page
  • SiFive HiFive Unmatched Official The wiki has imaging and boot instructions for HiFive Unmatched/Unleashed

Download

Regular riscv64 images (nightly, iso/tar.xz)riscv64 Sisyphus package repo (RPM)

Docs and videos

  • ALT Wiki: Regular/riscv64 (downloads, QEMU, Unmatched/Unleashed, VNC) Doc en
  • ALT Wiki: Ports/riscv64 (Russian) Doc ru

Pitfalls

  • The riscv64 images are officially framed as testing/developing the Sisyphus port, not a long-term supported product
  • The wiki and ftp are behind Anubis anti-bot protection, so scripts get a 200 challenge page instead of content (use a browser or a mirror)
  • The graphical image runs alterator-setup on first boot; boards without a GPU need VNC
  • rv64gc only, no rv32
