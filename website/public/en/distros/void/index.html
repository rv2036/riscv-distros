Bottom line

Not usable for any RISC-V scenario right now; listed only to show that "small and fast" does not mean "has RISC-V".

Based on
Independent (XBPS + runit + musl/glibc)
Upstream
No riscv64 target: the official repos only carry x86_64/i686/aarch64/armv6l/armv7l (including musl variants), and neither the download page nor /live/current has RISC-V images.

Pitfalls

  • There is currently no riscv64 package repo at all — you can't install or upgrade
  • The community only has one person's build status log (saeziae/voidriscv), not official artifacts
  • To use it you must cross-build from source with xbps-src; there are no official docs
