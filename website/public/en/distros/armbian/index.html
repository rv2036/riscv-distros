Bottom line

The main reason domestic RISC-V boards are usable out of the box; look here first for newer boards like K3/BPI-F3.

Based on
Debian/Ubuntu (Armbian build framework)
Upstream
The official build framework (armbian/build) produces riscv64 images directly, with boards graded Platinum/Standard/Community; RISC-V boards get their own download page and image list on the site.

Boards

  • SpacemiT K3 (Pico-ITX / CoM260) Official MusePi Pro is Platinum (kernel 6.18.55 current / 6.6.100 legacy); K3 Pico-ITX is Platinum too
  • Banana Pi BPI-F3 (SpacemiT K1) Official Standard tier, kernel 6.18.45; a Bianbu variant also exists
  • Orange Pi RV2 (Ky X1) Community Community tier, Debian 13 minimal only (6.18.58)
  • StarFive VisionFive 2 Community Community tier, vendor kernel 6.6.20, three Ubuntu/Debian images

Pitfalls

  • Many boards still depend on a vendor kernel (6.6.x Bianbu), with varying degrees of mainline support
  • Community-tier boards get a single CLI image; desktops and updates come from the community
  • No Meles / Pioneer / Megrez / K230 boards
  • The same release number ships different kernel versions on different boards — don't hard-code it in docs
