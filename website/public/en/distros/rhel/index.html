Bottom line

An enterprise-oriented RISC-V preview: use it to check whether the RHEL userland runs, but for day-to-day use Debian / Ubuntu / RevyOS are less trouble.

vendor
Red Hat
Based on
RHEL 10.2 (Fedora / CentOS Stream 10 code base)
Upstream
The RISC-V Developer Preview published by Red Hat itself, based on the RHEL 10.2 code base; prebuilt images are offered for only a few platforms, and Red Hat states explicitly that it is not a supported product release.

Pitfalls

  • Developer Preview, not a supported production release: Red Hat provides no support, so do not run production workloads on it
  • Downloading requires signing in with a (free) Red Hat developer account; a plain curl is blocked with 403 by anti-bot protection
  • Images are published per platform; there is no generic RISC-V installation medium — the 2.6 GB one is a single-platform disk image
  • SpacemiT V100, added in the 10.2 Update, is a server-class CPU with no matching complete-system entry yet, so it only shows that the chip has landed in RHEL
