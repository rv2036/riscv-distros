Bottom line

Arch's "official" here is only the port's own tested list, not official Arch support — the page should mark it as a community port.

Based on
Arch Linux
Upstream
Arch Linux RISC-V is a community port (archriscv.felixc.at, maintained by Felix Yan and others): it builds Arch source packages with an extra patch set and is not in the official Arch repos yet. Its site says the long-term goal is only "riscv64 can be added to Arch Linux itself as an alternative architecture".

Pitfalls

  • Not pure upstream: every package is built from Arch source packages with patches kept in the archriscv-packages repo
  • LicheePi 4A (TH1520) and Milk-V Pioneer (SG2042) only have experimental kernels in the [unsupported] repo
  • AX45MP boards are largely unusable as-is: "Other boards, except those with AX45MP, may work with a BSP or custom kernel"
  • The default rootfs account is root/archriscv — change it after installing
  • Still an alt architecture target, not in the official Arch repos
