Bottom line

Debian is the only independent distro here that made riscv64 an official release architecture; separately there are Debian-based riscv64 systems such as deepin and RevyOS (not verified one by one).

Based on
Independent
Upstream
riscv64 has been an official release architecture since Debian 13 (trixie) — the official announcement says: "This release for the first time officially supports the riscv64 architecture". It lives in the main archive on deb.debian.org, not the ports add-on tree (debian.org/ports lists riscv64 as 13/released).

Boards

  • QEMU virt (virtual machine) Official The official riscv64 netinst installs on QEMU virt; it is a primary target platform for d-i
  • SiFive HiFive Unmatched Community Generic riscv64 image booted via the board's own U-Boot/UEFI; Debian does not publish board images
  • StarFive VisionFive 2 Community As above: JH7110 boards use the vendor U-Boot to provide UEFI, then install the generic image
  • LicheePi 4A Partial TH1520 needs a vendor U-Boot/kernel; Debian mainline has no board support
  • Milk-V Meles Partial Same TH1520 platform, so the situation matches LicheePi 4A
  • SpacemiT K3 (Pico-ITX / CoM260) Partial SpacemiT K3 needs the vendor BSP; mainline Debian support is unconfirmed
  • Zhihe A210 (XuanTie MelonPi dev board) Partial Zhihe A210 needs vendor firmware/kernel; no official Debian support
  • Canaan K230 (Kendryte K230 / CanMV-K230) Partial Canaan K230 is an MCU-class SoC with limited mainline support
  • Milk-V Megrez (ESWIN EIC7700X) Community EIC7700 boards can use the generic UEFI image; not confirmed in Debian docs
  • Milk-V Titan (UltraRISC DP1000) Community DP1000 as above; not confirmed in Debian docs
  • Milk-V Pioneer (SG2042, server-oriented) Community SG2042 can use the generic image; not confirmed in Debian docs
  • Orange Pi RV2 (Ky X1) Community SpacemiT K1 board: generic image + board U-Boot
  • Banana Pi BPI-F3 (SpacemiT K1) Community SpacemiT K1 board: generic image + board U-Boot

Pitfalls

  • Only generic riscv64 images (netinst/ISO) are published, no board images; whether it boots depends on the board's U-Boot/UEFI firmware
  • The official guide says of itself: "This installation guide has not been fully updated and fact checked for riscv64" — some chapters may be stale
  • A netinst install needs network access to fetch packages
