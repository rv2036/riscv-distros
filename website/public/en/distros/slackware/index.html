Bottom line

Long-time Slackware users can try slarm64 to keep the habit alive on RISC-V; beginners should stay away.

Based on
Independent (pkgtools + slackpkg, BSD-style init)
Upstream
Official Slackware 15.0 is x86_64 only (slackware.com also runs the official ARM project at arm.slackware.com); RISC-V comes from the unofficial slarm64 port (sndwvs), which tracks 15.0/current with packages and board images.

Pitfalls

  • Zero official support; everything depends on slarm64, maintained by one person
  • No installer: chroot-install from the package tree by hand, or write a board image directly
  • slackware.com returns 403 to scripted access (Akamai), so check versions on a mirror
  • The only docs are a README and forum posts — virtually nothing in Chinese
