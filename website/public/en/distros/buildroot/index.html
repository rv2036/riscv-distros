Bottom line

Make it clear to newcomers: this is not a distro but a toolbox for building your own.

Based on
Built from source (BusyBox/glibc/musl + optional packages)
Upstream
A build system, not a ready-made distro: the tree ships defconfigs for qemu_riscv32/64_virt, spike, hifive_unmatched, visionfive/visionfive2, sipeed_licheepi_4a and more — RISC-V is a first-class citizen.

Pitfalls

  • This is a build system: no binary repos, no package manager — installing software means rebuilding the firmware
  • A first full build takes tens of minutes to hours and tens of GB of disk
  • BusyBox by default with no desktop; enable the packages yourself if you want graphics
  • Output is a wic/img; upgrades mean reflashing the whole disk
