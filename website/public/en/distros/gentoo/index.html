Bottom line

Friendly to veterans, discouraging for beginners: complete docs but a fully manual install, good for people who want deep customization or an embedded rootfs.

Pitfalls

  • Only the ~riscv (testing) keyword exists, no stable — expect unstable packages indefinitely
  • No directly flashable image; you must do a manual stage3 install (a bootable image is still on the official TODO)
  • rv32 still has bugs under qemu user-mode, which bites during cross/emulated testing
  • Mixing multilib with the lp64d/lp64 ABIs easily gets you the wrong stage3; check first whether the board has the D extension
