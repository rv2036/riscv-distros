Bottom line

The only system with an official desktop experience on K1/K3 boards (BPI-F3, Milk-V Jupiter, MUSE, Pico-ITX): GNOME/LXQt out of the box and complete documentation, making it the friendliest vendor distro for newcomers.

Based on
Ubuntu 24.04 LTS (Bianbu 2.x, K1) / Ubuntu 25.04 (Bianbu 3.x, K1) / Ubuntu 26.04 (Bianbu 4.x, K3; per vendor forum, not stated per release in official docs) + vendor BSP kernel 6.6 LTS / 6.18
Upstream
Downstream vendor distro: the official OS from SpacemiT, explicitly described as built from Ubuntu community sources, using APT and .deb packages; K1 follows Ubuntu 24.04 (2.x)/25.04 (3.x), K3 follows Ubuntu 26.04 (4.x).

Pitfalls

  • K1 and K3 use completely different version lines: K1 keeps 2.x long-term (Ubuntu 24.04), 3.x is based on the non-LTS Ubuntu 25.04, and K3 only has 4.x (Ubuntu 26.04)
  • RVA22 K1 chips cannot run Ubuntu 26.04/Bianbu 4.x built for RVA23; K3 is backward compatible with RVA22 code
  • Images are .zip files containing an .img that you unzip and write with dd/Etcher; some boards have a UEFI variant, so don't flash the wrong one
  • The kernel is the vendor BSP (6.6 LTS / 6.18), not mainline; build from the official kernel repo if you want to change it
  • MUSE series, BPI-F3 and Milk-V Jupiter images are board-specific and won't boot if mixed up; images are about 2–2.6GB
