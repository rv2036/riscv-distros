Pitfalls

  • Most boards need a board-specific U-Boot first; a generic image alone won't boot
  • RV64/SV39 only; rv32 is a separate port
  • Tier 2: weaker release and support effort than x86/arm
  • Board docs are scattered; much of it lives on mailing lists
