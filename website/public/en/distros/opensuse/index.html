Pitfalls

  • ISOs are auto-published snapshots with zero testing; README.FIRST says: "They haven't seen any kind of testing before publishing... there are times when they are broken"
  • Rolling only (Tumbleweed/MicroOS); there is no stable Leap release
  • No board images; everything relies on the board's UEFI/U-Boot firmware
  • Official RISC-V docs live mostly on the en.opensuse.org wiki, which returns 403 to automated fetching, so it can't be machine-checked
