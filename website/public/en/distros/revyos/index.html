Bottom line

The de facto standard on TH1520 boards: LicheePi 4A and Milk-V Meles ship with RevyOS, and the official tutorials flash it too. The best first pick for newcomers, but note that the mirror is newer than the docs — take the latest date from the mirror directory.

Based on
Debian 13 (trixie) rootfs + XuanTie-customized 6.6 kernel (TH1520/SG2042 BSP); the older 20240720 build is Debian 12 + 5.10 kernel
Upstream
Downstream vendor distro: maintained by PLCT Lab (Institute of Software, CAS) for the XuanTie/T-Head ecosystem, reusing the Debian 13 (trixie) package archive plus a XuanTie-customized kernel. It is neither an official Debian port nor an independent package base.

Pitfalls

  • Version numbers are dates (YYYYMMDD), not semantic versions; the docs lag the mirror badly (docs say 20251226, the mirror already has 20260504)
  • Upgrading from 20240720 or earlier requires resetting the U-Boot environment (env default -a -f; env save; reset), otherwise it won't boot
  • Some SD cards are incompatible with the LicheePi 4A; the vendor maintains a compatibility list, and eMMC is the safer bet
  • The 20260926/20260924 directories hold coreboot+EDK2 firmware (no U-Boot), not system images; at the default 1.84GHz you must add cooling
  • GPU/NPU depend on the vendor BSP driver stack (there are separate revyos-gles-21 and NPU docs); not everything is upstream
