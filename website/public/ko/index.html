Debian

업스트림 아키텍처

기반独立

Debian 是这批里唯一把 riscv64 放进正式发布架构的独立发行版；衍生作品另有 Deepin、RevyOS 等基于 Debian 的 riscv64 系统（未逐项核实）。

Ubuntu

업스트림 아키텍처

기반Debian

Ubuntu 是板级支持做得最细的一家：官方按板发 preinstalled 镜像，但 26.04 起把门槛抬到 RVA23，老板被锁在 24.04 LTS。

Fedora

커뮤니티 포팅

기반独立

Fedora 有官方 SIG 和持续构建，但架构身份仍是 "not officially supported"，这条要在页面上写清楚，别和 Debian/Ubuntu 并列成"官方支持"。

Fedora-V Force (FVF)

벤더 파생

기반Fedora

FVF 本身就是 Fedora 的 RISC-V 下游构建；把它单列一条是为了和 Fedora 官方 SIG 区分开，不要混为一谈。

RevyOS

벤더 파생

기반Debian 13 (trixie) rootfs + 玄铁定制 6.6 内核（TH1520/SG2042 BSP）；旧版 20240720 为 Debian 12 + 5.10 内核

TH1520 板卡的事实标准系统：LicheePi 4A、Milk-V Meles 出厂/官方教程默认刷 RevyOS。新手上手首选，但注意镜像站比文档新，按镜像站目录取最新日期。

Bianbu

벤더 파생

기반Ubuntu 24.04 LTS（Bianbu 2.x，K1）/ Ubuntu 25.04（Bianbu 3.x，K1）/ Ubuntu 26.04（Bianbu 4.x，K3；厂商论坛口径，官方文档未逐版标注）+ 厂商 BSP 内核 6.6 LTS / 6.18

K1/K3 板卡（BPI-F3、Milk-V Jupiter、MUSE、Pico ITX）唯一有官方桌面体验的系统，开箱 GNOME/LXQt，中文文档完整，是最适合新人的厂商发行版。

QEMU virt 虚拟机型

판매 중

无（QEMU 通用虚拟平台，可配 RV32/RV64，最多 512 核） · QEMU Project

纯虚拟平台：最多 512 个 RV64GC 核、CLINT/PLIC、PCIe 主机桥、8 个 virtio-mmio、NS16550 UART、可选 AIA/IOMMU；内存、磁盘、网络全部由命令行参数虚拟，无真实 GPU/VPU/NPU。

StarFive VisionFive 2

판매 중

StarFive JH7110：4×SiFive U74 @1.5GHz + S7 监控核 + E24 · StarFive

2/4/8GB LPDDR4，microSD + eMMC（部分版本）、M.2 M-Key NVMe、2×千兆网（v1.3 支持 PoE）、HDMI 2.0、4×USB、40-pin GPIO；另有精简版 VisionFive 2 Lite。

荔枝派 4A（LicheePi 4A）

판매 중

T-Head TH1520：4×C910 @1.85GHz + C906 + E902，4TOPS NPU · Sipeed

4/8/16GB LPDDR4X，8/32/128GB eMMC，2×千兆网，WiFi5/BT5，HDMI 2.0 + 4-lane MIPI DSI，2×MIPI CSI，4×USB3，40-pin GPIO。

Milk-V Meles

판매 중

T-Head TH1520：4×C910 @1.85GHz + C906 + E902，4TOPS NPU · Milk-V

4/8/16GB LPDDR4X 4266MT/s，eMMC 插槽（选配模块）+ microSD，1×千兆网（支持 PoE），WiFi5/BT5.2（AP6256），4×USB3.0，HDMI 2.0 4K60，MIPI DSI/CSI，40-pin，信用卡大小。
