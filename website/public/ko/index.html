여기서 해결하는 건 “일단 부팅해 보기”입니다. RISC-V 소프트웨어 지원은 각자 위키와 포럼 글, GitHub README에 흩어져 있고 초보자는 보통 “이미지를 잘못 받음, U-Boot 버전이 안 맞음, 시리얼을 못 붙임” 세 단계에서 막힙니다. 배포판과 개발 보드, 그리고 둘 사이의 지원 관계를 한곳에 모았고 항목마다 확인 날짜와 출처를 적었습니다.

시작하기 에서 순서를 보고, 지원 매트릭스 에서 어떤 조합이 되는지 확인하세요. 문제가 생기면 배포판과 보드 페이지의 “주의할 점”을 먼저 보세요.

모든 결론에는 확인 날짜와 출처가 있으며, 전체 목록과 판정 방법은 출처 및 감사 에 정리했습니다.

RISC-V를 실제로 지원하는 배포판

전체 →

Debian

업스트림 아키텍처

기반독립

Debian은 이 중 유일하게 riscv64를 정식 릴리스 아키텍처에 넣은 독립 배포판입니다. 파생으로는 Deepin, RevyOS 등 Debian 기반 riscv64 시스템이 있습니다(항목별 검증은 하지 않음).

Ubuntu

업스트림 아키텍처

기반Debian

Ubuntu는 보드 지원이 가장 세밀한 편입니다. 보드별 preinstalled 이미지를 공식으로 배포하지만, 26.04부터 문턱이 RVA23으로 올라가 구형 보드는 24.04 LTS에 묶입니다.

Fedora

커뮤니티 포팅

기반독립

Fedora에는 공식 RISC-V SIG와 지속 빌드가 있지만 riscv64는 여전히 "not officially supported"로 표기되고 이미지는 alt 채널로 배포됩니다. 일상 사용에는 문제가 없지만 공식 지원 등급은 Debian이나 Ubuntu와 같지 않습니다.

Fedora-V Force (FVF)

벤더 파생

기반Fedora

FVF는 별도 팀이 Fedora 소스에서 다시 빌드한 RISC-V 이미지로 Fedora 공식 릴리스가 아닙니다. 공식 SIG 이미지보다 지원 보드가 많아 바로 부팅되는 Fedora 사용자 환경이 필요할 때 실용적입니다.

RevyOS

벤더 파생

기반Debian 13(trixie) rootfs + 쉬안톄 맞춤 6.6 커널(TH1520/SG2042 BSP). 구버전 20240720은 Debian 12 + 5.10 커널

TH1520 보드의 사실상 표준 시스템입니다. LicheePi 4A와 Milk-V Meles는 출하 시/공식 튜토리얼 기본값이 RevyOS입니다. 초보자가 가장 먼저 손대기 좋지만, 이미지 서버가 문서보다 최신이므로 이미지 서버 디렉터리에서 가장 최근 날짜를 받으세요.

Bianbu

벤더 파생

기반Ubuntu 24.04 LTS(Bianbu 2.x, K1) / Ubuntu 25.04(Bianbu 3.x, K1) / Ubuntu 26.04(Bianbu 4.x, K3, 벤더 포럼 기준이며 공식 문서에 버전별 표기는 없음) + 벤더 BSP 커널 6.6 LTS / 6.18

K1/K3 보드(BPI-F3, Milk-V Jupiter, MUSE, Pico ITX)에서 공식 데스크톱 경험을 주는 유일한 시스템입니다. 기본 GNOME/LXQt에 중국어 문서도 충실해 초보자에게 가장 맞는 벤더 배포판입니다.

openEuler

업스트림 아키텍처

기반openEuler 24.03 LTS (RPM/dnf, 자체 저장소) + RVCK 6.6 커널. RISC-V는 RVA20과 RVA23 두 세트로 빌드

서버/엔터프라이즈 영역의 RISC-V 기반입니다. RVA23 + Server Platform 규격 추진이 가장 빠르지만, 개인 개발 보드 사용자라면 서버 검증이 목적이 아닌 한 RevyOS/Bianbu가 더 편합니다.

openKylin

업스트림 아키텍처

기반독립 빌드 (deb/APT + 자체 저장소, UKUI 데스크톱). 3.0은 Linux 7.0 커널, 2.0 SP2는 장기 안정판

중국산 데스크톱 OS의 RISC-V 갈래인데 보드 지원이 버전마다 끊깁니다(3.0은 K3/V100만). 중국산 데스크톱 스택을 평가하려는 사람에게 맞고, TH1520/K1 구형 보드의 일상용으로는 맞지 않습니다.

deepin

벤더 파생

기반Debian 계열 + deepin 자체 저장소(deepin 25 ‘crimson’). 커널은 보드별 6.6/6.12/6.16, DP1000은 메인라인 커널

데스크톱이 가장 예쁜 중국산 배포판이지만 RISC-V 갈래는 커뮤니티 프리뷰 성격에 보드별 tar.xz 배포라, 평가·체험용으로 맞고 유일한 일상 시스템으로는 권하지 않습니다.
