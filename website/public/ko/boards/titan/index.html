“그래픽 카드를 꽂을 수 있는 RISC-V 워크스테이션/경량 서버”를 겨냥하며 기본 OS는 Ubuntu입니다. Fedora 44부터 Omni 커널로 바뀌었습니다.

사용 가능한 배포판

  • Ubuntu 공식 지원 UltraRISC 공식 Ubuntu 24.04 Desktop(rvck-titan, 2026-06-05 빌드).
  • Fedora 공식 지원 Fedora 44 Server Omni(Fedora RISC-V 공식 이미지, GRUB/DTB 절차 포함).
  • openKylin 공식 지원 openKylin 2.0 SP2(ultrarisc-titan, 2026-06-22 빌드).

주의할 점

  • UR-DP1000에는 V(벡터) 확장이 없어 엄밀히는 RVA23에 못 미치고 AI/벡터 워크로드 성능이 불리합니다.
  • 메인보드에 HDMI/디스플레이 출력이 없어 외장 그래픽 카드나 순수 시리얼/SSH로 써야 합니다.
  • 현재는 벤더 커널이고 공식적으로 2026 Q4에 Linux mainline 업스트림을 계획한다고 합니다.
  • DDR4 UDIMM은 공식 지원 목록에서 골라야 합니다. 예약 배송 주기가 길고(45일+ 사례) 관세도 직접 부담합니다.
