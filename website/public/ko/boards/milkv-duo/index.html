Milk-V Duo 시리즈(Duo / Duo 256M / Duo S)

CV1800B(Duo)/ SG2002(Duo 256M)/ SG2000(Duo S) 판매 중 Milk-V

메일 구독 백엔드가 아직 연결되지 않아 입력란을 사용할 수 없습니다. 연결되면 이 양식에서 바로 신청됩니다.

사양
Duo: 2×C906(1GHz+700MHz) + 8051, 64MB SIP DRAM. Duo 256M: SG2002 + Cortex-A53 1개, 256MB. Duo S: 512MB + eMMC 패드(일부 세트는 8GB 포함) + WiFi6. 모두 100M 이더넷, USB-C. Duo/256M은 26×GPIO 패드, 21×51mm, Duo S는 2×26핀 헤더, 43×43mm.
가격
Duo US$4.99, Duo S US$9.99(Arace 공식점 실판매가). Duo 256M 약 US$7.99.

buildroot

US$5급 입문용으로 임베디드 Linux/RTOS 학습에 맞고 데스크톱에는 맞지 않습니다. 사기 전에 64M인지 256M/S인지 확인하세요. 이미지가 완전히 호환되지 않습니다. openwrt 등 커뮤니티 파생판도 있습니다(표준 배포판 id에는 미포함).

사용 가능한 배포판

  • Buildroot 공식 지원 공식 V1/V2 Buildroot SDK. 카드에 쓰면 바로 동작하는 가장 안정적인 시스템입니다.
  • Fedora 커뮤니티 지원 Fedora 41 이미지(Fedora-V Force, ISCAS 미러).
  • Debian 커뮤니티 지원 Fishwaldo/scpcom의 sophgo-sg200x-debian, 256M/S 커버.
  • Ubuntu 커뮤니티 지원 Ubuntu 22.04 커뮤니티 이미지(bassusteur).
  • Arch Linux RISC-V 커뮤니티 지원 커뮤니티 Arch 이미지.
  • Alpine Linux 커뮤니티 지원 커뮤니티 Alpine 이미지(cwt).
  • NixOS 커뮤니티 지원 커뮤니티 유지보수, 기능 제한적.
  • Yocto / OpenEmbedded 커뮤니티 지원 meta-milkv 레이어.
  • openEuler 커뮤니티 지원 openEuler에 Duo 이미지가 있습니다.

주의할 점

  • 64MB Duo는 메모리가 너무 작아 V2 이미지의 AI 앱이 돌지 않습니다. 공식적으로도 64M에는 V1 이미지를 쓰라고 합니다.
  • 기본은 USB-NCM 네트워크 카드(192.168.42.1)만 있고 DHCP가 없어 호스트에서 같은 대역 IP를 수동 설정해야 합니다. root 비밀번호는 milkv.
  • 메인라인 커널 지원이 불완전합니다. minimal은 6.7, GPIO 6.8, clock/SPI/I2C/MMC/USB는 6.9–6.10에야 들어갔고 camera/VPU/NPU/일부 clock은 아직 review 중입니다.
  • Duo 256M/S에는 ARM Cortex-A53 코어가 있어 RISC-V와 ARM 이미지를 섞어 기록하면 안 됩니다.
  • HDMI가 없고 Duo S도 MIPI DSI뿐입니다. 화면을 붙이려면 어댑터 보드를 따로 사야 합니다.
  • Duo S에는 BOOT 스위치가 있어 잘못 두면 다운로드/부팅 모드에 못 들어갑니다. 전원은 5V/1A면 충분하니 고속 충전기를 억지로 쓰지 마세요.
