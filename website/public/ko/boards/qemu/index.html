QEMU virt 가상 머신

없음(QEMU 범용 가상 플랫폼, RV32/RV64 구성 가능, 최대 512코어) 가상 플랫폼 QEMU Project

메일 구독 백엔드가 아직 연결되지 않아 입력란을 사용할 수 없습니다. 연결되면 이 양식에서 바로 신청됩니다.

순수 가상 플랫폼: 최대 512개 RV64GC 코어, CLINT/PLIC, PCIe 호스트 브리지, virtio-mmio 8개, NS16550 UART, 선택적 AIA/IOMMU. 메모리·디스크·네트워크는 전부 명령행 인자로 가상화되고 실제 GPU/VPU/NPU는 없습니다.

모든 보드의 공통 출발점입니다. virt에서 커널/rootfs를 먼저 검증하고 실기로 넘어가면 플래싱과 디버깅 시간을 크게 줄일 수 있습니다.

사용 가능한 배포판

  • Debian 공식 지원 Debian 13부터 riscv64가 정식 아키텍처라 공식 netinst ISO를 virt에 바로 설치할 수 있습니다.
  • Ubuntu 공식 지원 공식 riscv64 cloud image. EDK2(pflash) 또는 -kernel로 부팅합니다.
  • Fedora 커뮤니티 지원 Fedora RISC-V가 QEMU 설치 안내와 이미지를 제공합니다.
  • Alpine Linux 공식 지원 riscv64 minirootfs만 있고 virt ISO가 없어 커널/initramfs를 직접 준비해야 합니다.
  • Arch Linux RISC-V 공식 지원 archriscv가 riscv64 ISO를 제공하며 QEMU에서 부팅할 수 있습니다.
  • openSUSE 커뮤니티 지원 openSUSE Ports가 riscv64를 제공하지만 공식 사이트가 curl에 403을 돌려줘 직링크는 검증하지 못했습니다.
  • Gentoo 공식 지원 stage3 riscv64 + 핸드북이 QEMU 시스템을 지원합니다.
  • Void Linux 부분 지원 riscv64 포트는 있지만 QEMU 이미지는 직접 빌드해야 합니다.
  • NixOS 커뮤니티 지원 riscv64는 비공식 지원 등급이라 크로스 빌드가 필요합니다.
  • ALT Linux 공식 지원 ALT Ports riscv64가 QEMU 이미지를 제공합니다.
  • FreeBSD 공식 지원 riscv64가 QEMU virt를 지원합니다.
  • NetBSD 공식 지원 riscv64 포트가 QEMU를 지원합니다.
  • OpenBSD 공식 지원 riscv64가 QEMU virt를 지원합니다.
  • openEuler 공식 지원 openEuler RISC-V SIG가 QEMU 이미지를 제공합니다.
  • Buildroot 공식 지원 qemu_riscv64_virt_defconfig, make 한 줄로 시스템이 뜹니다.
  • Yocto / OpenEmbedded 공식 지원 qemuriscv64 machine 공식 지원.
  • AlmaLinux OS Kitten 10 공식 지원
  • Rocky Linux 10 부분 지원
  • RHEL RISC-V Developer Preview 부분 지원

주의할 점

  • -bios default는 OpenSBI만 올리고 U-Boot/EDK2는 없습니다. Ubuntu/Fedora cloud image를 부팅하려면 pflash로 32MiB EDK2 펌웨어를 올려야 하고, 아니면 화면이 검게 나옵니다.
  • virt에는 GPU/VPU/NPU가 없으니 그래픽, 영상 하드웨어 디코딩, AI 가속 검증에 쓰면 안 됩니다.
  • 시리얼은 ttyS0으로 고정입니다. -nographic 모드에서 나가려면 Ctrl-A 다음 X를 누릅니다.
  • Ubuntu 26.04부터 RVA23S64가 필요해 확장이 없는 구버전 QEMU에서는 부팅되지 않습니다. 24.04는 여전히 RVA20 베이스라인입니다.
  • Alpine riscv64는 minirootfs만 내고 virt ISO가 없어 커널과 initramfs를 직접 준비해야 합니다.
