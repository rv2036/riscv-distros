사용 가능한 배포판

  • RevyOS 공식 지원 공식 주력, 20251226 시스템 이미지(kernel 6.6). Milk-V 공식 이미지 페이지는 이제 RevyOS Docs를 가리킵니다.
  • openEuler 커뮤니티 지원 openEuler RISC-V SIG가 Meles 이미지를 제공합니다.
  • deepin 커뮤니티 지원 deepin RISC-V 포팅판.
  • Debian 커뮤니티 지원 Debian wiki의 RISC-V 페이지가 TH1520/Meles를 언급하며 debian-ports로 직접 구성할 수 있습니다.
  • Buildroot 부분 지원 RevyOS 빌드 체인이 Buildroot 기반이라 boot/rootfs를 직접 낼 수 있습니다.

주의할 점

  • 4GB판과 8GB/16GB판의 U-Boot SPL이 달라(u-boot-with-spl-meles-4g.bin vs meles.bin) 잘못 기록하면 바로 벽돌이 됩니다.
  • 20251226부터 kernel 6.6으로 바뀌었으니 시스템을 기록하기 전에 SPI Flash 펌웨어를 먼저 올려야 합니다.
  • eMMC는 옵션 모듈입니다. eMMC 부팅을 하려면 SPI NOR을 먼저 기록해야 하고, 아니면 SD로만 부팅합니다.
  • eMMC 기록은 fastboot(T-HEAD USB download gadget 2345:7654)로 하고 Download 키를 눌러 다운로드 모드로 들어갑니다.
  • 보드에 V1.x 하드웨어 리비전이 여럿이라(실크 인쇄는 앞면) DTB/이미지를 맞춰야 합니다.
  • PoE 전원은 핀헤더 PIN2/PIN4에 5V를 직접 넣는 방식이라 표준 802.3af 수전이 아닙니다.
