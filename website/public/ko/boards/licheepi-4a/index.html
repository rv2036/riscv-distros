TH1520 중 자료가 가장 많고 커뮤니티가 가장 큰 보드입니다. RevyOS 데스크톱은 쓸 만하지만 GPU/NPU가 클로즈드소스인 점이 아픕니다. openwrt 등 커뮤니티 파생판도 있습니다(표준 배포판 id에는 미포함).

사용 가능한 배포판

  • RevyOS 공식 지원 공식 주력. 최신 시스템 이미지 20251226(Debian 계열 + kernel 6.6).
  • Debian 부분 지원 메인라인 Debian 13이 LPi4A에서 부팅되지만 U-Boot/DTB를 직접 준비해야 하고 공식 설치 이미지는 없습니다.
  • Ubuntu 부분 지원 ubuntu-base rootfs뿐이라 커널과 부팅 구성을 직접 해야 합니다.
  • Fedora 커뮤니티 지원 Fedora-V Force가 TH1520 이미지를 제공합니다.
  • Arch Linux RISC-V 커뮤니티 지원 archriscv가 TH1520을 지원합니다.
  • Armbian 커뮤니티 지원 Armbian이 LicheePi 4A를 공식 지원합니다.
  • Gentoo 커뮤니티 지원 Gentoo wiki에 TH1520 전용 페이지가 있습니다.
  • NixOS 커뮤니티 지원 커뮤니티 저장소 nixos-licheepi4a(RevyOS 커널/U-Boot 재사용).
  • openEuler 커뮤니티 지원 openEuler RISC-V SIG가 이미지를 제공합니다.
  • openKylin 커뮤니티 지원 커뮤니티 openKylin 이미지.
  • deepin 커뮤니티 지원 deepin RISC-V 포팅판.
  • Buildroot 부분 지원 RevyOS가 Buildroot로 boot/rootfs를 빌드합니다.

주의할 점

  • GPU는 Imagination BXM-4-64인데 벤더 클로즈드 blob뿐이라 메인라인 커널에서는 GPU 가속이 없습니다. NPU는 T-Head 전용 SDK가 필요합니다.
  • 2023.8.1 이전 출하 16GB 배치에 U-Boot 메모리 인식 버그가 있어 16G 전용 u-boot를 기록해야 합니다. 아니면 대용량 메모리 앱이 죽습니다.
  • 플래싱은 BOOT 키를 누른 채 전원을 넣어 fastboot(USB 2345:7654)로 들어가야 합니다. 일반 전원 투입으로는 다운로드 모드에 못 들어갑니다.
  • 20240720 이하 RevyOS에서 올라올 때는 반드시 env default -a -f; env save로 U-Boot 환경 변수를 초기화해야 합니다.
  • 8GB와 16GB 버전은 boot.ext4 디바이스 트리가 달라 섞어 기록하면 부팅되지 않습니다.
  • 2026-09부터 RevyOS가 coreboot+EDK2 새 펌웨어(U-Boot SPL 대체)를 밀고 있는데 실험 성격이라 기록 전에 보드 형식을 확인하세요.
