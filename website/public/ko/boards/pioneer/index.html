“RISC-V 워크스테이션/서버”로 쓸 수 있는 유일한 보드이고 가격과 소비전력이 다른 차원입니다. 64코어 병렬 빌드나 CI 러너에 맞고 입문용은 아닙니다. opencloudos 등 커뮤니티 파생판도 있습니다(표준 배포판 id에는 미포함).

사용 가능한 배포판

  • RevyOS 공식 지원 현재 공식 주력. RevyOS 20260504가 pioneer/pisces 두 벌의 펌웨어와 이미지를 제공합니다.
  • Fedora 공식 지원 Milk-V 공식 문서가 Fedora 38을 설치 예시로 쓰고 Fedora RISC-V가 SG2042를 지원합니다.
  • openEuler 커뮤니티 지원 openEuler RISC-V SIG가 서버 시나리오로 SG2042를 지원합니다.
  • openKylin 커뮤니티 지원 openKylin에 RISC-V 서버 이미지가 있습니다.
  • deepin 커뮤니티 지원 deepin RISC-V 포팅판.
  • Debian 부분 지원 debian-ports에 riscv64 기본 패키지는 있지만 공식 Pioneer 이미지는 없습니다.
  • Ubuntu 부분 지원 Canonical 공식 이미지가 없어 rootfs를 직접 구성해야 합니다.

주의할 점

  • Milk-V 문서의 Download 페이지 Image 영역이 비었습니다(RevyOS로 이전). 옛 페이지에서 시스템 이미지를 찾지 마세요.
  • 메모리 선별이 중요합니다. 공식 DDR 지원 목록대로 RDIMM/UDIMM을 골라야 하고 아니면 DDR 트레이닝 실패로 부팅하지 않습니다.
  • 표준 ATX 24핀 + CPU 8핀 전원이 필요하고 쿨러를 반드시 달아야 합니다(전형 120W).
  • 온보드 디스플레이 출력이 없어 PCIe 그래픽 카드가 필요하고 일부 카드는 LinuxBoot/U-Boot 단계에서 출력이 없습니다.
  • 펌웨어(LinuxBoot/EDK2 + MCU) 업그레이드에 벽돌 위험이 있어 공식 순서대로 기록해야 합니다.
  • 초기 배치의 ASM2824 PCIe 스위치에 호환 문제가 있어 buglist를 먼저 확인하세요.
