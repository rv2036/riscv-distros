결론부터

서버/엔터프라이즈 영역의 RISC-V 기반입니다. RVA23 + Server Platform 규격 추진이 가장 빠르지만, 개인 개발 보드 사용자라면 서버 검증이 목적이 아닌 한 RevyOS/Bianbu가 더 편합니다.

기반
openEuler 24.03 LTS (RPM/dnf, 자체 저장소) + RVCK 6.6 커널. RISC-V는 RVA20과 RVA23 두 세트로 빌드
업스트림
독립 배포판(자신이 곧 업스트림)입니다. openEuler 커뮤니티(OpenAtom 재단)가 공식으로 다중 아키텍처 동일 소스 빌드를 하며 RISC-V는 OERV SIG가 포팅·유지합니다. Debian/Ubuntu 커스터마이즈가 아닙니다.
버전
24.03 LTS SP4(2026-06-30 릴리스; RISC-V RVA23 ISO 2026-09-08) · 24.03 LTS SP3(2026-03-09 장기 유지보수로 전환; RVA20 + RVA23 두 버전)

주의할 점

  • 혁신 버전 26.09(2026-09-30 출시)에는 riscv64 ISO가 없습니다. ISO/OS/everything 트리에는 aarch64와 x86_64만 있어 RISC-V는 계속 24.03 LTS SP4를 기준으로 삼아야 합니다.
  • RVA20과 RVA23 이미지가 따로 나옵니다. 24.03 LTS SP4의 RISC-V는 RVA23 ISO만 제공합니다(rva20 디렉터리 없음).
  • UEFI/EDK2 펌웨어와 보드에 맞는 DTB가 필요해 구형 U-Boot 보드는 부팅되지 않을 수 있습니다.
  • 문서가 버전별 경로로 나뉘고 RISC-V 설치 페이지는 24.03_LTS 경로에만 있어 SP3/SP4 경로는 404가 납니다.
  • 서버 지향이라 기본이 최소 설치이고 데스크톱·멀티미디어 지원은 벤더 데스크톱 배포판보다 약합니다.
  • everything ISO는 20GB급이니 일반 사용자는 dvd/netinst면 충분합니다.
