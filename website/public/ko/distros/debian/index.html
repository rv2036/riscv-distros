결론부터

Debian은 이 중 유일하게 riscv64를 정식 릴리스 아키텍처에 넣은 독립 배포판입니다. 파생으로는 Deepin, RevyOS 등 Debian 기반 riscv64 시스템이 있습니다(항목별 검증은 하지 않음).

기반
독립
업스트림
Debian 13(trixie)부터 riscv64가 공식 릴리스 아키텍처입니다. 공식 보도자료 원문은 “This release for the first time officially supports the riscv64 architecture”. 메인 아카이브인 deb.debian.org에 들어가며 ports 추가 트리가 아닙니다(debian.org/ports 목록에서 riscv64는 13/released로 표기).

지원 보드

  • QEMU virt 가상 머신 공식 지원 공식 riscv64 netinst 이미지로 QEMU virt에 설치할 수 있고, d-i의 주요 대상 플랫폼입니다.
  • SiFive HiFive Unmatched 커뮤니티 지원 범용 riscv64 이미지 + 보드 측 U-Boot/UEFI 부팅. Debian은 보드 전용 이미지를 배포하지 않습니다.
  • StarFive VisionFive 2 커뮤니티 지원 위와 같습니다. JH7110 보드는 벤더 U-Boot로 UEFI를 올린 뒤 범용 이미지를 설치합니다.
  • LicheePi 4A(리치파이 4A) 부분 지원 TH1520은 벤더 U-Boot/커널이 필요하고, Debian 메인라인에는 보드 지원이 없습니다.
  • Milk-V Meles 부분 지원 같은 TH1520 플랫폼이라 상황은 LicheePi 4A와 비슷합니다.
  • SpacemiT K3(Pico-ITX / CoM260) 부분 지원 SpacemiT K3는 벤더 BSP가 필요하며, Debian 메인라인 지원 여부는 확인되지 않았습니다.
  • Zhihe A210(XuanTie MelonPi 개발 보드) 부분 지원 즈허(Zhihe) A210은 벤더 펌웨어/커널이 필요하고 Debian 공식 지원은 없습니다.
  • Canaan K230(Kendryte K230 / CanMV-K230) 부분 지원 Canaan K230은 MCU 계열 SoC라 메인라인 지원이 제한적입니다.
  • Milk-V Megrez(ESWIN EIC7700X) 커뮤니티 지원 EIC7700 보드는 범용 UEFI 이미지로 갈 수 있으나 Debian 문서에서 확인되지는 않았습니다.
  • Milk-V Titan(UltraRISC DP1000) 커뮤니티 지원 DP1000도 같습니다. Debian 문서에서 확인되지 않았습니다.
  • Milk-V Pioneer(SG2042 서버 지향) 커뮤니티 지원 SG2042는 범용 이미지로 갈 수 있으나 Debian 문서에서 확인되지 않았습니다.
  • Orange Pi RV2(Ky X1) 커뮤니티 지원 SpacemiT K1 보드. 범용 이미지 + 보드 측 U-Boot.
  • Banana Pi BPI-F3(SpacemiT K1) 커뮤니티 지원 SpacemiT K1 보드. 범용 이미지 + 보드 측 U-Boot.

주의할 점

  • 범용 riscv64 이미지(netinst/ISO)만 배포하고 보드 전용 이미지는 없습니다. 부팅 가능 여부는 보드 측 U-Boot/UEFI 펌웨어에 달려 있습니다.
  • 공식 설치 매뉴얼도 “This installation guide has not been fully updated and fact checked for riscv64”라고 밝히고 있어 일부 장은 오래되었을 수 있습니다.
  • netinst 설치에는 네트워크로 패키지를 받아야 합니다.
