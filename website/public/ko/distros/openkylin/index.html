결론부터

중국산 데스크톱 OS의 RISC-V 갈래인데 보드 지원이 버전마다 끊깁니다(3.0은 K3/V100만). 중국산 데스크톱 스택을 평가하려는 사람에게 맞고, TH1520/K1 구형 보드의 일상용으로는 맞지 않습니다.

기반
독립 빌드 (deb/APT + 자체 저장소, UKUI 데스크톱). 3.0은 Linux 7.0 커널, 2.0 SP2는 장기 안정판
업스트림
독립 배포판입니다. openKylin 커뮤니티가 자체 deb 저장소와 UKUI 데스크톱을 만들고 공식적으로 독립 루트 커뮤니티 OS를 표방합니다. Ubuntu/Debian 직접 파생이 아니며 RISC-V는 openKylin RISC-V SIG가 적응합니다.
버전
openKylin 3.0(2026-08-31 릴리스; 다운로드 페이지 미러 2026-09-18, RISC-V 이미지 2026-08-28 / 2026-10-29) · openKylin 2.0 SP2(2026-08-13 장기 안정판; RISC-V 이미지 2025-08-26)

다운로드

시스템 다운로드 센터 (아키텍처로 RISC-V 필터)3.0 RISC-V: SpacemiT K3 Server (zip)3.0 RISC-V: SpacemiT V100 Server (iso)2.0 SP2 다운로드 페이지 (LicheePi4A / Pioneer / K1 / qemu 이미지는 ‘모든 버전’에 있음)미러 cdimage.openkylin.top

설치 문서와 영상

  • RISC-V에 openKylin 설치 문서 zh
  • openKylin 3.0 릴리스 노트 (RISC-V / RVA23 최적화) 문서 zh

주의할 점

  • 3.0의 RISC-V 이미지는 SpacemiT K3(Server/Embedded)와 V100만 커버합니다. LicheePi 4A / Pioneer는 아직 2.0 SP2입니다.
  • RISC-V 이미지는 범용 ISO가 아니라 보드별 맞춤이라 자기 보드에 맞는 것을 골라야 합니다. RVA23 qemu 이미지는 2.0 SP2에만 있습니다.
  • 3.0의 RISC-V 이미지는 서버/임베디드(Server, Embedded) 성격이라 데스크톱 경험과는 다릅니다.
  • 다운로드 링크가 download-smp.php?id=xxx로 넘어가고 실제 파일은 cdimage.openkylin.top에 있습니다.
  • 문서가 중국어 중심이고 영문 문서 사이트는 거의 비어 있습니다. RISC-V 문제는 주로 중국어 커뮤니티/SIG가 대응합니다.
