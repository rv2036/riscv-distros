결론부터

K1/K3 보드(BPI-F3, Milk-V Jupiter, MUSE, Pico ITX)에서 공식 데스크톱 경험을 주는 유일한 시스템입니다. 기본 GNOME/LXQt에 중국어 문서도 충실해 초보자에게 가장 맞는 벤더 배포판입니다.

기반
Ubuntu 24.04 LTS(Bianbu 2.x, K1) / Ubuntu 25.04(Bianbu 3.x, K1) / Ubuntu 26.04(Bianbu 4.x, K3, 벤더 포럼 기준이며 공식 문서에 버전별 표기는 없음) + 벤더 BSP 커널 6.6 LTS / 6.18
업스트림
다운스트림 맞춤 배포판입니다. SpacemiT(진디에스공시) 공식 OS로 “Ubuntu 커뮤니티 소스 기반으로 빌드”한다고 명시하며 APT + deb 패키지 형식을 씁니다. K1은 Ubuntu 24.04(2.x)/25.04(3.x), K3는 Ubuntu 26.04(4.x) 기반입니다.

주의할 점

  • K1과 K3의 버전 라인이 완전히 다릅니다. K1은 2.x(Ubuntu 24.04)를 장기 유지하고 3.x는 비LTS인 Ubuntu 25.04 기반이며, K3는 4.x(Ubuntu 26.04)뿐입니다.
  • RVA22인 K1은 RVA23용으로 빌드된 Ubuntu 26.04/Bianbu 4.x를 돌릴 수 없습니다. K3는 RVA22 코드를 하위 호환합니다.
  • 이미지는 .zip(내부 .img)이라 풀어서 dd/Etcher로 써야 합니다. 일부 보드는 UEFI 변형이 따로 있으니 잘못 고르지 마세요.
  • 벤더 BSP 커널(6.6 LTS / 6.18)이라 메인라인이 아닙니다. 커널을 바꾸려면 공식 kernel 저장소 기준으로 빌드해야 합니다.
  • MUSE 시리즈, BPI-F3, Milk-V Jupiter 이미지는 보드별로 다르고 잘못 쓰면 부팅되지 않습니다. 이미지 크기는 약 2~2.6GB입니다.
