결론부터

FVF는 별도 팀이 Fedora 소스에서 다시 빌드한 RISC-V 이미지로 Fedora 공식 릴리스가 아닙니다. 공식 SIG 이미지보다 지원 보드가 많아 바로 부팅되는 Fedora 사용자 환경이 필요할 때 실용적입니다.

기반
Fedora
업스트림
Fedora-V Force는 독립 팀/커뮤니티 프로젝트로 Fedora 36→rawhide의 riscv64 빌드를 자체 컴파일해 보드에 맞춥니다. 공식 사이트 설명은 “independently compiling releases from Fedora 36 to rawhide”이며 Fedora 공식 릴리스 절차와 소속 관계가 없습니다.
버전
