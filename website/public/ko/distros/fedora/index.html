결론부터

Fedora에는 공식 RISC-V SIG와 지속 빌드가 있지만 riscv64는 여전히 "not officially supported"로 표기되고 이미지는 alt 채널로 배포됩니다. 일상 사용에는 문제가 없지만 공식 지원 등급은 Debian이나 Ubuntu와 같지 않습니다.

기반
독립
업스트림
Fedora 공식 wiki 원문: “riscv64 is currently not an officially supported Fedora architecture”. 이미지는 Fedora RISC-V SIG가 관리하며 dl.fedoraproject.org/pub/alt/risc-v/(alt 트리, 메인 아키텍처 아님)에 있고 릴리스 블로킹에는 참여하지 않습니다.

  • Milk-V Pioneer(SG2042 서버 지향) 공식 지원 SOPHGO SG2042 항목이 공식 지원입니다(Milk-V Pioneer).
  • Orange Pi RV2(Ky X1) 공식 지원 SpacemiT M1/K1 항목이 공식 지원입니다(Orange Pi RV 2, BPI-F3, Milk-V Jupiter 포함).
  • Banana Pi BPI-F3(SpacemiT K1) 공식 지원 SpacemiT M1/K1 항목이 공식 지원입니다(Banana Pi BPI-F3).

주의할 점

  • 대부분의 보드는 Omni 커널(...riscv64.omni.fcXX)이 필요합니다. 표준 7.x 커널은 VisionFive 2 / Orange Pi RV / Milk-V Mars 정도만 커버합니다. 공식 원문: “Most boards can only boot when using the Omni kernel”
  • Omni 커널에는 아직 업스트림되지 않은 patch가 남아 있습니다(원문 “Some patches in this kernel are still under review upstream”).
  • headless 전용입니다. mainline에 SoC 내장 GPU 드라이버가 없고 공식 포지셔닝도 빌드 머신/서버입니다(“video output are pretty much completely ignored”).
  • 설치에는 시리얼 콘솔이 필요합니다(Requirements → Serial console access).
  • 일부 패키지는 RISC-V 전용 patch가 필요해 업스트림 소스와 차이가 남아 있습니다.
