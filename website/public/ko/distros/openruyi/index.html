결론부터

주로 벤더/생태계 테스트용입니다. 공식 포지셔닝이 ‘조기 검증’이라 펌웨어·플랫폼 의미론·커널 상호운용 문제를 빨리 드러내 벤더 분기를 줄이는 것이 목적입니다. 일반 사용자는 보통 필요 없고 일상용은 Bianbu / RevyOS / openKylin 같은 벤더 배포판을 고르세요. 비용 없이 맛보려면 QEMU 이미지부터 쓰면 됩니다.

기반
독립 자체 빌드 (RPM + dnf, 롤링 릴리스). 커널 7.2.6 / LTS 6.18.54, 툴체인 GCC 16.2 / glibc 내장
업스트림
독립 배포판입니다. 중국과학원 소프트웨어연구소(ISCAS)가 시작해 장기 유지하는 RISC-V 네이티브 배포판으로 자체 RPM 패키지 집합과 빌드 파이프라인(SPECS/dnf)을 쓰며 Debian/Ubuntu/openEuler 바이너리를 기반으로 하지 않습니다.

지원 보드

  • QEMU virt 가상 머신 공식 지원 공식 QEMU/virt 이미지와 RVA23 가상화 설명을 제공하며 가장 간편한 체험 경로입니다.
  • SpacemiT K3(Pico-ITX / CoM260) 커뮤니티 지원 Ruyi Firmware(coreboot+OpenSBI+EDK2)로 SpaceMiT K3 Pico ITX에서 펌웨어→데스크톱 전 과정을 검증했습니다.

주의할 점

  • 롤링 릴리스에 LTS가 없어 월간 버전이 크게 바뀔 수 있고 안정적인 운영 기반으로는 부적합합니다.
  • 이미지가 RVA20 / RVA23 두 세트라 해당 profile을 지원하지 않는 코어에서는 부팅되지 않습니다.
  • K3는 Ruyi Firmware(coreboot+OpenSBI+EDK2)가 필요하고 일반 U-Boot 개발 보드 대부분은 바로 쓸 이미지가 없습니다.
  • 설치 프로그램이 디스크를 통째로 포맷하고 기본이 서버/워크스테이션이라 중국어 데스크톱을 바로 쓰는 형태가 아닙니다.
  • 문서가 전부 영문이고 중국어 자료는 드물며 커뮤니티 규모도 작습니다.
