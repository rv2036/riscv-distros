결론부터

RISC-V에서 RHEL 10 사용자 공간을 쓰면서 Red Hat 계정은 피하고 싶다면, Rocky 10.3(GA 2026-11-16)에는 이제 설치 ISO, SBC 범용 raw, 클라우드 이미지, riscv64 저장소(BaseOS 952개 패키지)가 모두 있습니다. QEMU와 VisionFive 2는 릴리스 시점부터 공식 지원, P550은 제한 지원입니다.

vendor
Rocky Enterprise Software Foundation
기반
RHEL 10 (CentOS Stream 10 코드베이스)
업스트림
Rocky Linux 10은 riscv64(riscv64gc 빌드)를 공식 지원하며, Rocky AltArch SIG와 Fedora RISC-V 커뮤니티가 추진했습니다. riscv64는 대체 아키텍처(Alternative Architecture)로 분류되어, 이 아키텍처의 빌드 실패가 다른 아키텍처 릴리스를 막지 않습니다.
버전
10.3 (GA 2026-11-16): riscv64용 boot / minimal / dvd 설치 ISO(2026-11-12/13 빌드, 11-18에 10-latest 갱신), SBC 범용 raw 이미지(20261112.0), GenericCloud qcow2를 제공합니다. BaseOS와 AppStream의 riscv64 저장소도 공개되었습니다(BaseOS 952개 패키지) · 10.2 (riscv64 컨테이너 이미지 이미 릴리스: Base / Minimal / Toolbox / UBI, 2026-05-25 빌드) · 10.0 (GA 공지에서 riscv64를 지원 아키텍처로 명시)

지원 보드

  • QEMU virt 가상 머신 공식 지원 Rocky 공식 RISC-V 공지와 10.0 릴리스 노트 모두 QEMU를 릴리스 시점부터 지원 대상으로 명시합니다(원문 "works out-of-the-box ... in QEMU"). 이제 boot / minimal ISO로 anaconda 설치도 가능합니다
  • StarFive VisionFive 2 공식 지원 공식 공지에서 VisionFive 2를 권장 보드로 명시합니다(표준 EL10 커널로 부팅). SBC 범용 raw 이미지와 설치 ISO를 모두 쓸 수 있지만 보드별 검증 목록은 여전히 없습니다
  • SiFive HiFive Premier P550 부분 지원 공식적으로 "limited support"로 표기되어 벤더 커널이 필요하고 일부 기능이 제한됩니다

주의할 점

  • 설치 ISO는 있지만 boot / minimal / dvd 세 종류뿐이며 Live 이미지는 없습니다(/pub/rocky/10.3/Live/는 404). ISO는 EFI 부팅(EFI/BOOT/BOOTRISCV64.EFI 포함)이라 U-Boot에서 직접 부팅하는 보드는 여전히 SBC 범용 raw가 필요합니다
  • SBC 이미지는 'SBC-Generic' 범용 raw라 보드별 디렉터리도 보드별 검증 목록도 없습니다. JH7110 계열 보드가 부팅되는지는 직접 시험해야 합니다
  • riscv64는 대체 아키텍처(Alternative Architecture)라 빌드 실패가 주 아키텍처 릴리스를 막지 않으므로, 패키지가 얼마나 갖춰져 있는지는 운에 달려 있습니다
