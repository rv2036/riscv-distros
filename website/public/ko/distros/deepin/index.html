결론부터

데스크톱이 가장 예쁜 중국산 배포판이지만 RISC-V 갈래는 커뮤니티 프리뷰 성격에 보드별 tar.xz 배포라, 평가·체험용으로 맞고 유일한 일상 시스템으로는 권하지 않습니다.

기반
Debian 계열 + deepin 자체 저장소(deepin 25 ‘crimson’). 커널은 보드별 6.6/6.12/6.16, DP1000은 메인라인 커널
업스트림
다운스트림 맞춤 배포판입니다. deepin 커뮤니티판이 Debian 패키지를 이어받고 자체 저장소와 Linglong 패키지 체계를 얹습니다. RISC-V는 deepin-ports SIG가 유지하며 공식 표기는 ‘기술 프리뷰’입니다.

주의할 점

  • RISC-V는 아직 기술 프리뷰(공식 표기)라 안정성과 완성도가 부족합니다.
  • 보드별 이미지는 ISO가 아니라 tar.xz라 직접 풀어서 기록해야 합니다. 범용 ISO 25.2.0은 UEFI 부팅이 필요합니다.
  • 설치 프로그램이 있는 liveimage-desktop은 기본 사용자를 만들지 않으며 root 기본 비밀번호는 deepin입니다.
  • immutable(읽기 전용 루트) 변형이 있어 시스템을 고치는 방식이 일반적이지 않습니다.
  • deepin RISC-V는 커뮤니티 수준 지원뿐이고 상용 지원은 통신(UnionTech) UOS를 거쳐야 합니다.
