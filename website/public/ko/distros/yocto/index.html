기반
직접 컴파일 (BitBake + oe-core + meta-riscv)
업스트림
빌드 시스템입니다. oe-core에 qemuriscv32/qemuriscv64 machine과 riscv64 tune이 들어 있고, 보드별 지원은 공식 RISC-V 레이어인 meta-riscv(riscv/ 조직)가 machine 설정으로 제공합니다.

지원 보드

  • QEMU virt 가상 머신 공식 지원 oe-core 네이티브 qemuriscv64/qemuriscv32.
  • Banana Pi BPI-F3(SpacemiT K1) 커뮤니티 지원 meta-riscv의 bananapi-f3 (메인라인 커널/U-Boot, 벤더 FSBL은 여전히 필요)
  • SpacemiT K3(Pico-ITX / CoM260) 커뮤니티 지원 meta-riscv의 k3-com260 / k3-pico-itx (-mainline 변형 포함)
  • LicheePi 4A(리치파이 4A) 커뮤니티 지원 meta-riscv의 licheepi-4a
  • StarFive VisionFive 2 커뮤니티 지원 meta-riscv의 visionfive2
  • Orange Pi RV2(Ky X1) 커뮤니티 지원 meta-riscv의 orangepi-rv2 (메인라인 커널/U-Boot + 벤더 FSBL)
  • Zhihe A210(XuanTie MelonPi 개발 보드) 커뮤니티 지원 meta-riscv의 zhihe-a210: OSU-OSL 메인라인 커널, TFTP netboot만 지원하고 bootloader recipe가 없습니다.

주의할 점

  • 학습 곡선이 가장 가파릅니다. BitBake 문법 + 레이어 버전이 엄격히 맞아야 합니다(meta-riscv는 master를 따라감).
  • 첫 빌드에서 수십 GB를 내려받고 몇 시간이 걸립니다.
  • 완성 이미지를 주지 않으므로 wic/sdimg를 직접 만들어야 합니다.
  • 벤더 FSBL/TEE는 따로 구해야 해서 순수 오픈소스 흐름만으로는 안 됩니다.
