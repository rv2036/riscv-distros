결론부터

TH1520 보드의 사실상 표준 시스템입니다. LicheePi 4A와 Milk-V Meles는 출하 시/공식 튜토리얼 기본값이 RevyOS입니다. 초보자가 가장 먼저 손대기 좋지만, 이미지 서버가 문서보다 최신이므로 이미지 서버 디렉터리에서 가장 최근 날짜를 받으세요.

기반
Debian 13(trixie) rootfs + 쉬안톄 맞춤 6.6 커널(TH1520/SG2042 BSP). 구버전 20240720은 Debian 12 + 5.10 커널
업스트림
다운스트림 맞춤 배포판입니다. PLCT Lab(중국과학원 소프트웨어연구소)이 쉬안톄/T-Head(XuanTie) 생태계를 위해 유지하며 Debian 13(trixie) 패키지 저장소 + 쉬안톄 맞춤 커널을 재사용합니다. Debian 공식 port도, 독립 패키지 체계도 아닙니다.

지원 보드

  • LicheePi 4A(리치파이 4A) 공식 지원 주력 레퍼런스 보드. SD/eMMC 듀얼 부팅, 이미지와 문서가 가장 풍부합니다.
  • Milk-V Meles 공식 지원 Milk-V Meles. 공식 이미지 20260504 + 플래싱 튜토리얼.
  • Milk-V Pioneer(SG2042 서버 지향) 공식 지원 Milk-V Pioneer(SG2042), 이미지 20260504.
  • SpacemiT K3(Pico-ITX / CoM260) 부분 지원 coreboot+OpenSBI+EDK2 펌웨어 형태로 제공되며(Ruyi Firmware) 완전한 OS 이미지는 아닙니다.

주의할 점

  • 버전 번호가 날짜(YYYYMMDD)이고 시맨틱 버전이 아닙니다. 공식 문서 페이지가 이미지 서버보다 오래된 경우가 많습니다(문서는 20251226, 이미지 서버에는 20260504).
  • 20240720 이하에서 올라올 때는 반드시 U-Boot 환경 변수를 초기화해야 합니다(env default -a -f; env save; reset). 그러지 않으면 부팅되지 않습니다.
  • LicheePi 4A는 일부 SD 카드와 호환 문제가 있습니다. 공식 SD 카드 호환 목록이 있으니 eMMC를 우선하세요.
  • 20260926/20260924 디렉터리는 coreboot+EDK2 펌웨어(무 U-Boot)로 시스템 이미지가 아닙니다. 기본 1.84GHz에서는 방열이 필수입니다.
  • GPU/NPU는 벤더 BSP 드라이버 스택에 의존합니다(revyos-gles-21, NPU 문서 별도). 전부 메인라인에 들어간 것은 아닙니다.
