결론부터

기업 지향 RISC-V 프리뷰 시스템입니다. RHEL 사용자 공간이 돌아가는지 검증하려면 이걸 보면 되고, 일상 사용에는 여전히 Debian / Ubuntu / RevyOS가 편합니다.

vendor
Red Hat
기반
RHEL 10.2 (Fedora / CentOS Stream 10 코드베이스)
업스트림
Red Hat이 직접 배포하는 RISC-V 개발자 프리뷰(Developer Preview)로, RHEL 10.2 코드베이스를 기반으로 하며 소수 플랫폼에만 사전 빌드 이미지를 제공합니다. Red Hat은 지원 대상 제품 버전이 아니라고 분명히 밝히고 있습니다.
버전
10.2 Developer Preview Update (2026-10-09, 이미지 2.6 GB, 소스 14.19 GB, Red Hat 계정 로그인 후 다운로드) · 10.2 Developer Preview · 10.0 Developer Preview (2025-05 최초 배포, 플랫폼은 P550)
문서 언어
en
확인일
2026-11-02

지원 보드

  • SiFive HiFive Premier P550 공식 지원 최초이자 장기 주력 플랫폼(SiFive HiFive Premier P550)
  • SpacemiT K3(Pico-ITX / CoM260) 공식 지원 10.2 Update에서 추가: SpacemiT K3 Pico-ITX
  • SpacemiT K3 CoM260 Kit 공식 지원 10.2 Update에서 추가: SpacemiT K3 CoM260
  • Milk-V Titan(UltraRISC DP1000) 공식 지원 10.2 Update에서 추가: UltraRISC UR-DP1000 (Milk-V Titan)
  • QEMU virt 가상 머신 부분 지원 공식 QEMU 전용 이미지는 없고, 이미지는 보드별로 나옵니다

다운로드

공식 다운로드 페이지(RHEL 10.2 RISC-V Developer Preview Update, Red Hat 개발자 계정 필요)

설치 문서와 영상

  • Red Hat 블로그: RISC-V Developer Preview가 10.2로 업데이트됨 문서 en

주의할 점

  • Developer Preview이지 프로덕션 지원 버전이 아닙니다. Red Hat이 지원을 제공하지 않으니 업무용으로 쓰지 마세요
  • 다운로드에는 Red Hat 개발자 계정 로그인이 필요하며(무료), curl로 직접 받으면 봇 차단에 걸려 403이 됩니다
  • 이미지는 플랫폼별로 나오며 범용 RISC-V 설치 미디어는 없습니다. 2.6 GB짜리는 단일 플랫폼 디스크 이미지입니다
  • 10.2 Update에서 추가된 SpacemiT V100은 서버급 CPU이지만 현재 대응하는 완제품 항목이 없어, 칩이 RHEL에 들어갔다는 정도로만 볼 수 있습니다
