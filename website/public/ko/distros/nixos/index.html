결론부터

선언형 설정은 매력적이지만 riscv64는 “돌긴 돌아가지만 편하리라 기대하면 안 되는” 상태입니다.

기반
독립 (Nix/nixpkgs, systemd)
업스트림
nixpkgs의 nixpkgs-unstable과 stable channel 모두 공식 riscv64-linux 지원이 없습니다. 공식 wiki도 “모든 RISC-V 플랫폼은 현재 실험적”이라고 명시하며 이미지는 커뮤니티가 제공합니다.

지원 보드

  • QEMU virt 가상 머신 커뮤니티 지원 에뮬레이션은 가능하지만 wiki가 일부 프로그램은 QEMU에서 segfault한다고 명시합니다.
  • SiFive HiFive Unmatched 커뮤니티 지원 가장 이른 커뮤니티 포팅 대상입니다(zhaofengli/nixos-riscv64).
  • StarFive VisionFive 2 커뮤니티 지원 JH7110, 커뮤니티 이미지 + misuzu/nixos-vf2 flake.
  • LicheePi 4A(리치파이 4A) 커뮤니티 지원 ryan4yin/nixos-licheepi4a 커뮤니티 flake.

다운로드

NixOS 공식 다운로드 (riscv64 ISO 없음)커뮤니티 이미지/overlay: zhaofengli/nixos-riscv64 (HiFive Unmatched에서 시작)

설치 문서와 영상

  • NixOS Wiki: RISC-V (지원 기기, 커뮤니티 이미지, 제3자 binary cache) 문서 en

주의할 점

  • 공식 ISO가 없어 커뮤니티 이미지를 쓰거나 직접 cross-compile해야 합니다.
  • 공식 cache.nixos.org에 riscv64 패키지가 없어 제3자 substituter(cache.ztier.in / beam.attic.rs 등)를 붙여야 하며, 아니면 거의 전부 로컬 빌드입니다.
  • QEMU에서 불안정합니다(segfault).
  • 커뮤니티 이미지가 특정 커널/펌웨어 버전에 묶여 있어 업그레이드가 잘 깨집니다.
