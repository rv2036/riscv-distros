支持的开发板

  • QEMU virt 虚拟机型 官方支持 oe-core 原生 qemuriscv64/qemuriscv32
  • Banana Pi BPI-F3（SpacemiT K1） 社区可用 meta-riscv 的 bananapi-f3（主线内核/U-Boot，仍需厂商 FSBL）
  • 进迭时空 SpacemiT K3（Pico-ITX / CoM260） 社区可用 meta-riscv 的 k3-com260 / k3-pico-itx（含 -mainline 变体）
  • 荔枝派 4A（LicheePi 4A） 社区可用 meta-riscv 的 licheepi-4a
  • StarFive VisionFive 2 社区可用 meta-riscv 的 visionfive2
  • Orange Pi RV2（Ky X1） 社区可用 meta-riscv 的 orangepi-rv2（主线内核/U-Boot + 厂商 FSBL）
  • 知合计算 A210（玄铁 MelonPi 开发板） 社区可用 meta-riscv 的 zhihe-a210：OSU-OSL 主线内核，仅 TFTP netboot，无 bootloader recipe

坑

  • 学习曲线最陡：BitBake 语法 + layer 版本必须严格匹配（meta-riscv 跟 master）
  • 首次构建下载数十 GB、耗时数小时
  • 不提供现成镜像，要自己出 wic/sdimg
  • 厂商 FSBL/TEE 仍要单独获取，纯开源流程走不通
