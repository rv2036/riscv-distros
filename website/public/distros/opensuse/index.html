  • 嘉楠 Canaan K230（Kendryte K230 / CanMV-K230） 部分可用 无官方支持
  • Milk-V Megrez（ESWIN EIC7700X） 社区可用 通用镜像 + 板端 UEFI，未确认
  • Milk-V Titan（UltraRISC DP1000） 社区可用 通用镜像 + 板端 UEFI，未确认
  • Milk-V Pioneer（SG2042 服务器向） 社区可用 通用镜像 + 板端 UEFI，未确认
  • Orange Pi RV2（Ky X1） 社区可用 通用镜像 + 板端 UEFI，未确认
  • Banana Pi BPI-F3（SpacemiT K1） 社区可用 通用镜像 + 板端 UEFI，未确认

坑

  • ISO 是快照自动发布、发布前零测试，官方 README.FIRST 原文："They haven't seen any kind of testing before publishing... there are times when they are broken"
  • 只有滚动版（Tumbleweed/MicroOS），没有 Leap 稳定版可用
  • 无板级镜像，全部依赖板端 UEFI/U-Boot 固件
  • 官方 RISC-V 文档主要在 en.opensuse.org wiki，该站对自动化抓取返回 403，机器校验不了
