先说结论

主要供厂商/生态测试用：官方定位就是『早期验证』——尽早暴露固件、平台语义与内核互操作问题，让厂商少的分叉。普通用户一般不需要装它，日常使用请选 Bianbu / RevyOS / openKylin 这类厂商发行版；想零成本体验可先用它的 QEMU 镜像。

基于
独立自建（RPM + dnf，滚动发布）；内核 7.2.6 / LTS 6.18.54，工具链 GCC 16.2 / glibc 自带
上游状态
独立发行版：中科院软件所（ISCAS）发起并长期维护的 RISC-V 原生发行版，自建 RPM 包集与构建流水线（SPECS/dnf），不基于 Debian/Ubuntu/openEuler 的二进制包。

坑

  • 滚动发布、无 LTS，月度版本可能大改，不适合当稳定生产底座
  • 镜像分 RVA20 / RVA23 两套，选错会在不支持对应 profile 的核上起不来
  • K3 需要配套 Ruyi Firmware（coreboot+OpenSBI+EDK2），多数普通 U-Boot 开发板没有现成镜像
  • 安装器整盘格式化，且默认面向服务器/工作站，不是开箱即用的中文桌面
  • 文档全英文，中文资料很少；社区规模小
