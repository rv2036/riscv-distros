先说结论

想在 RISC-V 上用 RHEL 10 用户态、又不想碰 Red Hat 账号：Rocky 10.3（2026-11-16 GA）把安装 ISO、SBC 通用 raw、云镜像和 riscv64 仓库（BaseOS 952 个包）都补齐了；官方点名 QEMU 与 VisionFive 2 发布即支持，P550 属有限支持。

vendor

基于
RHEL 10（CentOS Stream 10 代码基）
上游状态
Rocky Linux 10 官方支持 riscv64（riscv64gc 构建），由 Rocky AltArch SIG 与 Fedora RISC-V 社区推动。riscv64 被列为 Alternative Architecture：它的构建失败不阻塞其它架构的发布。
版本

支持的开发板

  • QEMU virt 虚拟机型 官方支持 Rocky 官方 RISC-V 公告与 10.0 发布说明都把 QEMU 列为发布即支持（原文「works out-of-the-box … in QEMU」）；现在还能用 boot / minimal ISO 走 anaconda 安装
  • StarFive VisionFive 2 官方支持 官方公告把 VisionFive 2 列为推荐板（标准 EL10 内核即可启动）；SBC 通用 raw 与安装 ISO 都能用，但官方没给逐板验证清单
  • SiFive HiFive Premier P550 部分可用 官方标注为「limited support」：要用厂商内核，部分特性受限

坑

  • 有安装 ISO，但只有 boot / minimal / dvd 三种，没有 Live 镜像（/pub/rocky/10.3/Live/ 是 404）；ISO 走 EFI 引导（内含 EFI/BOOT/BOOTRISCV64.EFI），U-Boot 直启的板子仍要用 SBC 通用 raw
  • SBC 镜像是「SBC-Generic」通用 raw，不按板卡分目录，也没有逐板验证清单；JH7110 这类板能不能起要自己实测
  • riscv64 是 Alternative Architecture，构建失败不阻塞主架构发布，所以软件包齐不齐要看运气
