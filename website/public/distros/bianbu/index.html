先说结论

K1/K3 板卡（BPI-F3、Milk-V Jupiter、MUSE、Pico ITX）唯一有官方桌面体验的系统，开箱 GNOME/LXQt，中文文档完整，是最适合新人的厂商发行版。

基于
Ubuntu 24.04 LTS（Bianbu 2.x，K1）/ Ubuntu 25.04（Bianbu 3.x，K1）/ Ubuntu 26.04（Bianbu 4.x，K3；厂商论坛口径，官方文档未逐版标注）+ 厂商 BSP 内核 6.6 LTS / 6.18
上游状态
下游定制发行版：进迭时空（SpacemiT）官方 OS，明确『基于 Ubuntu 社区源码构建』，APT + deb 包格式；K1 走 Ubuntu 24.04(2.x)/25.04(3.x)，K3 走 Ubuntu 26.04(4.x)。

坑

  • K1 与 K3 版本线完全不同：K1 长期维护 2.x（Ubuntu 24.04），3.x 基于非 LTS 的 Ubuntu 25.04；K3 只有 4.x（Ubuntu 26.04）
  • RVA22 的 K1 跑不了为 RVA23 构建的 Ubuntu 26.04/Bianbu 4.x；K3 可向下兼容 RVA22 代码
  • 镜像是 .zip（内含 .img），需解压后 dd / Etcher 烧写；部分板卡另有 UEFI 变体，别刷错
  • 厂商 BSP 内核（6.6 LTS / 6.18）而非主线，换内核要按官方 kernel 仓编译
  • MUSE 系列、BPI-F3、Milk-V Jupiter 镜像按板卡区分，刷错无法启动；镜像约 2~2.6GB
