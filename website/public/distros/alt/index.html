先说结论

俄系里 RISC-V 支持最完整的一支，镜像开箱可用，适合 QEMU 与 Unmatched 玩家。

基于
独立（RPM/apt-rpm，ALT 自有工具链）
上游状态
官方 riscv64 移植：Sisyphus 的 riscv64 仓库 + Regular riscv64 测试镜像（jeos-systemd/lxqt/mate/xfce，rv64gc），由 ALT 团队维护并有 riscv-devel 邮件列表。
版本
Sisyphus（rolling，riscv64 port） · p11（stable 分支，riscv64 仅 Sisyphus 有）
文档语言
en / ru
下游衍生
Simply Linux / ALT Mobile（同仓库体系，无 riscv64 构建）
核查日期
2026-11-01

支持的开发板

  • QEMU virt 虚拟机型 官方支持 镜像设计为可直接在 qemu 启动，wiki 有 QEMU 专页
  • SiFive HiFive Unmatched 官方支持 wiki 提供 HiFive Unmatched/Unleashed 写盘与启动说明

下载

Regular riscv64 镜像（nightly，iso/tar.xz）riscv64 Sisyphus 软件仓库（RPM）

安装文档与视频

  • ALT Wiki: Regular/riscv64（下载、QEMU、Unmatched/Unleashed、VNC） 文档 en
  • ALT Wiki: Ports/riscv64（俄文） 文档 ru

坑

  • 官方把 riscv64 镜像定位为“测试与开发 Sisyphus 移植”，不是长期支持产品
  • wiki 与 ftp 全站挂 Anubis 反爬，脚本抓取会拿到 200 的挑战页而非正文（需浏览器或镜像站）
  • 图形镜像首启要走 alterator-setup，无显卡板子得用 VNC
  • 仅 rv64gc，无 rv32

  • mirror.yandex.ru/altlinux/ports/riscv64/Sisyphus/riscv64/
  • en.altlinux.org/Regular/riscv64
