先说结论

Debian 是这批里唯一把 riscv64 放进正式发布架构的独立发行版；衍生作品另有 Deepin、RevyOS 等基于 Debian 的 riscv64 系统（未逐项核实）。

上游状态
Debian 13 (trixie) 起 riscv64 为官方发布架构——官方新闻稿原文："This release for the first time officially supports the riscv64 architecture"；进入主归档 deb.debian.org，不是 ports 附加树（debian.org/ports 列表中 riscv64 标注 13/released）。

支持的开发板

  • QEMU virt 虚拟机型 官方支持 官方 riscv64 netinst 在 QEMU virt 上安装，是 d-i 的主要目标平台
  • SiFive HiFive Unmatched 社区可用 通用 riscv64 镜像 + 板端 U-Boot/UEFI 启动；Debian 不发布板级镜像
  • StarFive VisionFive 2 社区可用 同上，JH7110 板用厂商 U-Boot 提供 UEFI 后装通用镜像
  • 荔枝派 4A（LicheePi 4A） 部分可用 TH1520 需厂商 U-Boot/内核，Debian 主线无板级支持
  • Milk-V Meles 部分可用 同为 TH1520 平台，情况与 LicheePi 4A 类似
  • 进迭时空 SpacemiT K3（Pico-ITX / CoM260） 部分可用 SpacemiT K3 需厂商 BSP；Debian 主线支持情况未确认
  • 知合计算 A210（玄铁 MelonPi 开发板） 部分可用 知合 A210 需厂商固件/内核，无 Debian 官方支持
  • 嘉楠 Canaan K230（Kendryte K230 / CanMV-K230） 部分可用 Canaan K230 为 MCU 类 SoC，主线支持有限
  • Milk-V Megrez（ESWIN EIC7700X） 社区可用 EIC7700 板可走通用 UEFI 镜像，未在 Debian 文档确认
  • Milk-V Titan（UltraRISC DP1000） 社区可用 DP1000 同上，未在 Debian 文档确认
  • Milk-V Pioneer（SG2042 服务器向） 社区可用 SG2042 可走通用镜像，未在 Debian 文档确认
  • Orange Pi RV2（Ky X1） 社区可用 SpacemiT K1 板，通用镜像 + 板端 U-Boot
  • Banana Pi BPI-F3（SpacemiT K1） 社区可用 SpacemiT K1 板，通用镜像 + 板端 U-Boot

坑

  • 只发布通用 riscv64 镜像（netinst/ISO），没有板级镜像；能否启动取决于板端 U-Boot/UEFI 固件
  • 官方安装手册自我声明："This installation guide has not been fully updated and fact checked for riscv64"，部分章节可能过时
  • netinst 安装需联网拉取软件包
