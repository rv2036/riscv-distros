先说结论

桌面做得最漂亮的国产发行版，但 RISC-V 分支是社区预览性质、按板卡发 tar.xz，适合评估/尝鲜，不建议作为唯一日常系统。

基于
Debian 系 + deepin 自有仓库（deepin 25『crimson』）；内核按板卡 6.6/6.12/6.16，DP1000 用主线内核
上游状态
下游定制发行版：deepin（深度）社区版继承 Debian 软件包并叠加自有仓库与玲珑包体系；RISC-V 由 deepin-ports SIG 维护，官方标注为『技术预览』。

坑

  • RISC-V 仍为技术预览（官方明确标注），稳定性和完整性不足
  • 按板卡的镜像是 tar.xz 而非 ISO，需要手动解压写盘；通用 ISO 25.2.0 需要 UEFI 启动
  • 带安装器的 liveimage-desktop 不创建默认用户，root 默认密码是 deepin
  • 存在 immutable（只读根）变体，改装系统的方式与常规不同
  • deepin RISC-V 仅社区级支持，商业支持要走统信 UOS
