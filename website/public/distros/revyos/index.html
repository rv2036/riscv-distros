先说结论

TH1520 板卡的事实标准系统：LicheePi 4A、Milk-V Meles 出厂/官方教程默认刷 RevyOS。新手上手首选，但注意镜像站比文档新，按镜像站目录取最新日期。

基于
Debian 13 (trixie) rootfs + 玄铁定制 6.6 内核（TH1520/SG2042 BSP）；旧版 20240720 为 Debian 12 + 5.10 内核
上游状态
下游定制发行版：PLCT Lab（中科院软件所）为玄铁/T-Head（XuanTie）生态维护，复用 Debian 13 (trixie) 软件包仓 + 玄铁定制内核，不是 Debian 官方 port，也不是独立包体系。

坑

  • 版本号是日期（YYYYMMDD），不是语义化版本；官方文档页长期滞后于镜像站（文档写 20251226，镜像站已有 20260504）
  • 从 20240720 及更早版本升级必须重置 U-Boot 环境变量（env default -a -f; env save; reset），否则无法启动
  • LicheePi 4A 部分 SD 卡存在兼容性问题，官方维护 SD 卡兼容清单，建议优先 eMMC
  • 20260926/20260924 目录是 coreboot+EDK2 固件（无 U-Boot），不是系统镜像；默认 1.84GHz 必须加散热
  • GPU/NPU 依赖厂商 BSP 驱动栈（另有 revyos-gles-21、NPU 文档），不是全部进主线
