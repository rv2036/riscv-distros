先说结论

服务器/企业场景的 RISC-V 底座，RVA23 + Server Platform 规范推进最快；个人开发板用户除非要做服务器验证，否则不如 RevyOS/Bianbu 省事。

基于
openEuler 24.03 LTS（RPM/dnf，自建源）+ RVCK 6.6 内核；RISC-V 分 RVA20 与 RVA23 两套构建
上游状态
独立发行版（自身即上游）：openEuler 社区（开放原子基金会）官方多架构同源构建，RISC-V 由 OERV SIG 移植维护，不是 Debian/Ubuntu 定制。
版本
24.03 LTS SP4（2026-06-30 发布；RISC-V RVA23 ISO 2026-09-08） · 24.03 LTS SP3（2026-03-09 转入长期维护；RVA20 + RVA23 双版本）

支持的开发板

  • 进迭时空 SpacemiT K3（Pico-ITX / CoM260） 官方支持 SP3 起支持 SpacemiT K3（COM260 验证，SD + GMAC），首个进入 LTS 的 RVA23 SoC
  • SpacemiT K3 CoM260 Kit 部分可用
  • Lichee Cluster 4A 社区可用
  • 荔枝派 4A（LicheePi 4A） 官方支持 官方安装文档单列，TH1520 平台
  • Milk-V Duo 系列（Duo / Duo 256M / Duo S） 社区可用
  • Muse Pi Pro 社区可用
  • Milk-V Pioneer（SG2042 服务器向） 官方支持 Milk-V Pioneer（SG2042），官方安装文档 RISC-V-Pioneer1.3
  • QEMU virt 虚拟机型 官方支持 官方 QEMU 安装文档，最适合先试
  • SiFive HiFive Unmatched 社区可用
  • VisionFive 社区可用
  • StarFive VisionFive 2 社区可用 23.03 起支持 VisionFive 2，24.03 文档未单列

坑

  • 创新版本 26.09（2026-09-30 发布）没有 riscv64 ISO：ISO/OS/everything 目录只有 aarch64 与 x86_64，RISC-V 仍以 24.03 LTS SP4 为准
  • RVA20 与 RVA23 镜像分开发布；24.03 LTS SP4 的 RISC-V 只提供 RVA23 ISO（rva20 目录不存在）
  • 需要 UEFI/EDK2 固件与对应板卡 DTB，老 U-Boot 板卡可能起不来
  • 文档按版本分路径，RISC-V 安装页只挂在 24.03_LTS 路径下，SP3/SP4 路径会 404
  • 服务器导向：默认最小化安装，桌面与多媒体支持弱于厂商桌面发行版
  • everything ISO 20GB 级别，普通用户选 dvd/netinst 即可
