先说结论

国产 RISC-V 板“能开箱用”的最大功臣；K3/BPI-F3 这类新板优先看它。

基于
Debian/Ubuntu（Armbian build framework）
上游状态
官方构建框架（armbian/build）直接出 riscv64 镜像，板卡按 Platinum/Standard/Community 分级；RISC-V 板在官网有独立下载页与镜像清单。

支持的开发板

  • 进迭时空 SpacemiT K3（Pico-ITX / CoM260） 官方支持 MusePi Pro 为 Platinum（内核 6.18.55 current / 6.6.100 legacy）；K3 Pico-ITX 亦为 Platinum
  • Banana Pi BPI-F3（SpacemiT K1） 官方支持 Standard 级，内核 6.18.45；另有 Bianbu 变体
  • Orange Pi RV2（Ky X1） 社区可用 Community 级，仅 Debian 13 minimal（6.18.58）
  • StarFive VisionFive 2 社区可用 Community 级，vendor 内核 6.6.20，Ubuntu/Debian 三镜像

坑

  • 不少板仍绑 vendor 内核（6.6.x Bianbu），主线化程度不一
  • Community 级板只有单一 CLI 镜像，桌面/更新靠社区
  • 没有 Meles / Pioneer / Megrez / K230 等板
  • 同一版本号在不同板上的内核版本不一致，写文档别写死
