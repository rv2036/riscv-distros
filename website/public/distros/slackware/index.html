基于
独立（pkgtools + slackpkg，BSD 风格 init）
上游状态
官方 Slackware 15.0 只发 x86_64（slackware.com 另有官方 ARM 项目 arm.slackware.com）；RISC-V 由非官方 slarm64 移植（sndwvs）跟随 15.0/current 提供软件包与板级镜像。

安装文档与视频

  • slarm64 项目仓库（构建脚本与说明） 文档 en
  • RVSpace 论坛：slarm64（aarch64/riscv64 非官方 Slackware 移植） 文档 en

坑

  • 官方零支持，全部依赖单人维护的 slarm64
  • 没有 installer：要从包树 chroot 手工装，或直接写板级镜像
  • slackware.com 对脚本访问返回 403（Akamai），查版本要走镜像站
  • 文档只有 README 与论坛帖，中文资料几乎为零
