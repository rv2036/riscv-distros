坑

  • 多数板子必须用 Omni 内核（...riscv64.omni.fcXX），标准 7.x 内核只覆盖 VisionFive 2 / Orange Pi RV / Milk-V Mars 一类，官方原文 "Most boards can only boot when using the Omni kernel"
  • Omni 内核里仍有 patch 未上游（原文 "Some patches in this kernel are still under review upstream"）
  • 只适合 headless：mainline 不含 SoC 集显驱动，官方定位是构建机/服务器（"video output are pretty much completely ignored"）
  • 安装需要串口控制台（Requirements → Serial console access）
  • 部分软件包需要 RISC-V 专用 patch，与上游源码仍有 delta
