先说结论

国产桌面 OS 的 RISC-V 分支，板卡覆盖随版本割裂（3.0 只认 K3/V100）。适合想评估国产桌面栈的人，不适合作为 TH1520/K1 老板子的日常系统。

基于
独立构建（deb/APT + 自建源，UKUI 桌面）；3.0 用 Linux 7.0 内核，2.0 SP2 为长期稳定版
上游状态
独立发行版：openKylin（开放麒麟）社区自建 deb 仓库与 UKUI 桌面，官方定位为独立根社区操作系统，不是 Ubuntu/Debian 直接派生；RISC-V 由 openKylin RISC-V SIG 适配。

支持的开发板

  • BIT-BRICK K1 社区可用
  • Banana Pi BPI-F3（SpacemiT K1） 社区可用 2.0 SP2 有 SpacemiT K1 镜像（未点名 BPI-F3，需自行验证）
  • 进迭时空 SpacemiT K3（Pico-ITX / CoM260） 官方支持 3.0 提供 SpacemiT K3 Server / Embedded 镜像
  • Lichee Cluster 4A 社区可用
  • 荔枝派 4A（LicheePi 4A） 官方支持 2.0 SP2 提供 LicheePi4A 镜像（2.5G，2025-08-26）
  • Milk-V Mars 社区可用
  • Milk-V Pioneer（SG2042 服务器向） 官方支持 2.0 SP2 提供 Milk-V Pioneer 镜像（3.0G）
  • QEMU virt 虚拟机型 官方支持 2.0 SP2 提供 RVA23 QEMU 镜像（1.8G）
  • SiFive HiFive Unmatched 社区可用
  • VisionFive 社区可用
  • StarFive VisionFive 2 社区可用

坑

  • 3.0 的 RISC-V 镜像只覆盖 SpacemiT K3（Server/Embedded）与 V100；LicheePi 4A / Pioneer 仍停在 2.0 SP2
  • RISC-V 镜像是按板卡定制而非通用 ISO，需对号入座；只有 2.0 SP2 提供 RVA23 qemu 镜像
  • 3.0 的 RISC-V 镜像偏服务器/嵌入式（Server、Embedded），不等于桌面体验
  • 下载链接是 download-smp.php?id=xxx 跳转，真实文件在 cdimage.openkylin.top
  • 文档以中文为主，英文文档站基本是空壳；RISC-V 问题主要靠中文社区/SIG 响应
