先说结论

只适合想看“Android 框架在 RISC-V 上跑起来”的验证性实验，别当可用系统。

基于
AOSP（Linux 内核 + Android 框架）
上游状态
AOSP 主线保留 riscv64 target（build/target/product/aosp_riscv64.mk、module_riscv64.mk），但只在 Cuttlefish 虚拟设备上验证；2024 年 Android Common Kernel/GKI 移除了 RISC-V 支持，Google 称仍在 AOSP 继续。

  • QEMU virt 虚拟机型 官方支持 Cuttlefish（cvd）是官方唯一运行方式，需 qemu ≥ 8.1（9.0+ 对 V 扩展更稳）

坑

  • 没有手机/开发板官方镜像，只有模拟器
  • NDK 的 riscv64 ABI 尚未定稿（provisional），现在编译的 .so 将来可能不兼容
  • 启动到桌面在快机器上也要约 10 分钟
  • ACK/GKI 移除 RISC-V 后，厂商拿不到长期内核支持，量产无望
