先说结论

企业级取向的 RISC-V 预览系统：想验证「RHEL 用户态能不能跑起来」看它，日常用还是 Debian / Ubuntu / RevyOS 更省事。

vendor
Red Hat
基于
RHEL 10.2（Fedora / CentOS Stream 10 代码基）
上游状态
Red Hat 自己发布的 RISC-V 开发者预览版（Developer Preview），基于 RHEL 10.2 代码基，只面向少数平台提供预构建镜像；Red Hat 明确它不是受支持的产品版本。

支持的开发板

  • SiFive HiFive Premier P550 官方支持 首个也是长期的主平台（SiFive HiFive Premier P550）
  • 进迭时空 SpacemiT K3（Pico-ITX / CoM260） 官方支持 10.2 Update 新增：SpacemiT K3 Pico-ITX
  • SpacemiT K3 CoM260 Kit 官方支持 10.2 Update 新增：SpacemiT K3 CoM260
  • Milk-V Titan（UltraRISC DP1000） 官方支持 10.2 Update 新增：UltraRISC UR-DP1000（Milk-V Titan）
  • QEMU virt 虚拟机型 部分可用 官方没有单独的 QEMU 镜像，镜像按板卡出

下载

官方下载页（RHEL 10.2 RISC-V Developer Preview Update，需 Red Hat 开发者账号）

安装文档与视频

  • Red Hat 博客：RISC-V Developer Preview 已更新到 10.2 文档 en

坑

  • Developer Preview，不是生产支持版本：Red Hat 不提供支持，别拿去跑业务
  • 下载要登录 Red Hat 开发者账号（免费），直接 curl 会被反爬挡成 403
  • 镜像按平台出，没有通用的 RISC-V 安装介质；2.6 GB 那个是单平台磁盘镜像
  • 10.2 Update 新增的 SpacemiT V100 是服务器级 CPU，目前没有对应的整机条目，只能当「芯片已进 RHEL」看
