Характеристики
Чисто виртуальная платформа: до 512 ядер RV64GC, CLINT/PLIC, хост-мост PCIe, 8 virtio-mmio, NS16550 UART, опционально AIA/IOMMU; ОЗУ, накопитель и сеть полностью виртуализируются параметрами командной строки, реальных GPU/VPU/NPU нет.
Цена
Бесплатно, с открытым исходным кодом (GPLv2), поставляется в репозиториях дистрибутивов

Общая отправная точка для всех плат: сначала проверить ядро/rootfs на virt, затем переходить на реальное железо — это экономит массу времени на отладку прошивки.

Дистрибутивы

  • Debian Официально Начиная с Debian 13 riscv64 — официальная архитектура, официальный netinst ISO можно напрямую установить в virt
  • Ubuntu Официально Официальный cloud image riscv64, запуск с EDK2(pflash) или -kernel
  • Fedora Сообщество Fedora RISC-V предоставляет инструкцию по установке QEMU и образы
  • Alpine Linux Официально Есть только riscv64 minirootfs, без virt ISO, нужны собственные ядро/initramfs
  • Arch Linux RISC-V Официально archriscv предоставляет riscv64 ISO, можно загрузить в QEMU
  • openSUSE Сообщество openSUSE Ports предоставляет riscv64; официальный сайт возвращает 403 на curl, прямые ссылки не проверены
  • Gentoo Официально stage3 riscv64 + руководство по поддержке системы QEMU
  • Void Linux Частично Есть порт riscv64, образ QEMU нужно собирать самостоятельно
  • NixOS Сообщество riscv64 — неофициальный уровень поддержки, требуется кросс-сборка
  • ALT Linux Официально ALT Ports riscv64 предоставляет образ QEMU
  • FreeBSD Официально riscv64 поддерживает QEMU virt
  • NetBSD Официально Порт riscv64 поддерживает QEMU
  • OpenBSD Официально riscv64 поддерживает QEMU virt
  • openEuler Официально openEuler RISC-V SIG предоставляет образ QEMU
  • Buildroot Официально qemu_riscv64_virt_defconfig, система поднимается одной командой make
  • Yocto / OpenEmbedded Официально Машина qemuriscv64 официально поддерживается

Подводные камни

  • -bios default загружает только OpenSBI, без U-Boot/EDK2; для загрузки облачного образа Ubuntu/Fedora нужно загрузить 32MiB прошивку EDK2 через pflash, иначе будет чёрный экран
  • В virt нет GPU/VPU/NPU, не используйте его для проверки графики, аппаратного декодирования видео или AI-ускорения
  • Последовательный порт фиксирован — ttyS0; для выхода из режима -nographic нажмите Ctrl-A, затем X
  • Начиная с Ubuntu 26.04 требуется RVA23S64, старые версии QEMU без нужных расширений не запустятся; 24.04 всё ещё использует базовый уровень RVA20
  • Alpine riscv64 выпускает только minirootfs, без virt ISO; ядро и initramfs нужно готовить самостоятельно
