Подводные камни

  • Прошивка должна соответствовать версии образа: при устаревшем bootchain Fedora просто не загружается, сначала нужно прошить последнюю firmware
  • Нет собственного слота NVMe, можно использовать только переходник PCIe; на плате только 2×GbE
  • iGPU поддерживает только OpenGL ES, для OpenGL требуется MESA_LOADER_DRIVER_OVERRIDE=zink; при подключении дискретной видеокарты меню GRUB не отображается
  • В стране нет официальных каналов, нужны зарубежные дилеры вроде Arrow, доставка/пошлины оплачиваются отдельно
