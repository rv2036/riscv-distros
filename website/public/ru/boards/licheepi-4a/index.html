Самая документированная и с самым большим сообществом плата на TH1520; рабочий стол RevyOS работает, но закрытые GPU/NPU — серьёзный недостаток. Есть также производные от сообщества сборки вроде openwrt (не входят в стандартный id дистрибутива).

Дистрибутивы

  • RevyOS Официально Официально продвигаемая, последний системный образ 20251226 (на базе Debian + kernel 6.6)
  • Debian Частично Mainline Debian 13 загружается на LPi4A, но нужно самостоятельно подготовить U-Boot/DTB; официального образа установщика нет
  • Ubuntu Частично Есть только ubuntu-base rootfs, ядро и загрузку нужно настраивать самостоятельно
  • Fedora Сообщество Fedora-V Force предоставляет образы TH1520
  • Arch Linux RISC-V Сообщество archriscv поддерживает TH1520
  • Armbian Сообщество Armbian официально поддерживает LicheePi 4A
  • Gentoo Сообщество На wiki Gentoo есть отдельная страница TH1520
  • NixOS Сообщество Репозиторий сообщества nixos-licheepi4a (использует ядро/U-Boot от RevyOS)
  • openEuler Сообщество openEuler RISC-V SIG предоставляет образы
  • openKylin Сообщество Образ openKylin от сообщества
  • deepin Сообщество Портированная версия deepin RISC-V
  • Buildroot Частично RevyOS собирает boot/rootfs с помощью Buildroot

Подводные камни

  • GPU — Imagination BXM-4-64, доступен только закрытый blob от производителя, в mainline-ядре нет ускорения GPU; для NPU нужен специальный SDK от T-Head
  • В партиях 16GB, отгруженных до 2023.8.1, в U-Boot есть баг определения ОЗУ: необходимо прошить специальный u-boot для 16G, иначе приложения с большим объёмом памяти будут падать
  • Для прошивки нужно зажать кнопку BOOT и затем подать питание, чтобы войти в fastboot (USB 2345:7654); при обычной подаче питания режим загрузки не включается
  • При обновлении с RevyOS ≤20240720 необходимо сначала выполнить `env default -a -f; env save`, чтобы сбросить переменные окружения U-Boot
  • Версии 8GB и 16GB имеют разные device tree в boot.ext4 — при перекрёстной прошивке плата не загрузится
  • С 2026-09 RevyOS продвигает новую прошивку coreboot+EDK2 (вместо U-Boot SPL); это экспериментально — перед прошивкой уточните модель платы
