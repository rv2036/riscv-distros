Подводные камни

  • U-Boot SPL для версии 4GB отличается от версий 8GB/16GB (u-boot-with-spl-meles-4g.bin vs meles.bin) — прошивка не той версии превратит плату в кирпич
  • С 20251226 используется kernel 6.6; перед прошивкой системы необходимо сначала обновить прошивку в SPI Flash
  • eMMC — опциональный модуль; для загрузки с eMMC необходимо сначала прошить SPI NOR, иначе загрузка возможна только с SD
  • Прошивка eMMC выполняется через fastboot (T-HEAD USB download gadget 2345:7654); для входа в режим загрузки нужно нажать кнопку Download
  • Плата имеет несколько аппаратных версий V1.x (маркировка на лицевой стороне); DTB/образ должны соответствовать версии
  • Питание PoE требует самостоятельной подачи 5V на контакты PIN2/PIN4 разъёма — это не стандартное питание 802.3af
