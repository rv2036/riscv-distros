Единственная плата, которую можно использовать как «RISC-V рабочую станцию/сервер»; цена и энергопотребление на порядок выше; подходит для 64-ядерной параллельной сборки, CI runner, не подходит для начинающих. Есть также производные версии сообщества, например opencloudos (не входят в id стандартных дистрибутивов).

Дистрибутивы

  • RevyOS Официально Сейчас официально продвигается, RevyOS 20260504 предоставляет два набора прошивок и образов pioneer/pisces
  • Fedora Официально Официальная документация Milk-V использует Fedora 38 как пример установки, Fedora RISC-V поддерживает SG2042
  • openEuler Сообщество openEuler RISC-V SIG поддерживает SG2042 для серверных сценариев
  • openKylin Сообщество openKylin имеет серверный образ RISC-V
  • deepin Сообщество Портированная версия deepin RISC-V
  • Debian Частично debian-ports имеет базовые пакеты riscv64, но официального образа Pioneer нет
  • Ubuntu Частично Официального образа Canonical нет, нужно самостоятельно собирать rootfs

Подводные камни

  • Раздел Image на странице Download в документации Milk-V пуст (переехал в RevyOS), не ищите образы системы на старых страницах
  • Выбор модулей памяти: обязательно выбирайте RDIMM/UDIMM по официальному списку поддерживаемой DDR, иначе тренировка DDR не пройдёт и плата не запустится
  • Требуется стандартное питание ATX 24-pin + CPU 8-pin, радиатор обязателен (типичное энергопотребление 120 Вт)
  • Встроенного видеовыхода нет, нужна видеокарта PCIe; некоторые видеокарты не выводят изображение на этапе LinuxBoot/U-Boot
  • Обновление прошивки (LinuxBoot/EDK2 + MCU) несёт риск превратить плату в кирпич, прошивать строго в официальном порядке
  • У ранних партий ASM2824 PCIe switch есть проблемы совместимости, сначала проверьте buglist
