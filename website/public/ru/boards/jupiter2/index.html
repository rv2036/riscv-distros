Первый одноплатный компьютер на K3, готовый к RVA23 (по заявлению производителя), форм-фактор pico-ITX плюс 10GbE SFP+, подходит как настольная платформа или платформа для сетевых экспериментов.

Подводные камни

  • 10GbE — это оптический порт SFP+, а не RJ45: в обычный коммутатор придётся вставлять оптический модуль либо использовать единственный электрический порт GbE
  • Вывод на два дисплея идёт через DP Alt Mode по USB-C и eDP, стандартного порта HDMI нет
  • Bianbu предустановлена с завода (в RuyiSDK записано 4.0.1 Desktop); при переустановке сначала убедитесь, что образ предназначен для Jupiter2, а не универсальный образ для K3
  • На официальной странице цена не указана, цена и розничные каналы не проверены
