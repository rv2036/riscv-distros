Характеристики
8-ядерный 64-битный RISC-V: 4×C920@1.9GHz + 4×C908@1.9GHz, все поддерживают RVV (128bit); NPU 12 TOPS@INT8, поддерживает INT4/INT8/FP8/FP16/BF16 и Transformer; LPDDR4X до 16GB; eMMC5.1; декодирование H.265 4K@120fps; плата — модуль-ядро SODIMM + открытая базовая плата V1/V2/V3, 8GB LPDDR4X + 32GB eMMC (данные со страницы стороннего проекта)

Уточнение модели: чип — Zhihe Computing A210 (серия «Архимед», ядра XuanTie C920/C908), бренд платы разработчика записывается как «XuanTie MelonPi». Образ Ubuntu покрывает только A200 (a200-evb), для A210 он несовместим.

Дистрибутивы

  • Debian Официально Предкомпилированный образ Debian для рабочего стола a210-evb (SDK v2.9.0)
  • Buildroot Официально zhihe_a210_defconfig, официальный Buildroot SDK

Подводные камни

  • Розничных каналов и публичных цен нет, платы разработчика распространяются в основном через каналы оценки/сотрудничества, обычному разработчику трудно купить
  • Образы A210 и A200 несовместимы: официальная Ubuntu есть только для A200, для A210 — только Debian/Buildroot
  • На GitHub/Gitee нет официального репозитория BSP (поиск дал 0 результатов), ядро и драйверы поставляются в виде пакета SDK производителя, сторонних дистрибутивов сообщества практически нет
  • Данные производителя: на одном чипе DeepSeek-7B около 8 tok/s, при каскаде из 4 die — 25 tok/s, фактически ориентироваться на собственные замеры
