Аппаратная сборка хорошая, экосистема cape сильная, но ПО — худшее среди трёх плат на TH1520: официальные образы не обновлялись три года, подходит только для коллекции или обучения.

Дистрибутивы

  • Ubuntu Официально Единственный официальный образ Linux-десктопа xuantie-ubuntu-23.04-20230705 (Ubuntu 23.04 уже EOL)
  • Yocto / OpenEmbedded Официально Официальный производственный образ Yocto 2023-06-10, предустановлен на заводе
  • RevyOS Сообщество Каталог beagle в RevyOS остановился на 20231210, после этого не обновлялся
  • Fedora Сообщество Fedora-V Force предоставляет образы для BeagleV Ahead
  • Debian Частично В mainline Debian нет поддержки официального установщика, можно только собрать rootfs самостоятельно

Подводные камни

  • Официальные образы остановились на 2023 годе (Ubuntu 23.04 / Yocto 2023-06), Ubuntu 23.04 давно EOL, репозитории apt практически недоступны
  • Образ beagle для RevyOS также остановился на 20231210 — то есть поддерживаемого дистрибутива нет
  • Для прошивки eMMC нужен USB-C вход в fastboot + продукты специальной цепочки инструментов Xuantie; загрузка с SD-карты проще
  • Всего 4GB ОЗУ, для десктопа тесновато; для microHDMI нужен переходник
  • WiFi — AP6203BM, требуется соответствующий firmware blob, поддержка в mainline-ядре неполная
  • Гребёнка cape — логика 3.3V, подключение 5V cape сожжёт плату
