K1 — один из чипов для высокопроизводительных RISC-V SBC с наибольшими поставками в 2024–2025 гг.; у BPI-F3 самая пёстрая экосистема (официальный Bianbu + образы сообщества Armbian/Fedora/openSUSE/Arch/Gentoo). BPI-F3 также включён в матрицу поддержки RuyiSDK.

Дистрибутивы

  • Bianbu Официально Официально продвигается Bianbu (образ SpacemiT K1, с v1.0.7 поддерживает 16GB)
  • Armbian Сообщество Стандартная поддержка Armbian, образы Debian/Ubuntu (только загрузка с SD)
  • Debian Сообщество Предоставляется через Armbian
  • Ubuntu Сообщество Предоставляется через Armbian (не официально от Canonical)
  • Fedora Сообщество Сторонние образы, указанные на странице документации Banana Pi
  • openSUSE Сообщество То же, сторонние образы
  • Arch Linux RISC-V Сообщество То же, сторонние образы
  • Gentoo Сообщество То же, сторонние образы

Подводные камни

  • Образы Bianbu делятся на версию для SD-карты (*.img.zip) и версию для eMMC (*.zip); при записи не той версии система не загрузится
  • Официально продвигается только Bianbu; Debian/Ubuntu в основном через образы сообщества Armbian, причём Armbian поддерживает только загрузку с SD
  • Ранние Bianbu (<v1.0.7) не поддерживают версию с 16 ГБ ОЗУ
  • HDMI только 1.4/1080p, не подходит для 4K-десктопа
