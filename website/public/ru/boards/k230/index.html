CanMV (прошивка MicroPython) — форма с наибольшим объёмом выпуска и самой полной документацией; на стороне Linux официально продвигается Buildroot. Для Apache NuttX также есть поддержка платы CanMV-K230 (не дистрибутив); CanMV K230(D) уже включён в матрицу поддержки RuyiSDK, образ можно получить через ruyi device provision.

Дистрибутивы

  • Buildroot Официально k230_linux_sdk по умолчанию использует Buildroot (k230_canmv/k230_evb defconfig)
  • Debian Официально SDK поддерживает make debian, официально есть «Руководство по системе K230 Debian/Ubuntu»
  • Ubuntu Официально SDK поддерживает make ubuntu, см. то же руководство

Подводные камни

  • AMP-гетерогенность: по умолчанию малое ядро работает под Linux, большое — под RT-Smart/CanMV; только большое ядро имеет расширение V, векторные нагрузки должны идти на правильное ядро
  • Официальный Linux mainline — Buildroot; Debian/Ubuntu нужно собирать самостоятельно через make debian / make ubuntu, готовых официальных десктопных образов нет
  • Прошивка должна соответствовать: CanMV IDE распознаёт только прошивки с именем файла, начинающимся на CanMV-K230_micropython; с образом K230 SDK подключиться не удастся
  • Инструментарий nncase закрытый и жёстко привязан к версии прошивки; ранняя документация по сборке только на китайском
