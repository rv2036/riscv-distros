Исторический эталон RISC-V десктопа; сейчас он скорее для покупки б/у по случаю и для обучения. Порог входа для новичка высокий (последовательный порт + переключатели + питание), в качестве первой платы не рекомендуется. Есть также производные сборки сообщества, например openwrt (не входят в стандартный id дистрибутива).

Дистрибутивы

  • Ubuntu Официально Официальный предустановленный образ Canonical ubuntu-24.04.5-...+unmatched.img.xz, всё ещё в рамках поддержки 24.04 LTS
  • Buildroot Официально SiFive Freedom U SDK (FUSDK, гибрид Buildroot/Yocto) — эталонная система производителя, включает U-Boot/OpenSBI
  • Debian Сообщество Официальный установщик Debian riscv64 доступен, на Debian wiki есть отдельная страница по этой плате
  • Fedora Сообщество Fedora RISC-V долгое время указывает Unmatched как эталонную плату
  • openSUSE Сообщество openSUSE Ports предоставляет riscv64; официальный сайт возвращает 403, образ для этой платы не проверен
  • FreeBSD Сообщество FreeBSD/riscv поддерживает Unmatched
  • OpenBSD Сообщество OpenBSD/riscv64 по сообщениям сообщества работоспособен
  • Gentoo Сообщество Проект Gentoo RISC-V охватывает платформу U74
  • Armbian Частично Ранее был образ от сообщества, сейчас страница этой платы на сайте Armbian снята
  • openEuler Сообщество openEuler RISC-V SIG имеет образ для этой платы
  • openKylin Сообщество Версия openKylin RISC-V ранее поддерживала
  • deepin Сообщество Портированная версия deepin RISC-V доступна

Подводные камни

  • Нет встроенного видеовыхода — нужна PCIe-видеокарта или последовательный порт; для отладки обязательно подключить USB-UART (FTDI), иначе не увидеть логи OpenSBI/U-Boot
  • Питание 12V/6A через цилиндрический разъём; при недостаточном питании возможны случайные перезагрузки или сбой DDR-тренировки
  • Загрузочный носитель определяется переключателями MSEL (SD/SPI Flash); при неверном положении плата не загрузится; при повреждении прошивки SPI восстановление только через JTAG
  • Официально снята с производства; Ubuntu 24.04 — последний поддерживаемый LTS-образ, ядро устаревшее, новые дистрибутивы образы для этой платы практически не выпускают
  • PCIe-видеокарте нужно внешнее питание; некоторые карты на этапе U-Boot не выводят изображение — оно появляется только после загрузки Linux
