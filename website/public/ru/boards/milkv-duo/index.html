Характеристики
Duo: 2×C906 (1 ГГц + 700 МГц) + 8051, 64 МБ SIP DRAM; Duo 256M: SG2002 плюс 1×Cortex-A53, 256 МБ; Duo S: 512 МБ + площадка eMMC (в некоторых комплектах 8 ГБ) + WiFi6; у всех есть порт 100M и USB-C; Duo/256M — 26×контактных площадок GPIO, 21×51 мм, Duo S — 2×26-pin гребёнка, 43×43 мм.

Входной гаджет уровня US$5, подходит для изучения встраиваемого Linux/RTOS, не для использования в качестве десктопа; перед покупкой уточните, 64M или 256M/S — образы полностью несовместимы. Есть также производные версии сообщества, например openwrt (не входят в стандартный id дистрибутива).

  • Debian Сообщество sophgo-sg200x-debian от Fishwaldo/scpcom, покрывает 256M/S
  • Ubuntu Сообщество Образ Ubuntu 22.04 от сообщества (bassusteur)

  • Yocto / OpenEmbedded Сообщество Слой meta-milkv

Подводные камни

  • 64MB ОЗУ у Duo слишком мало: AI-приложения из образа V2 не запускаются, официально рекомендуется для 64M использовать образ V1
  • По умолчанию только сетевой адаптер USB-NCM (192.168.42.1), без DHCP; на хосте нужно вручную настроить IP в той же подсети; пароль root — milkv
  • Поддержка в mainline-ядре неполная: minimal вошёл с 6.7, GPIO — с 6.8, clock/SPI/I2C/MMC/USB — только с 6.9–6.10, camera/VPU/NPU/часть clock всё ещё на review
  • Duo 256M/S имеет ядро ARM Cortex-A53; образы RISC-V и ARM нельзя прошивать вперемешку
  • HDMI нет, у Duo S тоже только MIPI DSI; для подключения экрана нужно отдельно покупать переходную плату
  • У Duo S есть переключатель BOOT: при неверном положении не войти в режим загрузки/прошивки; питание только 5V/1A, не подключайте мощное зарядное устройство
