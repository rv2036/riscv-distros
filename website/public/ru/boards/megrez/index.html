Megrez — первая серийная плата Mini-ITX на EIC7700X; на том же чипе есть SiFive HiFive Premier P550 (дороже, официальная поддержка Ubuntu лучше).

Дистрибутивы

  • Debian Официально RockOS (оптимизированная версия Debian от PLCT для серии EIC77)
  • Fedora Официально Образ Fedora 41 собран Fedora-V Force (FVF), не является официальным образом Fedora
  • Gentoo Сообщество В wiki Gentoo есть страница установки Megrez (поддерживается сообществом)

Подводные камни

  • Заводская частота CPU по умолчанию 1.4GHz/800mV; чтобы достичь 1.8GHz, нужно вручную настроить частоту по документации, иначе производительность ниже заявленной
  • При первом запуске разделы не расширяются автоматически, корневой раздел всего 6GB; необходимо вручную расширить через gparted, иначе он быстро заполнится/перезагрузка не дойдёт до рабочего стола
  • Образ Fedora от Fedora-V Force (F41), не официальная сборка Fedora; официального образа Ubuntu нет
  • Публичных розничных каналов нет (на официальном сайте осталось только Contact us); в 2026 году фактически трудно купить
