  • Виртуальная машина QEMU virt Официально Официально предоставляется пакет u-boot-qemu; QEMU — стандартный путь разработки

  • Zhihe A210 (плата разработки XuanTie MelonPi) Частично Официального пакета u-boot нет

  • Milk-V Megrez (ESWIN EIC7700X) Частично Официального пакета u-boot нет
  • Milk-V Titan (UltraRISC DP1000) Частично Официального пакета u-boot нет
  • Milk-V Pioneer (серверный, SG2042) Частично Официального пакета u-boot нет
  • Orange Pi RV2 (Ky X1) Частично Плата SpacemiT K1, возможно, использует u-boot-spacemit — не подтверждено

Подводные камни

  • Официальный u-boot покрывает только пять категорий: qemu / starfive / spacemit / unleashed / unmatched; для остальных плат загрузчик нужно готовить самостоятельно
  • musl libc + busybox: предварительно собранные бинарники, зависящие от glibc, не запустятся
  • Официальная wiki (wiki.alpinelinux.org) возвращает 403 при автоматизированном доступе; детали RISC-V можно вывести только из страниц packages/downloads
