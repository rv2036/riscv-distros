Коротко

RISC-V-ветка китайской настольной ОС, покрытие плат разорвано по версиям (3.0 поддерживает только K3/V100). Подходит для оценки китайского настольного стека, не подходит как повседневная система для старых плат TH1520/K1.

Основа
Собственная сборка (deb/APT + собственные репозитории, рабочий стол UKUI); в 3.0 используется ядро Linux 7.0, 2.0 SP2 — долгосрочная стабильная версия
Апстрим
Независимый дистрибутив: сообщество openKylin само создаёт репозиторий deb и рабочий стол UKUI, официально позиционируется как независимая корневая ОС сообщества, а не прямой производный от Ubuntu/Debian; RISC-V адаптируется силами openKylin RISC-V SIG.

Подводные камни

  • Образы RISC-V в 3.0 охватывают только SpacemiT K3 (Server/Embedded) и V100; LicheePi 4A / Pioneer остаются на 2.0 SP2
  • Образы RISC-V собираются под конкретную плату, а не как универсальный ISO, поэтому нужно выбирать соответствующий; только 2.0 SP2 предоставляет образ RVA23 qemu
  • Образы RISC-V в 3.0 ориентированы на серверы/встраиваемые системы (Server, Embedded) и не равны настольному опыту
  • Ссылки на скачивание ведут через download-smp.php?id=xxx, реальные файлы находятся на cdimage.openkylin.top
  • Документация в основном на китайском, англоязычный сайт документации практически пустой; вопросы по RISC-V решаются в основном через китайское сообщество/SIG
