Коротко

Самый красивый по оформлению рабочего стола китайский дистрибутив, но ветка RISC-V — это общественный предпросмотр с tar.xz по платам: подходит для оценки/первого знакомства, не рекомендуется как единственная повседневная система.

Основа
На базе Debian + собственные репозитории deepin (deepin 25 «crimson»); ядро по платам 6.6/6.12/6.16, для DP1000 используется mainline-ядро
Апстрим
Дистрибутив с downstream-кастомизацией: общественная версия deepin наследует пакеты Debian и добавляет собственные репозитории и систему пакетов Linglong; RISC-V поддерживается SIG deepin-ports, официально помечен как «технический предпросмотр».

Подводные камни

  • RISC-V по-прежнему в статусе технического предпросмотра (официально явно указано), стабильность и полнота недостаточны
  • Образы по платам — это tar.xz, а не ISO: нужно вручную распаковать и записать на носитель; универсальный ISO 25.2.0 требует загрузки через UEFI
  • liveimage-desktop с установщиком не создаёт пользователя по умолчанию, пароль root по умолчанию — deepin
  • Есть вариант immutable (только для чтения корень), способ модификации системы отличается от обычного
  • deepin RISC-V поддерживается только на уровне сообщества; коммерческая поддержка — через UnionTech UOS
