Коротко

База RISC-V для серверных/корпоративных сценариев, быстрее всех продвигается RVA23 + спецификация Server Platform; пользователям персональных плат разработчика, если только не нужна серверная проверка, проще с RevyOS/Bianbu.

Основа
openEuler 24.03 LTS (RPM/dnf, собственные репозитории) + ядро RVCK 6.6; для RISC-V две сборки: RVA20 и RVA23
Апстрим
Независимый дистрибутив (сам является upstream): официальная сборка сообщества openEuler (OpenAtom Foundation) для нескольких архитектур из одного источника, RISC-V портирован и поддерживается OERV SIG, а не кастомизация Debian/Ubuntu.

Подводные камни

  • Образы RVA20 и RVA23 выпускаются отдельно; для RISC-V в 24.03 LTS SP4 доступен только ISO RVA23 (каталог rva20 отсутствует)
  • Требуется прошивка UEFI/EDK2 и соответствующий DTB платы; на старых платах с U-Boot может не загрузиться
  • Документация разложена по путям версий: страница установки RISC-V доступна только по пути 24.03_LTS, по путям SP3/SP4 будет 404
  • Ориентация на серверы: по умолчанию минимальная установка, поддержка рабочего стола и мультимедиа слабее, чем у настольных дистрибутивов производителей
  • ISO everything — порядка 20 ГБ; обычному пользователю достаточно dvd/netinst
