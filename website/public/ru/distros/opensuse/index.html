Подводные камни

  • ISO публикуются автоматически как снапшоты, без тестирования перед выпуском; в официальном README.FIRST сказано: "They haven't seen any kind of testing before publishing... there are times when they are broken"
  • Доступна только rolling-версия (Tumbleweed/MicroOS), стабильной Leap нет
  • Образов для конкретных плат нет, всё зависит от прошивки UEFI/U-Boot на стороне платы
  • Официальная документация по RISC-V в основном на wiki en.opensuse.org; этот сайт возвращает 403 на автоматический сбор, машинная проверка невозможна
