Коротко

Если нужно пользовательское окружение RHEL 10 на RISC-V и не хочется связываться с аккаунтом Red Hat: в Rocky 10.3 (GA 2026-11-16) теперь есть установочные ISO, универсальный SBC-образ raw, облачные образы и репозиторий riscv64 (952 пакета в BaseOS); QEMU и VisionFive 2 официально поддерживаются с релиза, P550 — в режиме ограниченной поддержки.

Апстрим
Rocky Linux 10 официально поддерживает riscv64 (сборки riscv64gc); работу ведут Rocky AltArch SIG и сообщество Fedora RISC-V. riscv64 отнесена к Alternative Architecture: её сбой сборки не блокирует выпуск остальных архитектур.
Версии
10.3 (GA 2026-11-16): для riscv64 есть установочные ISO boot / minimal / dvd (сборка 2026-11-12/13, 10-latest обновлён 11-18), универсальный SBC-образ raw (20261112.0) и GenericCloud qcow2; репозитории BaseOS и AppStream для riscv64 доступны (952 пакета в BaseOS) · 10.2 (образы контейнеров riscv64 уже выпущены: Base / Minimal / Toolbox / UBI, сборка 2026-05-25) · 10.0 (в анонсе GA riscv64 указана как поддерживаемая архитектура)

Платы

  • Виртуальная машина QEMU virt Официально В официальном анонсе Rocky и в заметках о выпуске 10.0 QEMU указан как поддерживаемый с момента релиза (в оригинале "works out-of-the-box ... in QEMU"); теперь для установки через anaconda есть и ISO boot / minimal
  • StarFive VisionFive 2 Официально В официальном анонсе VisionFive 2 названа рекомендуемой платой (загружается со стандартным ядром EL10); работают и универсальный SBC-образ, и установочные ISO, но списка проверки по платам по-прежнему нет
  • SiFive HiFive Premier P550 Частично Официально указана как "limited support": требуется ядро от производителя, часть функций ограничена

Подводные камни

  • Установочные ISO есть, но только boot / minimal / dvd — Live-образа нет (/pub/rocky/10.3/Live/ отдаёт 404); ISO загружаются через EFI (внутри EFI/BOOT/BOOTRISCV64.EFI), поэтому платам с прямой загрузкой из U-Boot по-прежнему нужен универсальный SBC-образ raw
  • SBC-образ — универсальный «SBC-Generic» raw: разбивки по платам и списка проверки по платам нет, поэтому загрузится ли плата на JH7110, придётся проверять самому
  • riscv64 — Alternative Architecture: сбой сборки не блокирует выпуск основных архитектур, поэтому полнота пакетов — как повезёт
