"Официальность" Arch — это лишь список tested самого проекта портирования, а не официальная поддержка Arch — на странице нужно указать, что это community port.

Основа
Arch Linux
Апстрим
Arch Linux RISC-V — это портирование сообществом (archriscv.felixc.at, поддерживают Felix Yan и др.): сборка с наложением патчей на исходные пакеты Arch, в официальные репозитории Arch пока не вошла. На сайте заявлена долгосрочная цель — "riscv64 can be added to Arch Linux itself as an alternative architecture".

Подводные камни

  • Не чистый upstream: все пакеты собираются с patch поверх исходных пакетов Arch, patch поддерживаются в репозитории archriscv-packages
  • LicheePi 4A (TH1520), Milk-V Pioneer (SG2042) имеют только экспериментальное ядро в репозитории [unsupported]
  • Платы серии AX45MP в основном не работают напрямую; в оригинале официально сказано "Other boards, except those with AX45MP, may work with a BSP or custom kernel"
  • Учётная запись rootfs по умолчанию root/archriscv, после установки обязательно сменить
  • По-прежнему цель alt-архитектуры, не входит в официальные репозитории Arch
