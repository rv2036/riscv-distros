Коротко

K1/K3 платы (BPI-F3, Milk-V Jupiter, MUSE, Pico ITX) — единственная система с официальным десктоп-опытом, GNOME/LXQt из коробки, полная документация на китайском; наиболее подходящий для новичков дистрибутив от производителя.

Основа
Ubuntu 24.04 LTS (Bianbu 2.x, K1) / Ubuntu 25.04 (Bianbu 3.x, K1) / Ubuntu 26.04 (Bianbu 4.x, K3; по данным форума производителя, в официальной документации по версиям не отмечено) + ядро BSP производителя 6.6 LTS / 6.18
Апстрим
Дистрибутив с доработками от производителя: официальная OS от SpacemiT, явно указано «собрана на основе исходников сообщества Ubuntu», формат пакетов APT + deb; K1 — Ubuntu 24.04(2.x)/25.04(3.x), K3 — Ubuntu 26.04(4.x).

Подводные камни

  • Версии K1 и K3 совершенно разные: K1 — долгосрочная поддержка 2.x (Ubuntu 24.04), 3.x на не-LTS Ubuntu 25.04; K3 — только 4.x (Ubuntu 26.04)
  • K1 с RVA22 не запустит Ubuntu 26.04/Bianbu 4.x, собранные для RVA23; K3 обратно совместим с кодом RVA22
  • Образы в .zip (внутри .img), нужно распаковать и записать через dd / Etcher; для некоторых плат есть вариант UEFI — не прошейте не тот
  • Ядро BSP производителя (6.6 LTS / 6.18), а не mainline; при смене ядра собирайте по официальному репозиторию kernel
  • Образы для серии MUSE, BPI-F3, Milk-V Jupiter различаются по платам; при ошибке прошивки не загрузится; образ около 2~2.6GB
