Коротко

В основном предназначен для тестирования производителями/экосистемой: официальная позиция — «ранняя проверка» — как можно раньше выявить проблемы совместимости прошивки, семантики платформы и ядра, чтобы у производителей было меньше форков. Обычным пользователям устанавливать его обычно не нужно; для повседневного использования выбирайте дистрибутивы производителей, такие как Bianbu / RevyOS / openKylin; для бесплатного знакомства можно сначала воспользоваться его образом для QEMU.

Основа
Собственная сборка (RPM + dnf, rolling release); ядро 7.2.6 / LTS 6.18.54, тулчейн GCC 16.2 / glibc в комплекте
Апстрим
Независимый дистрибутив: RISC-V-нативный дистрибутив, инициированный и долго поддерживаемый Институтом программного обеспечения Китайской академии наук (ISCAS), с собственным набором RPM-пакетов и сборочным конвейером (SPECS/dnf), не основан на бинарных пакетах Debian/Ubuntu/openEuler.

Подводные камни

  • Rolling-релиз без LTS: ежемесячные версии могут сильно меняться и не подходят в качестве стабильной производственной основы
  • Образы выпускаются в двух вариантах — RVA20 и RVA23; при неверном выборе система не загрузится на ядрах, не поддерживающих соответствующий profile
  • Для K3 требуется комплект Ruyi Firmware (coreboot+OpenSBI+EDK2); у большинства обычных плат разработчика с U-Boot готовых образов нет
  • Установщик форматирует весь диск и по умолчанию ориентирован на серверы/рабочие станции, а не на готовый к использованию китайский рабочий стол
  • Документация полностью на английском, материалов на китайском очень мало; сообщество небольшое
