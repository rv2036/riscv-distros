Коротко

Debian — единственный независимый дистрибутив в этой подборке, включивший riscv64 в число официально поддерживаемых архитектур релиза; есть и производные системы на базе Debian для riscv64, например Deepin и RevyOS (по каждому пункту не проверялось).

Основа
Независимый
Апстрим
Начиная с Debian 13 (trixie) riscv64 является официальной архитектурой релиза — цитата из официального пресс-релиза: "This release for the first time officially supports the riscv64 architecture"; входит в основной архив deb.debian.org, а не в дополнительное дерево ports (в списке debian.org/ports у riscv64 указано 13/released).

Платы

  • Виртуальная машина QEMU virt Официально Официальный riscv64 netinst устанавливается на QEMU virt и является основной целевой платформой d-i
  • SiFive HiFive Unmatched Сообщество Универсальный образ riscv64 + загрузка через U-Boot/UEFI на плате; Debian не выпускает образы для конкретных плат
  • StarFive VisionFive 2 Сообщество То же самое; для плат JH7110 используется U-Boot от производителя, который предоставляет UEFI, после чего устанавливается универсальный образ
  • LicheePi 4A Частично Для TH1520 требуется U-Boot/ядро от производителя; в mainline Debian поддержки на уровне платы нет
  • Milk-V Meles Частично Та же платформа TH1520, ситуация аналогична LicheePi 4A
  • SpacemiT K3 (Pico-ITX / CoM260) Частично Для SpacemiT K3 требуется BSP от производителя; поддержка в mainline Debian не подтверждена
  • Zhihe A210 (плата разработки XuanTie MelonPi) Частично Для Zhihe A210 требуются прошивка/ядро от производителя, официальной поддержки Debian нет
  • Canaan K230 (Kendryte K230 / CanMV-K230) Частично Canaan K230 — SoC класса MCU, поддержка в mainline ограничена
  • Milk-V Megrez (ESWIN EIC7700X) Сообщество Платы EIC7700 могут использовать универсальный образ UEFI, в документации Debian это не подтверждено
  • Milk-V Titan (UltraRISC DP1000) Сообщество DP1000 — то же самое, в документации Debian не подтверждено
  • Milk-V Pioneer (серверный, SG2042) Сообщество SG2042 может использовать универсальный образ, в документации Debian не подтверждено
  • Orange Pi RV2 (Ky X1) Сообщество Плата SpacemiT K1, универсальный образ + U-Boot на плате
  • Banana Pi BPI-F3 (SpacemiT K1) Сообщество Плата SpacemiT K1, универсальный образ + U-Boot на плате

Подводные камни

  • Публикуются только универсальные образы riscv64 (netinst/ISO), образов для конкретных плат нет; возможность загрузки зависит от прошивки U-Boot/UEFI на стороне платы
  • Официальное руководство по установке содержит оговорку: "This installation guide has not been fully updated and fact checked for riscv64", часть разделов может быть устаревшей
  • Установка netinst требует подключения к сети для загрузки пакетов
