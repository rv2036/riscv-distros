Во многом благодаря ему китайские платы RISC-V «работают из коробки»; для новых плат вроде K3/BPI-F3 смотрите в первую очередь на него.

Основа
Debian/Ubuntu (фреймворк сборки Armbian)
Апстрим
Официальный фреймворк сборки (armbian/build) напрямую собирает образы riscv64, платы классифицируются по уровням Platinum/Standard/Community; для плат RISC-V на официальном сайте есть отдельная страница загрузки и список образов.

Подводные камни

  • Многие платы всё ещё привязаны к ядру производителя (6.6.x Bianbu), степень перехода на mainline различается
  • Платы уровня Community имеют только один CLI-образ, десктоп/обновления — за счёт сообщества
  • Нет плат Meles / Pioneer / Megrez / K230 и др.
  • Один и тот же номер версии на разных платах соответствует разным версиям ядра — не указывайте жёстко в документации
