  • Для большинства плат сначала нужно подготовить U-Boot уровня платы, с универсального образа не загрузится
  • Только RV64/SV39, rv32 — это другой port
  • tier 2: уровень выпуска и поддержки ниже, чем у x86/arm
  • Документация по платам разрозненна, многое приходится искать в списках рассылки
