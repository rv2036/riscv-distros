Коротко

У Fedora есть официальный SIG RISC-V с непрерывными сборками, но riscv64 по-прежнему помечен как «not officially supported», а образы публикуются в канале alt. В повседневной работе это не мешает, однако уровень поддержки не тот же, что у Debian или Ubuntu.

Апстрим
Официальная wiki Fedora, оригинал: "riscv64 is currently not an officially supported Fedora architecture". Образы поддерживаются Fedora RISC-V SIG и размещены на dl.fedoraproject.org/pub/alt/risc-v/ (дерево alt, не основная архитектура), не участвуют в release blocking.

Подводные камни

  • Для большинства плат необходимо использовать ядро Omni (...riscv64.omni.fcXX); стандартное ядро 7.x покрывает только VisionFive 2 / Orange Pi RV / Milk-V Mars и подобные; в оригинале: "Most boards can only boot when using the Omni kernel"
  • В ядре Omni всё ещё есть патчи, не принятые в upstream (в оригинале: "Some patches in this kernel are still under review upstream")
  • Подходит только для headless: mainline не содержит драйвера встроенной графики SoC, официальное позиционирование — сборочная машина/сервер ("video output are pretty much completely ignored")
  • Для установки требуется последовательная консоль (Requirements → Serial console access)
  • Некоторые пакеты требуют патчей специально для RISC-V, всё ещё есть расхождения с исходным кодом upstream
