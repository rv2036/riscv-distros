Коротко

Фактически стандартная система для плат TH1520: LicheePi 4A, Milk-V Meles — заводская/официальная прошивка по умолчанию RevyOS. Первый выбор для новичков, но учтите: зеркало новее документации — берите самую свежую дату в каталоге зеркала.

Основа
rootfs Debian 13 (trixie) + кастомное ядро 6.6 XuanTie (BSP TH1520/SG2042); старая версия 20240720 — Debian 12 + ядро 5.10
Апстрим
Дистрибутив с downstream-кастомизацией: поддерживается PLCT Lab (Институт программного обеспечения КАН) для экосистемы XuanTie/T-Head, использует репозиторий пакетов Debian 13 (trixie) + кастомное ядро XuanTie; это не официальный port Debian и не независимая система пакетов.

Подводные камни

  • Номер версии — это дата (YYYYMMDD), а не семантическая версия; страница официальной документации долго отстаёт от зеркала (в документации указано 20251226, на зеркале уже есть 20260504)
  • При обновлении с 20240720 и более ранних версий необходимо сбросить переменные окружения U-Boot (env default -a -f; env save; reset), иначе система не загрузится
  • У некоторых SD-карт есть проблемы совместимости с LicheePi 4A; официально ведётся список совместимых SD-карт, рекомендуется отдавать предпочтение eMMC
  • Каталоги 20260926/20260924 — это прошивка coreboot+EDK2 (без U-Boot), а не образ системы; при штатной частоте 1.84GHz обязательно охлаждение
  • GPU/NPU зависят от стека драйверов BSP производителя (также есть revyos-gles-21, документация NPU), не всё вошло в mainline
