Коротко

Ubuntu — дистрибутив с самой детальной поддержкой на уровне платы: официально выпускает preinstalled образы для каждой платы, но с 26.04 поднимает планку до RVA23, и старые платы остаются на 24.04 LTS.

Апстрим

Подводные камни

  • Начиная с 26.04 LTS требуется RVA23S64: оборудование без RVA23 (VisionFive 2/JH7110, SiFive Unmatched и др.) может использовать только 24.04.5 LTS, официальная формулировка "Hardware that is not RVA23-ready continues to be supported by our 24.04.5 LTS release"
  • Образы некоторых плат поддерживают только headless (без GPU, без WiFi), официальная страница прямо указывает это в записи DeepComputing FML13V01
  • Образы для конкретных плат различаются по суффиксу +<board> (+unmatched/+jh7110/+icicle/+nezha/+licheerv/+pic64gx), при скачивании неверного образа система не загрузится
