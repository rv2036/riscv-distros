Подводные камни

  • Это система сборки: нет бинарного репозитория, нет пакетного менеджера, установка ПО = пересборка прошивки
  • Первая полная сборка занимает от десятков минут до нескольких часов и требует десятков ГБ
  • По умолчанию BusyBox без рабочего стола; для графики нужно включать пакеты самостоятельно
  • Результат — wic/img, обновление только полной перезаписью диска
