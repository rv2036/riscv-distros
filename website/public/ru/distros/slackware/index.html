Коротко

Старым пользователям Slack, желающим продлить жизнь на RISC-V, можно попробовать slarm64; новичкам не стоит браться.

Основа
Независимый (pkgtools + slackpkg, init в стиле BSD)
Апстрим
Официальный Slackware 15.0 выпускается только для x86_64 (на slackware.com есть отдельный официальный ARM-проект arm.slackware.com); RISC-V обеспечивается неофициальным портом slarm64 (sndwvs), который следует за 15.0/current и предоставляет пакеты и образы для конкретных плат.

15.0 (официальный, x86_64) · slarm64-riscv64-current / slarm64-riscv64-15.0 (неофициальный порт)

Подводные камни

  • Официальной поддержки нет, всё зависит от slarm64, поддерживаемого одним человеком
  • Нет installer: нужно вручную устанавливать из дерева пакетов через chroot или напрямую записывать образ для конкретной платы
  • slackware.com возвращает 403 на скриптовые запросы (Akamai), версию нужно смотреть через зеркала
  • Документация — только README и сообщения на форуме, материалов на китайском почти нет
