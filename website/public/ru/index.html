Эта страница — про то, как сначала просто запустить систему. Поддержка RISC-V разбросана по вики разных проектов, постам на форумах и README на GitHub, и новичок чаще всего спотыкается на трёх шагах: скачал не тот образ, взял не ту версию U-Boot, не подключил последовательный порт. Мы собрали в одном месте дистрибутивы, платы разработчика и отношения поддержки между ними; у каждой записи указана дата проверки и источник.

Порядок действий — в разделе С чего начать , проверить конкретную пару «плата + дистрибутив» можно в матрице поддержки , а если что-то не работает, сначала загляните в «подводные камни» на страницах дистрибутива и платы.

У каждого утверждения есть дата проверки и источник; полный список и методика — в разделе Источники .

Дистрибутивы, которые действительно поддерживают RISC-V

Все →

Debian

Официальная архитектура

ОсноваНезависимый

Debian — единственный независимый дистрибутив в этой подборке, включивший riscv64 в число официально поддерживаемых архитектур релиза; есть и производные системы на базе Debian для riscv64, например Deepin и RevyOS (по каждому пункту не проверялось).

Ubuntu

Официальная архитектура

ОсноваDebian

Ubuntu — дистрибутив с самой детальной поддержкой на уровне платы: официально выпускает preinstalled образы для каждой платы, но с 26.04 поднимает планку до RVA23, и старые платы остаются на 24.04 LTS.

Fedora

Порт сообщества

ОсноваНезависимый

У Fedora есть официальный SIG RISC-V с непрерывными сборками, но riscv64 по-прежнему помечен как «not officially supported», а образы публикуются в канале alt. В повседневной работе это не мешает, однако уровень поддержки не тот же, что у Debian или Ubuntu.

Fedora-V Force (FVF)

Дистрибутив вендора

ОсноваFedora

FVF — это образы RISC-V, пересобранные из исходников Fedora отдельной командой, а не официальный релиз Fedora. Они покрывают больше плат, чем образы официального SIG, поэтому практичны, если нужен готовый к загрузке Fedora-пользовательский слой.

RevyOS

Дистрибутив вендора

Основаrootfs Debian 13 (trixie) + кастомное ядро 6.6 XuanTie (BSP TH1520/SG2042); старая версия 20240720 — Debian 12 + ядро 5.10

Фактически стандартная система для плат TH1520: LicheePi 4A, Milk-V Meles — заводская/официальная прошивка по умолчанию RevyOS. Первый выбор для новичков, но учтите: зеркало новее документации — берите самую свежую дату в каталоге зеркала.

Bianbu

Дистрибутив вендора

ОсноваUbuntu 24.04 LTS (Bianbu 2.x, K1) / Ubuntu 25.04 (Bianbu 3.x, K1) / Ubuntu 26.04 (Bianbu 4.x, K3; по данным форума производителя, в официальной документации по версиям не отмечено) + ядро BSP производителя 6.6 LTS / 6.18

K1/K3 платы (BPI-F3, Milk-V Jupiter, MUSE, Pico ITX) — единственная система с официальным десктоп-опытом, GNOME/LXQt из коробки, полная документация на китайском; наиболее подходящий для новичков дистрибутив от производителя.

openEuler

Официальная архитектура

ОсноваopenEuler 24.03 LTS (RPM/dnf, собственные репозитории) + ядро RVCK 6.6; для RISC-V две сборки: RVA20 и RVA23

База RISC-V для серверных/корпоративных сценариев, быстрее всех продвигается RVA23 + спецификация Server Platform; пользователям персональных плат разработчика, если только не нужна серверная проверка, проще с RevyOS/Bianbu.

openKylin

Официальная архитектура

ОсноваСобственная сборка (deb/APT + собственные репозитории, рабочий стол UKUI); в 3.0 используется ядро Linux 7.0, 2.0 SP2 — долгосрочная стабильная версия

RISC-V-ветка китайской настольной ОС, покрытие плат разорвано по версиям (3.0 поддерживает только K3/V100). Подходит для оценки китайского настольного стека, не подходит как повседневная система для старых плат TH1520/K1.

deepin

Дистрибутив вендора

ОсноваНа базе Debian + собственные репозитории deepin (deepin 25 «crimson»); ядро по платам 6.6/6.12/6.16, для DP1000 используется mainline-ядро

Самый красивый по оформлению рабочего стола китайский дистрибутив, но ветка RISC-V — это общественный предпросмотр с tar.xz по платам: подходит для оценки/первого знакомства, не рекомендуется как единственная повседневная система.

Виртуальная платформа

нет (универсальная виртуальная платформа QEMU, настраивается RV32/RV64, до 512 ядер) · QEMU Project

Чисто виртуальная платформа: до 512 ядер RV64GC, CLINT/PLIC, хост-мост PCIe, 8 virtio-mmio, NS16550 UART, опционально AIA/IOMMU; ОЗУ, накопитель и сеть полностью виртуализируются параметрами командной строки, реальных GPU/VPU/NPU нет.
