可用发行版

  • Ubuntu 官方支持 Ubuntu 24.04 Server/GNOME（厂商 6.6 内核，orangepi-build 可自编）
  • Armbian 社区可用 Armbian 提供 Debian/Ubuntu 构建
  • Debian 社区可用 经 Armbian 提供
  • Arch Linux RISC-V 社区可用 BredOS（Arch 衍生）在官网列为第三方镜像

坑

  • Ubuntu 24.04 是厂商 6.6 内核（orange-pi-6.6-ky），不是 mainline，升级内核需谨慎
  • “2 TOPS”是 CPU 融合算力，没有独立 NPU，跑大模型只能靠 CPU/RVV
  • 8 核实际性能仍偏低（Phoronix/多方评测：不及同期 4 核 ARM 板），不适合当桌面主力
  • 官方镜像托管在 Google Drive，国内下载不便；eMMC 需另购模块
