K1 是 2024-2025 出货量最大的高性能 RISC-V SBC 芯片之一，BPI-F3 生态最杂（官方 Bianbu + 社区 Armbian/Fedora/openSUSE/Arch/Gentoo 都有镜像）。RuyiSDK 支持矩阵也收录了 BPI-F3。

可用发行版

  • Bianbu 官方支持 官方主推 Bianbu（SpacemiT K1 镜像，v1.0.7 起支持 16GB）
  • Armbian 社区可用 Armbian 标准支持，提供 Debian/Ubuntu 镜像（仅 SD 启动）
  • Debian 社区可用 经 Armbian 提供
  • Ubuntu 社区可用 经 Armbian 提供（非 Canonical 官方）
  • Fedora 社区可用 Banana Pi 文档页挂出的第三方镜像
  • openSUSE 社区可用 同上，第三方镜像
  • Arch Linux RISC-V 社区可用 同上，第三方镜像
  • Gentoo 社区可用 同上，第三方镜像

坑

  • Bianbu 镜像分 SD 卡版（*.img.zip）与 eMMC 版（*.zip），刷错无法启动
  • 官方只主推 Bianbu；Debian/Ubuntu 主要靠 Armbian 社区镜像，且 Armbian 仅支持 SD 启动
  • 早期 Bianbu（<v1.0.7）不支持 16GB 内存版本
  • HDMI 仅 1.4/1080p，不适合 4K 桌面
