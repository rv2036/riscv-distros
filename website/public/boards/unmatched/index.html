历史上的 RISC-V 桌面标杆，现在更适合二手捡漏/教学；新人上手成本高（串口+拨码+供电），不推荐作为第一块板。 另有 openwrt 等社区衍生版（未列入标准发行版 id）。

可用发行版

  • Ubuntu 官方支持 Canonical 官方 preinstalled 镜像 ubuntu-24.04.5-...+unmatched.img.xz，仍在 24.04 LTS 支持范围内
  • Buildroot 官方支持 SiFive Freedom U SDK（FUSDK，Buildroot/Yocto 混合）是厂商参考系统，含 U-Boot/OpenSBI
  • Debian 社区可用 Debian 官方 riscv64 安装器可用，Debian wiki 有该板专页
  • Fedora 社区可用 Fedora RISC-V 长期把 Unmatched 列为参考板
  • openSUSE 社区可用 openSUSE Ports 提供 riscv64；官网 403，未验证该板镜像
  • FreeBSD 社区可用 FreeBSD/riscv 支持 Unmatched
  • OpenBSD 社区可用 OpenBSD/riscv64 社区报告可用
  • Gentoo 社区可用 Gentoo RISC-V 项目覆盖 U74 平台
  • Armbian 部分可用 曾有社区镜像，Armbian 官网现已下架该板页面
  • openEuler 社区可用 openEuler RISC-V SIG 有面向该板的镜像
  • openKylin 社区可用 openKylin RISC-V 版本曾支持
  • deepin 社区可用 deepin RISC-V 移植版可用

坑

  • 没有板载显示输出，必须插 PCIe 显卡或用串口；调试必须接 USB-UART(FTDI) 才能看到 OpenSBI/U-Boot 日志
  • 12V/6A 桶形电源，供电不足会随机重启或 DDR 训练失败
  • 启动介质由 MSEL 拨码决定（SD/SPI Flash），拨错直接不启动；SPI 固件损坏要靠 JTAG 恢复
  • 官方已停产，Ubuntu 24.04 是最后一个受支持的 LTS 镜像，内核偏旧，新发行版基本不再出该板镜像
  • PCIe 显卡需外接供电，部分卡在 U-Boot 阶段没有输出，要等 Linux 起来才亮
