硬件做工好、cape 生态强，但软件是 TH1520 三兄弟里最差的：官方镜像三年没更新，只适合当收藏/教学。

可用发行版

  • Ubuntu 官方支持 官方唯一 Linux 桌面镜像 xuantie-ubuntu-23.04-20230705（Ubuntu 23.04 已 EOL）
  • Yocto / OpenEmbedded 官方支持 官方 Yocto 生产镜像 2023-06-10，出厂预装
  • RevyOS 社区可用 RevyOS 的 beagle 目录停在 20231210，之后没再更新
  • Fedora 社区可用 Fedora-V Force 提供 BeagleV Ahead 镜像
  • Debian 部分可用 主线 Debian 没有官方安装器支持，只能自建 rootfs

坑

  • 官方镜像停在 2023 年（Ubuntu 23.04 / Yocto 2023-06），Ubuntu 23.04 早已 EOL，apt 源基本不可用
  • RevyOS 的 beagle 镜像也停在 20231210，等于没有持续维护的发行版
  • 刷 eMMC 需要 USB-C 进 fastboot + Xuantie 专用工具链产物，从 SD 卡启动反而简单
  • 只有 4GB RAM，跑桌面偏紧；microHDMI 需要转接头
  • WiFi 是 AP6203BM，需要配套 firmware blob，主线内核支持不完整
  • cape 排针是 3.3V 逻辑，接 5V cape 会烧
