CanMV（MicroPython 固件）是出货量最大、资料最全的形态；Linux 侧官方主推 Buildroot。Apache NuttX 另有 CanMV-K230 板级支持（非发行版）；RuyiSDK 支持矩阵已收录 CanMV K230(D)，可 ruyi device provision 取镜像。

可用发行版

  • Buildroot 官方支持 k230_linux_sdk 默认 Buildroot 方案（k230_canmv/k230_evb defconfig）
  • Debian 官方支持 SDK 支持 make debian，官方有《K230 Debian/Ubuntu 系统指南》
  • Ubuntu 官方支持 SDK 支持 make ubuntu，同上指南

坑

  • AMP 异构：默认小核跑 Linux、大核跑 RT-Smart/CanMV；只有大核带 V 扩展，向量负载必须放对核
  • 官方 Linux 主线是 Buildroot；Debian/Ubuntu 要自己 make debian / make ubuntu 构建，无现成官方桌面镜像
  • 固件必须匹配：CanMV IDE 只认文件名以 CanMV-K230_micropython 开头的固件，刷 K230 SDK 镜像连不上
  • nncase 工具链闭源且与固件版本强绑定；早期构建文档只有中文
