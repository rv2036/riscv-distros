规格
Duo：2×C906（1GHz+700MHz）+8051，64MB SIP DRAM；Duo 256M：SG2002 加 1×Cortex-A53，256MB；Duo S：512MB + eMMC 焊盘（部分套装带 8GB）+ WiFi6；均有 100M 网口、USB-C；Duo/256M 为 26×GPIO 焊盘、21×51mm，Duo S 为 2×26-pin 排针、43×43mm。

可用发行版

  • Buildroot 官方支持 官方 V1/V2 Buildroot SDK，烧卡即用，是最稳的系统
  • Fedora 社区可用 Fedora 41 镜像（Fedora-V Force，ISCAS 镜像站）
  • Debian 社区可用 Fishwaldo/scpcom 的 sophgo-sg200x-debian，覆盖 256M/S
  • Ubuntu 社区可用 Ubuntu 22.04 社区镜像（bassusteur）
  • Arch Linux RISC-V 社区可用 社区 Arch 镜像
  • Alpine Linux 社区可用 社区 Alpine 镜像（cwt）
  • NixOS 社区可用 社区维护，功能有限
  • Yocto / OpenEmbedded 社区可用 meta-milkv 层
  • openEuler 社区可用 openEuler 有 Duo 镜像

坑

  • 64MB 的 Duo 内存太小，V2 镜像里的 AI 应用跑不动，官方明确建议 64M 用 V1 镜像
  • 默认只有 USB-NCM 网卡（192.168.42.1），没有 DHCP，主机要手动配同网段 IP；root 密码 milkv
  • 主线内核支持不完整：minimal 从 6.7、GPIO 6.8、clock/SPI/I2C/MMC/USB 6.9–6.10 才进，camera/VPU/NPU/部分 clock 仍在 review
  • Duo 256M/S 带 ARM Cortex-A53 核，RISC-V 与 ARM 镜像不能混刷
  • 没有 HDMI，Duo S 也只有 MIPI DSI；想接屏要另买转接板
  • Duo S 有 BOOT 开关，拨错进不了下载/启动模式；供电只要 5V/1A，别接快充头硬灌
