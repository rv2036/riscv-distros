规格
8×X100@2.4GHz + 8×A100 AI 核，RVA23/RVV1.0（最高 1024bit），60 TOPS 通用 AI 算力，130 KDMIPS。Pico-ITX：16/32GB LPDDR5-6400、UFS2.2 128/256GB、10GbE SFP+ + 1GbE、2×M.2（M-Key Gen3 x4 / B-Key）、2×USB3.2 Type-C（含全功能 65W PD + 4K DP）+ 4×USB2.0、100×86mm。CoM260：260pin 核心板 + 参考载板，载板与 Jetson Orin Nano 硬件兼容。

官方命名为 K3-CoM260（260pin SO-DIMM 核心板），任务中的 SOM260 即此形态；Pico-ITX 与 CoM260 共用 SoC/SDK 与系统镜像。K3 于 2026-04-30 全球开卖，2026-05 进入量产公售。

可用发行版

  • Bianbu 官方支持 出厂预装 Bianbu Desktop 3.0；archive 已到 4.0.8（2026-10-16 构建，LXQt/Minimal，含 UEFI 变体）
  • Ubuntu 官方支持 SpacemiT archive 提供 ubuntu-26.04-preinstalled-desktop-riscv64 镜像；官网规格页列 Ubuntu 26.04
  • Debian 官方支持 Debian 13 GNOME/XFCE/Minimal 镜像（2026-07-30 构建）
  • Buildroot 官方支持 官方 SDK 提供 buildroot 配置与镜像
  • openKylin 官网规格页称支持 OpenKylin，未见公开镜像下载
  • deepin 官网规格页称支持 Deepin，未见公开镜像下载
  • Fedora 官网规格页称支持 Fedora，未见 K3 专用官方镜像
  • RHEL RISC-V Developer Preview 官方支持

坑

  • 出厂 Bianbu 4.0.4 用厂商内核 6.18.3-generic，非 mainline；K3 参考设计与 SDK 自 2026-05 起分批释放，文档与硬件验证同步推进
  • 16 核枚举但单任务最多调度 8 核，KVM/虚拟机实测不可用（TinyComputers 2026-09 评测）
  • 评测中万兆 SFP+ 未 link，仅千兆口可用；10GbE 驱动/光模块兼容需实测
  • 渠道价差极大且需自付关税；Milk-V Jupiter2 文档目前仍是 stub，主要靠 SpacemiT 官方文档
