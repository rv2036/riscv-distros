型号消歧：芯片是知合计算 A210（阿基米德系列，玄铁 C920/C908 核），开发板品牌写作“玄铁 MelonPi”。Ubuntu 镜像只覆盖 A200（a200-evb），A210 不通用。

可用发行版

  • Debian 官方支持 a210-evb 桌面 Debian 预编译镜像（SDK v2.9.0）
  • Buildroot 官方支持 zhihe_a210_defconfig，官方 Buildroot SDK

坑

  • 无零售渠道与公开报价，开发板以评估/合作渠道为主，普通开发者难买到
  • A210 与 A200 镜像不通用：官方 Ubuntu 只给 A200，A210 只有 Debian/Buildroot
  • GitHub/Gitee 无官方 BSP 仓库（检索 0 结果），内核与驱动以厂商 SDK 包形式发布，社区几乎无第三方发行版支持
  • 厂商数据：单芯片 DeepSeek-7B 约 8 tok/s，4 die 级联 25 tok/s，实际以自测为准
