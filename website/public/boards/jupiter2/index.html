坑

  • 10GbE 是 SFP+ 光口，不是 RJ45：普通交换机要么插光模块，要么用那唯一的 GbE 电口
  • 双显示走 USB-C 的 DP Alt Mode 与 eDP，没有标准 HDMI 口
  • 出厂预装 Bianbu（RuyiSDK 记录为 4.0.1 Desktop）；重装时先确认镜像对应 Jupiter2，而不是通用 K3 镜像
  • 官方页不标价，价格与零售渠道未核实
