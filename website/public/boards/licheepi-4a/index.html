TH1520 里资料最全、社区最大的板；RevyOS 桌面可用，但 GPU/NPU 闭源是硬伤。 另有 openwrt 等社区衍生版（未列入标准发行版 id）。

可用发行版

  • RevyOS 官方支持 官方主推，最新系统镜像 20251226（Debian 系 + kernel 6.6）
  • Debian 部分可用 主线 Debian 13 能在 LPi4A 启动，但需自备 U-Boot/DTB，没有官方安装器镜像
  • Ubuntu 部分可用 只有 ubuntu-base rootfs，需自行配内核与引导
  • Fedora 社区可用 Fedora-V Force 提供 TH1520 镜像
  • Arch Linux RISC-V 社区可用 archriscv 支持 TH1520
  • Armbian 社区可用 Armbian 官方支持 LicheePi 4A
  • Gentoo 社区可用 Gentoo wiki 有 TH1520 专页
  • NixOS 社区可用 社区仓库 nixos-licheepi4a（复用 RevyOS 内核/U-Boot）
  • openEuler 社区可用 openEuler RISC-V SIG 提供镜像
  • openKylin 社区可用 社区 openKylin 镜像
  • deepin 社区可用 deepin RISC-V 移植版
  • Buildroot 部分可用 RevyOS 用 Buildroot 构建 boot/rootfs

坑

  • GPU 是 Imagination BXM-4-64，只有厂商闭源 blob，主线内核下没有 GPU 加速；NPU 需要 T-Head 专用 SDK
  • 2023.8.1 之前出货的 16GB 批次 U-Boot 识别内存有 bug，必须刷 16G 专用 u-boot，否则大内存应用会崩
  • 刷机要按住 BOOT 键再上电进 fastboot（USB 2345:7654），普通上电进不了下载模式
  • 从 ≤20240720 的 RevyOS 升级，必须先 `env default -a -f; env save` 重置 U-Boot 环境变量
  • 8GB 与 16GB 版本的 boot.ext4 设备树不同，混刷会起不来
  • 2026-09 起 RevyOS 在推 coreboot+EDK2 新固件（取代 U-Boot SPL），属于实验性质，刷前确认板型
