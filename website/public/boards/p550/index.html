可用发行版

  • Ubuntu 官方支持 Ubuntu 24.04 预装，SiFive 发布 2025.11.00（内核 6.12.33）
  • Fedora 官方支持 Fedora 42 起支持，Fedora 44 起走 Omni 内核
  • Yocto / OpenEmbedded 官方支持 freedom-u-sdk Yocto BSP（含 bootchain 固件）
  • Debian 社区可用 SiFive 博客称已推进 Debian 支持，需自行准备镜像

坑

  • 固件必须与镜像版本匹配：bootchain 过旧时 Fedora 直接不启动，需先刷最新 firmware
  • 无原生 NVMe 槽，只能插 PCIe 转接卡；板载只有 2×GbE
  • iGPU 只支持 OpenGL ES，OpenGL 需 MESA_LOADER_DRIVER_OVERRIDE=zink；接独显时 GRUB 菜单不显示
  • 国内无正规渠道，需 Arrow 等海外代理，运费/关税另计
