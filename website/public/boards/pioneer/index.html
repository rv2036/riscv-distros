唯一能当「RISC-V 工作站/服务器」用的板子，价格与功耗都是另一个量级；适合做 64 核并行编译、CI runner，不适合入门。 另有 opencloudos 等社区衍生版（未列入标准发行版 id）。

可用发行版

  • RevyOS 官方支持 当前官方主推，RevyOS 20260504 提供 pioneer/pisces 两套固件与镜像
  • Fedora 官方支持 Milk-V 官方文档以 Fedora 38 为安装示例，Fedora RISC-V 支持 SG2042
  • openEuler 社区可用 openEuler RISC-V SIG 面向服务器场景支持 SG2042
  • openKylin 社区可用 openKylin 有 RISC-V 服务器镜像
  • deepin 社区可用 deepin RISC-V 移植版
  • Debian 部分可用 debian-ports 有 riscv64 基础包，但没有官方 Pioneer 镜像
  • Ubuntu 部分可用 无 Canonical 官方镜像，需自行搭 rootfs

坑

  • Milk-V 文档的 Download 页 Image 区已空（迁移到 RevyOS），别在旧页面找系统镜像
  • 内存挑条：必须按官方 DDR 支持列表选 RDIMM/UDIMM，否则 DDR 训练失败不开机
  • 需要标准 ATX 24-pin + CPU 8-pin 供电，散热器必须装（120W 典型功耗）
  • 没有板载显示输出，需要 PCIe 显卡；部分显卡在 LinuxBoot/U-Boot 阶段无输出
  • 固件（LinuxBoot/EDK2 + MCU）升级有变砖风险，必须按官方顺序刷
  • 早期批次 ASM2824 PCIe switch 有兼容性问题，先查 buglist
