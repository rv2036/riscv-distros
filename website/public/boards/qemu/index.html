规格
纯虚拟平台：最多 512 个 RV64GC 核、CLINT/PLIC、PCIe 主机桥、8 个 virtio-mmio、NS16550 UART、可选 AIA/IOMMU；内存、磁盘、网络全部由命令行参数虚拟，无真实 GPU/VPU/NPU。

所有板子的公共起点：先在 virt 上验证内核/rootfs，再上真机，能省掉大量刷机排错时间。

可用发行版

  • Debian 官方支持 Debian 13 起 riscv64 为正式架构，官方 netinst ISO 可直接装进 virt
  • Ubuntu 官方支持 官方 riscv64 cloud image，配 EDK2(pflash) 或 -kernel 启动
  • Fedora 社区可用 Fedora RISC-V 提供 QEMU 安装说明与镜像
  • Alpine Linux 官方支持 只有 riscv64 minirootfs，无 virt ISO，需自备内核/initramfs
  • Arch Linux RISC-V 官方支持 archriscv 提供 riscv64 ISO，可在 QEMU 启动
  • openSUSE 社区可用 openSUSE Ports 提供 riscv64；官网对 curl 返回 403，未验证直链
  • Gentoo 官方支持 stage3 riscv64 + 手册支持 QEMU 系统
  • Void Linux 部分可用 有 riscv64 端口，QEMU 镜像需自行构建
  • NixOS 社区可用 riscv64 非官方支持等级，需交叉构建
  • ALT Linux 官方支持 ALT Ports riscv64 提供 QEMU 镜像
  • FreeBSD 官方支持 riscv64 支持 QEMU virt
  • NetBSD 官方支持 riscv64 端口支持 QEMU
  • OpenBSD 官方支持 riscv64 支持 QEMU virt
  • openEuler 官方支持 openEuler RISC-V SIG 提供 QEMU 镜像
  • Buildroot 官方支持 qemu_riscv64_virt_defconfig，一行 make 起系统
  • Yocto / OpenEmbedded 官方支持 qemuriscv64 machine 官方支持

坑

  • -bios default 只加载 OpenSBI，没有 U-Boot/EDK2；启动 Ubuntu/Fedora cloud image 需用 pflash 加载 32MiB EDK2 固件，否则黑屏
  • virt 没有 GPU/VPU/NPU，别用它验证图形、视频硬解或 AI 加速
  • 串口固定是 ttyS0；-nographic 模式退出要按 Ctrl-A 再按 X
  • Ubuntu 26.04 起要求 RVA23S64，旧版 QEMU 缺扩展会起不来；24.04 仍是 RVA20 基线
  • Alpine riscv64 只发 minirootfs，没有 virt ISO，需要自己准备内核和 initramfs
