TH1520 の中で資料が最も揃い、コミュニティも最大のボードです。RevyOS ならデスクトップが使えますが、GPU/NPU がクローズドソースなのが痛いところです。ほかに openwrt などのコミュニティ派生版もあります（標準のディストリビューション id には入れていません）。

使えるディストロ

  • RevyOS 公式対応 公式の主力。最新システムイメージは 20251226（Debian 系 ＋ kernel 6.6）
  • Debian 一部のみ メインライン Debian 13 は LPi4A で起動できますが、U-Boot/DTB を自分で用意する必要があり、公式インストーライメージはありません
  • Ubuntu 一部のみ ubuntu-base の rootfs だけで、カーネルとブートローダーは自分で用意します
  • Fedora コミュニティ対応 Fedora-V Force が TH1520 イメージを提供
  • Arch Linux RISC-V コミュニティ対応 archriscv が TH1520 に対応
  • Armbian コミュニティ対応 Armbian が LicheePi 4A を公式サポート
  • Gentoo コミュニティ対応 Gentoo wiki に TH1520 専用ページあり
  • NixOS コミュニティ対応 コミュニティリポジトリ nixos-licheepi4a（RevyOS のカーネル／U-Boot を再利用）
  • openEuler コミュニティ対応 openEuler RISC-V SIG がイメージを提供
  • openKylin コミュニティ対応 コミュニティの openKylin イメージ
  • deepin コミュニティ対応 deepin の RISC-V 移植版
  • Buildroot 一部のみ RevyOS は Buildroot で boot/rootfs をビルドしています

つまずきどころ

  • GPU は Imagination BXM-4-64 で、ベンダーのクローズド blob しかありません。メインラインカーネルでは GPU アクセラレーションが効きません。NPU には T-Head 専用 SDK が必要です
  • 2023.8.1 より前に出荷された 16GB ロットは U-Boot のメモリ認識にバグがあり、16G 専用の u-boot を書き込まないと大容量メモリを使うアプリが落ちます
  • 書き込みは BOOT ボタンを押したまま電源を入れ、fastboot（USB 2345:7654）に入ります。通常の電源投入ではダウンロードモードに入りません
  • 20240720 以前の RevyOS からアップグレードする場合は、先に `env default -a -f; env save` で U-Boot の環境変数をリセットする必要があります
  • 8GB 版と 16GB 版では boot.ext4 のデバイスツリーが異なり、混ぜて書き込むと起動しません
  • 2026-09 から RevyOS は coreboot+EDK2 の新ファームウェア（U-Boot SPL の置き換え）を進めています。実験的な扱いなので、書き込む前にボードの型を確認してください
