仕様
Duo：2×C906（1GHz＋700MHz）＋8051、64MB SIP DRAM。Duo 256M：SG2002 に 1×Cortex-A53 を追加、256MB。Duo S：512MB ＋ eMMC パッド（セットによっては 8GB）＋ WiFi6。いずれも 100M ネットポート、USB-C。Duo/256M は 26×GPIO パッド、21×51mm。Duo S は 2×26-pin ピンヘッダ、43×43mm。

つまずきどころ

  • 64MB の Duo はメモリが小さすぎて、V2 イメージの AI アプリは動きません。公式も 64M では V1 イメージを使うよう明確に勧めています
  • 既定では USB-NCM のネットワークインターフェース（192.168.42.1）だけで DHCP がありません。ホスト側で同じサブネットの IP を手動設定します。root パスワードは milkv です
  • メインラインカーネルの対応は不完全です。minimal が 6.7、GPIO が 6.8、clock/SPI/I2C/MMC/USB が 6.9〜6.10 で入り、camera/VPU/NPU と一部の clock は今もレビュー中です
  • Duo 256M/S は ARM Cortex-A53 コアを積んでおり、RISC-V と ARM のイメージを混ぜて書き込むことはできません
  • HDMI はなく、Duo S も MIPI DSI のみです。画面を繋ぐには変換ボードを別途買う必要があります
  • Duo S には BOOT スイッチがあり、間違えるとダウンロード／起動モードに入れません。給電は 5V/1A で十分なので、急速充電器を繋いで無理に流さないでください
