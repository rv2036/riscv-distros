公式名称は K3-CoM260（260pin SO-DIMM コアボード）で、タスク中の SOM260 はこの形態を指します。Pico-ITX と CoM260 は SoC/SDK とシステムイメージを共有します。K3 は 2026-04-30 に世界発売、2026-05 から量産販売に入りました。

使えるディストロ

  • Bianbu 公式対応 出荷時は Bianbu Desktop 3.0 をプリインストール。archive は 4.0.8 まで来ています（2026-10-16 ビルド、LXQt/Minimal、UEFI 変体あり）
  • Ubuntu 公式対応 SpacemiT の archive が ubuntu-26.04-preinstalled-desktop-riscv64 イメージを提供。公式仕様ページにも Ubuntu 26.04 が記載されています
  • Debian 公式対応 Debian 13 の GNOME/XFCE/Minimal イメージ（2026-07-30 ビルド）

つまずきどころ

  • 出荷時の Bianbu 4.0.4 はベンダーカーネル 6.18.3-generic で、メインラインではありません。K3 のリファレンス設計と SDK は 2026-05 から段階的に公開され、ドキュメントとハードウェア検証が並行して進んでいます
  • 16 コアと列挙されますが、1 タスクが同時に使えるのは最大 8 コアです。KVM／仮想マシンは実測で使えませんでした（TinyComputers 2026-09 のレビュー）
  • レビューでは 10 ギガビット SFP+ が link せず、使えたのはギガビットポートだけでした。10GbE のドライバ／光モジュールの互換性は実測が必要です
  • 流通価格の差が非常に大きく、関税も自己負担です。Milk-V Jupiter2 のドキュメントは現状スタブで、主に SpacemiT 公式ドキュメントに頼ることになります
