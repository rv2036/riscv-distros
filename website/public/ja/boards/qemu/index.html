仕様
純粋な仮想プラットフォームです。最大 512 個の RV64GC コア、CLINT/PLIC、PCIe ホストブリッジ、8 個の virtio-mmio、NS16550 UART、オプションの AIA/IOMMU を備えます。メモリ、ディスク、ネットワークはすべてコマンドライン引数で仮想化され、実物の GPU/VPU/NPU はありません。

無料のオープンソース（GPLv2）で、各ディストリビューションのリポジトリから入手できます

すべてのボードの共通の出発点です。まず virt でカーネル／rootfs を検証してから実機に移ると、書き込みやトラブルシュートの時間を大幅に節約できます。

使えるディストロ

  • Debian 公式対応 Debian 13 から riscv64 が正式アーキテクチャになり、公式 netinst ISO をそのまま virt に入れられます
  • Ubuntu 公式対応 公式 riscv64 cloud image。EDK2（pflash）か -kernel で起動します
  • Fedora コミュニティ対応 Fedora RISC-V が QEMU のインストール手順とイメージを提供
  • Alpine Linux 公式対応 riscv64 minirootfs だけで virt 用 ISO はなく、カーネル／initramfs を自分で用意します
  • Arch Linux RISC-V 公式対応 archriscv が riscv64 ISO を提供し、QEMU で起動できます
  • openSUSE コミュニティ対応 openSUSE Ports が riscv64 を提供。公式サイトは curl に 403 を返すため、直リンクは未検証です
  • Gentoo 公式対応 stage3 riscv64 ＋ マニュアルで QEMU 上のシステム構築に対応
  • Void Linux 一部のみ riscv64 ポートはありますが、QEMU イメージは自分でビルドします
  • NixOS コミュニティ対応 riscv64 は非公式サポート扱いで、クロスビルドが必要です
  • ALT Linux 公式対応 ALT Ports の riscv64 が QEMU イメージを提供
  • FreeBSD 公式対応 riscv64 が QEMU virt に対応
  • NetBSD 公式対応 riscv64 ポートが QEMU に対応
  • OpenBSD 公式対応 riscv64 が QEMU virt に対応
  • openEuler 公式対応 openEuler RISC-V SIG が QEMU イメージを提供
  • Buildroot 公式対応 qemu_riscv64_virt_defconfig。make 一行でシステムが起動します
  • Yocto / OpenEmbedded 公式対応 qemuriscv64 マシンを公式サポート

つまずきどころ

  • -bios default は OpenSBI しか読み込まず、U-Boot/EDK2 は入っていません。Ubuntu/Fedora の cloud image を起動するには 32MiB の EDK2 ファームウェアを pflash で読み込ませる必要があり、しないと画面が真っ暗になります
  • virt には GPU/VPU/NPU がありません。グラフィックス、動画のハードウェアデコード、AI アクセラレーションの検証には使わないでください
  • シリアルは常に ttyS0 です。-nographic モードを抜けるには Ctrl-A を押してから X を押します
  • Ubuntu 26.04 から RVA23S64 が必須で、古い QEMU は拡張が足りず起動しません。24.04 は今も RVA20 ベースラインです
  • Alpine の riscv64 は minirootfs のみで virt 用 ISO がないため、カーネルと initramfs を自分で用意する必要があります
