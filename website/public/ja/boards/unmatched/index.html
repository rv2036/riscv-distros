歴史的に RISC-V デスクトップの基準でしたが、今は中古で安く拾うか教材用途が似合います。初心者の着手コストは高く（シリアル＋DIP スイッチ＋給電）、最初の 1 枚にはおすすめしません。ほかに openwrt などのコミュニティ派生版もあります（標準のディストリビューション id には入れていません）。

使えるディストロ

  • Ubuntu 公式対応 Canonical 公式の preinstalled イメージ ubuntu-24.04.5-...+unmatched.img.xz。今も 24.04 LTS のサポート範囲内です
  • Buildroot 公式対応 SiFive Freedom U SDK（FUSDK、Buildroot/Yocto の混成）はベンダーのリファレンスシステムで、U-Boot/OpenSBI を含みます
  • Debian コミュニティ対応 Debian 公式の riscv64 インストーラが使え、Debian wiki にこのボード専用ページがあります
  • Fedora コミュニティ対応 Fedora RISC-V は長く Unmatched をリファレンスボードとしてきました
  • openSUSE コミュニティ対応 openSUSE Ports が riscv64 を提供。公式サイトは 403 のため、このボード向けイメージは未検証です
  • FreeBSD コミュニティ対応 FreeBSD/riscv が Unmatched に対応
  • OpenBSD コミュニティ対応 OpenBSD/riscv64 はコミュニティから動作報告があります
  • Gentoo コミュニティ対応 Gentoo RISC-V プロジェクトが U74 プラットフォームをカバー
  • Armbian 一部のみ かつてコミュニティイメージがありましたが、Armbian 公式サイトはこのボードのページを外しました
  • openEuler コミュニティ対応 openEuler RISC-V SIG にこのボード向けイメージがあります
  • openKylin コミュニティ対応 openKylin の RISC-V 版がかつて対応していました
  • deepin コミュニティ対応 deepin の RISC-V 移植版が使えます

つまずきどころ

  • オンボードの表示出力がなく、PCIe グラフィックスカードを挿すかシリアルを使うしかありません。デバッグでは USB-UART（FTDI）を繋がないと OpenSBI/U-Boot のログが見えません
  • 12V/6A のバレル電源が必要で、電力不足だと勝手に再起動したり DDR トレーニングに失敗します
  • 起動媒体は MSEL の DIP スイッチで決まります（SD/SPI Flash）。間違えると起動しません。SPI ファームウェアが壊れた場合は JTAG で復旧する必要があります
  • 公式は生産終了で、Ubuntu 24.04 が最後にサポートされる LTS イメージです。カーネルも古く、新しいディストリビューションはほぼこのボード向けイメージを出さなくなりました
  • PCIe グラフィックスカードは補助電源が必要で、カードによっては U-Boot 段階では出力されず、Linux が起動してから画面が出ます
