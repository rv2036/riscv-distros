「RISC-V ワークステーション／サーバー」として使える唯一のボードで、価格も消費電力も別格です。64 コアの並列ビルドや CI ランナー向きで、入門には向きません。ほかに opencloudos などのコミュニティ派生版もあります（標準のディストリビューション id には入れていません）。

使えるディストロ

  • RevyOS 公式対応 現在の公式主力。RevyOS 20260504 は pioneer/pisces の 2 種類のファームウェアとイメージを提供します
  • Fedora 公式対応 Milk-V 公式ドキュメントは Fedora 38 をインストール例にしており、Fedora RISC-V は SG2042 に対応しています
  • openEuler コミュニティ対応 openEuler RISC-V SIG がサーバー用途で SG2042 に対応
  • openKylin コミュニティ対応 openKylin に RISC-V サーバーイメージあり
  • deepin コミュニティ対応 deepin の RISC-V 移植版
  • Debian 一部のみ debian-ports に riscv64 の基本パッケージはありますが、Pioneer 公式イメージはありません
  • Ubuntu 一部のみ Canonical 公式イメージはなく、rootfs を自分で組む必要があります

つまずきどころ

  • Milk-V ドキュメントの Download ページの Image 欄は空になっています（RevyOS へ移行）。古いページでシステムイメージを探さないでください
  • メモリの選定が重要です。公式の DDR 対応リストに沿って RDIMM/UDIMM を選ばないと DDR トレーニングに失敗して起動しません
  • 標準 ATX 24-pin ＋ CPU 8-pin の給電が必要で、冷却器は必ず付けます（典型消費電力 120W）
  • オンボードの表示出力がなく、PCIe グラフィックスカードが必要です。カードによっては LinuxBoot/U-Boot 段階で出力がありません
  • ファームウェア（LinuxBoot/EDK2 ＋ MCU）の更新は文鎮化のリスクがあり、公式の順序どおりに書き込む必要があります
  • 初期ロットの ASM2824 PCIe スイッチには互換性の問題があります。まず buglist を確認してください
