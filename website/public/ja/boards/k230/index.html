CanMV（MicroPython ファームウェア）が最も出荷量が多く資料も揃った形態です。Linux 側で公式が推すのは Buildroot です。Apache NuttX にも CanMV-K230 のボード対応があります（ディストリビューションではありません）。RuyiSDK サポートマトリクスにも CanMV K230(D) が収録されており、ruyi device provision でイメージを取得できます。

使えるディストロ

  • Buildroot 公式対応 k230_linux_sdk の既定は Buildroot 構成（k230_canmv/k230_evb defconfig）
  • Debian 公式対応 SDK は make debian に対応。公式に「K230 Debian/Ubuntu システムガイド」があります
  • Ubuntu 公式対応 SDK は make ubuntu に対応。ガイドは上記と同じ

つまずきどころ

  • AMP 構成です。既定では LITTLE コアで Linux、ビッグコアで RT-Smart/CanMV を動かします。V 拡張があるのはビッグコアだけなので、ベクトル処理は必ずそちらに載せてください
  • 公式の Linux 本流は Buildroot です。Debian/Ubuntu は自分で make debian / make ubuntu する必要があり、既成の公式デスクトップイメージはありません
  • ファームウェアの一致が必須です。CanMV IDE はファイル名が CanMV-K230_micropython で始まるファームウェアしか認識せず、K230 SDK のイメージを書き込んでも接続できません
  • nncase ツールチェーンはクローズドソースで、ファームウェア版と強く結びついています。初期のビルドドキュメントは中国語しかありません
