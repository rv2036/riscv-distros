エコシステムが最も充実し、ディストリビューションの対応範囲も最も広い JH7110 ボードです。初めての RISC-V ボードとして有力な候補のひとつです。ロットによるファームウェア差に注意してください。ほかに openwrt/dietpi/guix などのコミュニティ派生版もあります（標準のディストリビューション id には入れていません）。

  • Debian 公式対応 StarFive 公式 Debian 202510（Trixie ＋ Wayland デスクトップ）。ほかにメインライン Debian 13 の公式インストーラでも導入できます
  • Ubuntu 公式対応 StarFive 公式 Ubuntu 24.04.3（202510）＋ Canonical jh7110 プリインストールイメージ
  • Fedora コミュニティ対応 Fedora RISC-V の公式テストボードのひとつ
  • openSUSE コミュニティ対応 openSUSE Ports が riscv64 を提供。公式サイトは 403 のため直リンクは未検証です
  • Arch Linux RISC-V コミュニティ対応 archriscv が VF2 の rootfs/ISO を提供
  • Alpine Linux コミュニティ対応 riscv64 minirootfs が使えます
  • Armbian コミュニティ対応 Armbian が VisionFive 2 を公式サポート
  • Gentoo コミュニティ対応 Gentoo wiki に VisionFive 2 専用ページあり
  • NetBSD コミュニティ対応 NetBSD/riscv が JH7110 に対応
  • OpenBSD コミュニティ対応 OpenBSD/riscv64 が JH7110 に対応
  • FreeBSD コミュニティ対応 FreeBSD に JH7110 対応あり
  • NixOS コミュニティ対応 コミュニティ保守。イメージは自分でビルドします
  • Buildroot 公式対応 StarFive SDK は Buildroot ベースで、SPL/U-Boot/FIT を生成します
  • Yocto / OpenEmbedded コミュニティ対応 コミュニティの meta-starfive レイヤ
  • openEuler コミュニティ対応 openEuler RISC-V SIG がイメージを提供
  • deepin コミュニティ対応 deepin の RISC-V 移植版
  • openKylin コミュニティ対応 openKylin に VF2 イメージあり
  • AlmaLinux OS Kitten 10 一部のみ
  • Rocky Linux 10 一部のみ

つまずきどころ

  • U-Boot/SPL は QSPI Flash に入っており、イメージとファームウェアが強く結びついています。202310 以降のイメージは QSPI 内の U-Boot が v3.1.5 以上を要求し、満たさない場合は先に u-boot-spl.bin.normal.out と visionfive2_fw_payload.img を書き込む必要があります
  • 起動順は QSPI → SD/eMMC/NVMe です。DIP スイッチを間違えると別の媒体から起動します
  • v1.2 の旧ボードで Debian 202510 の書き込みに失敗した報告があります。先にファームウェアを更新するか、メインラインの Debian に切り替えてください
  • StarFive 公式の Debian 202510 は USB 起動に対応していません。メインラインの Debian 13 は USB から起動できますが、HDMI/GPU/VPU のドライバがありません
  • VisionFive 2 Lite は標準版と U-Boot/DTB が異なり、イメージを混用できません
  • eMMC/SD 起動には既知の errata があります。NVMe か品質の良い SD カードを優先してください
