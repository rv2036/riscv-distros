K1 は 2024〜2025 年で最も出荷された高性能 RISC-V SBC チップのひとつで、BPI-F3 はエコシステムが最も雑多です（公式 Bianbu に加え、コミュニティの Armbian/Fedora/openSUSE/Arch/Gentoo にもイメージがあります）。RuyiSDK サポートマトリクスにも BPI-F3 が収録されています。

使えるディストロ

  • Bianbu 公式対応 公式の主力は Bianbu（SpacemiT K1 イメージ、v1.0.7 から 16GB 対応）
  • Armbian コミュニティ対応 Armbian の標準サポートで Debian/Ubuntu イメージを提供（SD 起動のみ）
  • Debian コミュニティ対応 Armbian 経由で提供
  • Ubuntu コミュニティ対応 Armbian 経由で提供（Canonical 公式ではありません）
  • Fedora コミュニティ対応 Banana Pi のドキュメントページに掲載されたサードパーティイメージ
  • openSUSE コミュニティ対応 同上、サードパーティイメージ
  • Arch Linux RISC-V コミュニティ対応 同上、サードパーティイメージ
  • Gentoo コミュニティ対応 同上、サードパーティイメージ

つまずきどころ

  • Bianbu イメージは SD カード版（*.img.zip）と eMMC 版（*.zip）に分かれており、間違えると起動できません
  • 公式が推すのは Bianbu だけで、Debian/Ubuntu は主に Armbian のコミュニティイメージに頼ります。しかも Armbian は SD 起動のみ対応です
  • 初期の Bianbu（v1.0.7 未満）は 16GB メモリ版に対応していません
  • HDMI は 1.4/1080p のみで、4K デスクトップには向きません
