つまずきどころ

  • 10GbE は SFP+ の光ポートで、RJ45 ではありません。一般的なスイッチにつなぐには光モジュールを挿すか、唯一の GbE 有線ポートを使うことになります
  • デュアルディスプレイは USB-C の DP Alt Mode と eDP を使うもので、標準の HDMI ポートはありません
  • 出荷時に Bianbu をプリインストール（RuyiSDK の記録は 4.0.1 Desktop）。再インストール時は、汎用の K3 イメージではなく Jupiter2 に対応したイメージかどうかを先に確認してください
  • 公式ページに価格の記載はなく、価格と小売チャネルは未確認です
