Milk-V Megrez と同じチップ（EIC7700X）ですが、P550 は公式 Ubuntu のプリインストールと OTA があり、ソフトウェアの成熟度は Megrez より上です。ほかに Red Hat RHEL 10 の開発者プレビューもサポートされています。

使えるディストロ

  • Ubuntu 公式対応 Ubuntu 24.04 プリインストール。SiFive が 2025.11.00 を公開（カーネル 6.12.33）
  • Fedora 公式対応 Fedora 42 から対応、Fedora 44 からは Omni カーネル
  • Yocto / OpenEmbedded 公式対応 freedom-u-sdk の Yocto BSP（bootchain ファームウェアを含む）
  • Debian コミュニティ対応 SiFive のブログでは Debian 対応を進めているとされていますが、イメージは自分で用意する必要があります

つまずきどころ

  • ファームウェアとイメージの版を合わせる必要があります。bootchain が古いと Fedora は起動すらしません。先に最新ファームウェアを書き込んでください
  • ネイティブの NVMe スロットがなく、PCIe アダプタカードを使うしかありません。オンボードは 2×GbE のみです
  • iGPU は OpenGL ES のみ対応で、OpenGL を使うには MESA_LOADER_DRIVER_OVERRIDE=zink が必要です。外付け GPU を挿すと GRUB メニューが表示されません
  • 中国国内に正規チャネルがなく、Arrow などの海外代理店経由になります。送料と関税は別途です
