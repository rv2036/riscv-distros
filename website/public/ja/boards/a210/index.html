仕様
8 コア 64bit RISC-V：4×C920@1.9GHz ＋ 4×C908@1.9GHz、いずれも RVV（128bit）対応。NPU は 12 TOPS@INT8 で INT4/INT8/FP8/FP16/BF16 と Transformer をサポート。LPDDR4X 最大 16GB、eMMC5.1、H.265 デコード 4K@120fps。ボードは SODIMM コアボード ＋ V1/V2/V3 のオープンソースキャリアで、8GB LPDDR4X ＋ 32GB eMMC（サードパーティのプロジェクトページのデータ）。

つまずきどころ

  • 小売チャネルも公開価格もなく、開発ボードは評価／提携チャネルが中心で、一般の開発者は入手しにくいです
  • A210 と A200 のイメージは互換がありません。公式 Ubuntu は A200 向けだけで、A210 には Debian/Buildroot しかありません
  • GitHub/Gitee に公式 BSP リポジトリはありません（検索しても 0 件）。カーネルとドライバはベンダー SDK のパッケージとして配布され、コミュニティによるサードパーティのディストリビューション対応はほぼありません
  • ベンダー公称値では、単チップで DeepSeek-7B が約 8 tok/s、4 die のカスケードで 25 tok/s。実際の値は自分の環境で測ってください
