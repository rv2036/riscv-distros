  • onnxruntime 一部可 build_riscv64.sh はクロスコンパイル成果物の検証に qemu を使っており、動きますが非常に遅いです。 raw.githubusercontent.com

  • opencv 動作可 エミュレーション環境でも動作しますが、性能的な意味はありません。 github.com
  • ncnn 動作可 CI は riscv64 上で通っています。 github.com

SiFive HiFive Unmatched

SiFive FU740（4x U74, RV64GC、V なし）
  • llama.cpp 公開情報なし Unmatched 専用の公開実測は見つかりませんでした。上流はソースのみで（release に riscv64 バイナリはありません）、U74 に RVV がないためスカラ経路しかなく、かなり遅いと見込まれます。 github.comgithub.com
  • onnxruntime 一部可 上流には MLAS の RVV カーネルと tools/scripts/build_riscv64.sh（SiFive が貢献）がありますが、riscv64 のビルド済みパッケージはなく、自分でクロスコンパイルする必要があります。RVV カーネルは RVV 1.0 向けです。 raw.githubusercontent.comgithub.com
  • pytorch 一部可 PyPI に riscv64 の wheel はありません。RISE が torch 2.13.0 の manylinux_2_39_riscv64 wheel を提供しています（glibc 2.39 以上、Ubuntu 24.04/Bianbu など）。 riseproject.devpypi.riseproject.dev
  • opencv 動作可 上流の 4.x は RISC-V と RVV HAL に対応しています。多くのディストリビューションで導入でき、RVV バックエンドで自前ビルドも可能です。ボードごとの性能検証はしていません。 github.com
  • ncnn 一部可 上流には linux-riscv64 の CI と RVV 実装があります。U74 に RVV はないので、ncnn はスカラでしか動きません。 github.comgithub.com
  • tengine 一部可 tengine-lite は risc-v/lp64dv の RVV 畳み込みカーネルと rv64-c906 ツールチェーンを提供しますが、最適化されるのは一部の演算子だけで、実験的な対応です。 raw.githubusercontent.comgithub.com
