ここで解決するのは「まず動かす」ということです。 RISC-V のソフトウェア対応は各社の wiki、フォーラムの投稿、GitHub の README に散らばっていて、初心者がつまずきやすいのは「イメージを間違える」「U-Boot の版が合わない」「シリアルを繋いでいない」の 3 つです。ここではディストロ、開発ボード、そして両者の対応関係を 1 か所にまとめ、各項目に確認日と出典を付けています。

RISC-V に本当に対応しているディストロ

すべて →

Debian

アップストリーム対応

ベース独立

Debian は今回のリストで唯一、riscv64 を正式なリリースアーキテクチャに含めている独立系ディストリビューションです。派生には Deepin や RevyOS など、Debian をベースにした riscv64 システムもあります（個別の検証はしていません）。

Ubuntu

アップストリーム対応

ベースDebian

Ubuntu はボード対応が最も細かいところです。公式がボード別に preinstalled イメージを出していますが、26.04 からはハードルが RVA23 に上がり、古いボードは 24.04 LTS に留まります。

Fedora

コミュニティ移植

ベース独立

Fedora には公式の RISC-V SIG と継続ビルドがありますが、riscv64 はいまも「not officially supported」と明記され、イメージは alt チャネル配布です。日常利用に問題はありませんが、公式サポートの位置づけは Debian や Ubuntu とは同じではありません。

Fedora-V Force (FVF)

ベンダー派生

ベースFedora

FVF は別チームが Fedora のソースから独自に再ビルドした RISC-V イメージで、Fedora 公式リリースではありません。公式 SIG のイメージより対応ボードが広く、箱から出して動く Fedora 環境が欲しい場合に実用的です。

RevyOS

ベンダー派生

ベースDebian 13 (trixie) の rootfs ＋ XuanTie カスタム 6.6 カーネル（TH1520/SG2042 BSP）。旧版 20240720 は Debian 12 ＋ 5.10 カーネル

TH1520 ボードでの事実上の標準システムです。LicheePi 4A と Milk-V Meles は出荷時／公式チュートリアルで RevyOS を書き込む前提になっています。初心者にはまずこれですが、ミラーサイトの方がドキュメントより新しく、日付はミラーサイトのディレクトリで最新のものを選んでください。

Bianbu

ベンダー派生

ベースUbuntu 24.04 LTS（Bianbu 2.x、K1）／Ubuntu 25.04（Bianbu 3.x、K1）／Ubuntu 26.04（Bianbu 4.x、K3。ベンダーフォーラムの説明で、公式ドキュメントに版ごとの明記はなし）＋ ベンダー BSP カーネル 6.6 LTS / 6.18

K1/K3 ボード（BPI-F3、Milk-V Jupiter、MUSE、Pico ITX）で唯一、公式のデスクトップ環境が用意されているシステムです。GNOME/LXQt が最初から入っており、中国語ドキュメントも揃っていて、初心者に最も向いたベンダー製ディストリビューションです。

openEuler

アップストリーム対応

ベースopenEuler 24.03 LTS（RPM/dnf、自前リポジトリ）＋ RVCK 6.6 カーネル。RISC-V は RVA20 と RVA23 の 2 系統のビルドがあります

サーバー／企業向けの RISC-V 基盤で、RVA23 ＋ Server Platform 仕様の整備が最も進んでいます。個人の開発ボード用途なら、サーバー検証をしたい場合を除いて RevyOS/Bianbu の方が楽です。

openKylin

アップストリーム対応

ベース独立ビルド（deb/APT ＋ 自前リポジトリ、UKUI デスクトップ）。3.0 は Linux 7.0 カーネル、2.0 SP2 が長期安定版

中国製デスクトップ OS の RISC-V ブランチですが、ボード対応がバージョンごとに分断されています（3.0 は K3/V100 のみ）。中国製デスクトップスタックを評価したい人向けで、TH1520/K1 の旧ボードの日常用途には向きません。

deepin

ベンダー派生

ベースDebian 系 ＋ deepin 独自リポジトリ（deepin 25「crimson」）。カーネルはボードごとに 6.6/6.12/6.16、DP1000 はメインラインカーネル

デスクトップが最も美しい中国製ディストリビューションですが、RISC-V ブランチはコミュニティのプレビュー扱いでボード別に tar.xz を配布しています。評価や試用向けで、唯一の日常システムにはしないでください。

QEMU virt 仮想マシン

仮想プラットフォーム

なし（QEMU の汎用仮想プラットフォーム。RV32/RV64 を構成可能、最大 512 コア） · QEMU Project

純粋な仮想プラットフォームです。最大 512 個の RV64GC コア、CLINT/PLIC、PCIe ホストブリッジ、8 個の virtio-mmio、NS16550 UART、オプションの AIA/IOMMU を備えます。メモリ、ディスク、ネットワークはすべてコマンドライン引数で仮想化され、実物の GPU/VPU/NPU はありません。

StarFive VisionFive 2

販売中

StarFive JH7110：4×SiFive U74 @1.5GHz + S7 モニタコア + E24 · StarFive

2/4/8GB LPDDR4、microSD ＋ eMMC（一部の版）、M.2 M-Key NVMe、2×ギガビット Ethernet（v1.3 は PoE 対応）、HDMI 2.0、4×USB、40-pin GPIO。簡素版の VisionFive 2 Lite もあります。

LicheePi 4A（ライチパイ 4A）
