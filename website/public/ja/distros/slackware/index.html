結論から

Slack の古参ユーザーが RISC-V で続けたいなら slarm64 を試す価値はありますが、初心者は手を出さないでください。

ベース
独立（pkgtools ＋ slackpkg、BSD 風の init）
アップストリーム
公式の Slackware 15.0 は x86_64 のみです（slackware.com には別途公式 ARM プロジェクト arm.slackware.com があります）。RISC-V は非公式の slarm64 移植（sndwvs）が 15.0/current に追随してパッケージとボードイメージを提供しています。
バージョン
15.0（公式、x86_64） · slarm64-riscv64-current / slarm64-riscv64-15.0（非公式移植）

つまずきどころ

  • 公式サポートはゼロで、すべて個人が保守する slarm64 に依存します
  • インストーラがありません。パッケージツリーから chroot で手作業インストールするか、ボードイメージを直接書き込みます
  • slackware.com はスクリプトアクセスに 403 を返します（Akamai）。バージョン確認はミラーサイトで行ってください
  • ドキュメントは README とフォーラム投稿だけで、中国語の資料はほぼありません
