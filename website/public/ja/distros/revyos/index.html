結論から

TH1520 ボードでの事実上の標準システムです。LicheePi 4A と Milk-V Meles は出荷時／公式チュートリアルで RevyOS を書き込む前提になっています。初心者にはまずこれですが、ミラーサイトの方がドキュメントより新しく、日付はミラーサイトのディレクトリで最新のものを選んでください。

ベース
Debian 13 (trixie) の rootfs ＋ XuanTie カスタム 6.6 カーネル（TH1520/SG2042 BSP）。旧版 20240720 は Debian 12 ＋ 5.10 カーネル
アップストリーム
下流のカスタムディストリビューションです。PLCT Lab（中国科学院ソフトウェア研究所）が XuanTie（T-Head）エコシステム向けに保守しており、Debian 13（trixie）のパッケージリポジトリと XuanTie 向けカスタムカーネルを組み合わせています。Debian の公式ポートでも、独立したパッケージ体系でもありません。

対応ボード

  • LicheePi 4A（ライチパイ 4A） 公式対応 主力のリファレンスボード。SD/eMMC のデュアルブートで、イメージもドキュメントも最も充実しています
  • Milk-V Meles 公式対応 Milk-V Meles。公式イメージ 20260504 と書き込みチュートリアルがあります
  • Milk-V Pioneer（SG2042 サーバー向け） 公式対応 Milk-V Pioneer（SG2042）。イメージは 20260504
  • SpacemiT K3（Pico-ITX / CoM260） 一部のみ coreboot+OpenSBI+EDK2 ファームウェア（Ruyi Firmware）として提供されており、OS イメージそのものではありません

つまずきどころ

  • バージョン番号は日付（YYYYMMDD）で、セマンティックバージョニングではありません。公式ドキュメントはミラーサイトより遅れがちです（ドキュメントは 20251226、ミラーサイトには 20260504 があります）
  • 20240720 以前からアップグレードする場合は U-Boot の環境変数をリセットする必要があります（env default -a -f; env save; reset）。しないと起動しません
  • LicheePi 4A は一部の SD カードで互換性の問題があります。公式が SD カード互換リストを保守しているので、eMMC を優先するのがおすすめです
  • 20260926/20260924 のディレクトリは coreboot+EDK2 ファームウェア（U-Boot なし）で、システムイメージではありません。既定の 1.84GHz で回すなら放熱対策が必須です
  • GPU/NPU はベンダー BSP のドライバスタックに依存します（revyos-gles-21、NPU のドキュメントも別途あり）。すべてがメインラインに入っているわけではありません
