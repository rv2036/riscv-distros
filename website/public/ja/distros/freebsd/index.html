結論から

「まともな Unix 系 OS ＋ 公式イメージ」が欲しいなら、FreeBSD は RISC-V で最も安定した非 Linux の選択肢です。

独立（BSD、FreeBSD カーネル ＋ pkg）

つまずきどころ

  • Tier 2 なので、セキュリティチームは迅速な修正を保証しておらず、新しいハードウェアへの対応も遅れます
  • 公式の対応プラットフォームは Unmatched/Unleashed/VisionFive 2/QEMU/Spike だけで、中国製の新しいボードはほぼ対象外です
  • riscv64sf（ソフト浮動小数点）は 13.5 以降サポート終了です。古いドキュメントをそのまま当てにしないでください
  • RISC-V では GPU や無線などのドライバ対応が x86/arm64 に遠く及ばず、デスクトップ体験は限られます
