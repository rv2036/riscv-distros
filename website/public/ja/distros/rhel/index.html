結論から

エンタープライズ志向の RISC-V プレビューシステムです。「RHEL のユーザーランドが動くか」を確かめたいときに見るもので、日常使いなら Debian / Ubuntu / RevyOS のほうが手間がかかりません。

vendor
Red Hat
ベース
RHEL 10.2（Fedora / CentOS Stream 10 のコードベース）
アップストリーム
Red Hat 自身が公開している RISC-V 開発者プレビュー（Developer Preview）です。RHEL 10.2 のコードベースを基にしており、一部のプラットフォームにのみビルド済みイメージを提供しています。Red Hat はサポート対象の製品版ではないと明言しています。
バージョン
10.2 Developer Preview Update（2026-10-09；イメージ 2.6 GB、ソース 14.19 GB、ダウンロードには Red Hat アカウントでのログインが必要） · 10.2 Developer Preview · 10.0 Developer Preview（2025-05 に初公開、プラットフォームは P550）
ドキュメント言語
en
確認日
2026-11-02

対応ボード

  • SiFive HiFive Premier P550 公式対応 最初のプラットフォームであり、長期的な主力ターゲットでもあります（SiFive HiFive Premier P550）
  • SpacemiT K3（Pico-ITX / CoM260） 公式対応 10.2 Update で追加：SpacemiT K3 Pico-ITX
  • SpacemiT K3 CoM260 Kit 公式対応 10.2 Update で追加：SpacemiT K3 CoM260
  • Milk-V Titan（UltraRISC DP1000） 公式対応 10.2 Update で追加：UltraRISC UR-DP1000（Milk-V Titan）
  • QEMU virt 仮想マシン 一部のみ 公式に QEMU 専用イメージはなく、イメージはボードごとに提供されます

つまずきどころ

  • Developer Preview であり、本番サポート版ではありません。Red Hat はサポートを提供しないため、業務用途には使わないでください
  • ダウンロードには Red Hat 開発者アカウント（無料）でのログインが必要です。curl で直接取得しようとするとボット対策で 403 になります
  • イメージはプラットフォームごとに提供され、汎用の RISC-V インストールメディアはありません。2.6 GB のものは単一プラットフォーム向けのディスクイメージです
  • 10.2 Update で追加された SpacemiT V100 はサーバー級 CPU で、現時点で対応する完成機の項目がありません。「チップが RHEL に入った」という段階にとどまります
