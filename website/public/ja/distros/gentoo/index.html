結論から

慣れた人には快適、初心者には厳しい。ドキュメントは揃っていますがすべて手作業のインストールで、深くカスタマイズしたい人や組み込み向け rootfs を作りたい人に向いています。

ベース
独立（ソースビルド、OpenRC/systemd 選択可）
アップストリーム
公式アーキテクチャです。ARCH=riscv、~riscv キーワードで、release engineering が rv64gc/rv32gc の stage3（lp64d/lp64/multilib、openrc/systemd、glibc/musl の全組み合わせ）を出しています。ただし stable キーワードを付ける予定は当面ないと公式が明言しています。

つまずきどころ

  • ~riscv（テスト）キーワードしかなく stable はありません。インストール後も不安定なパッケージを受け入れ続けることになります
  • そのまま書き込めるイメージは提供されず、stage3 からの手作業インストールが必須です（公式 TODO にも bootable image が残っています）
  • rv32 は qemu user-mode でまだバグがあり、クロス／エミュレーションのテストでつまずきます
  • multilib と lp64d/lp64 の ABI を混ぜると stage3 を間違えやすいので、まずボードに D 拡張があるか確認してください
