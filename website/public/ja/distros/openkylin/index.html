結論から

中国製デスクトップ OS の RISC-V ブランチですが、ボード対応がバージョンごとに分断されています（3.0 は K3/V100 のみ）。中国製デスクトップスタックを評価したい人向けで、TH1520/K1 の旧ボードの日常用途には向きません。

ベース
独立ビルド（deb/APT ＋ 自前リポジトリ、UKUI デスクトップ）。3.0 は Linux 7.0 カーネル、2.0 SP2 が長期安定版
アップストリーム
独立したディストリビューションです。openKylin コミュニティが自前の deb リポジトリと UKUI デスクトップを持ち、公式には独立したルートコミュニティ OS と位置づけられています（Ubuntu/Debian の直接派生ではありません）。RISC-V は openKylin RISC-V SIG が対応しています。
バージョン
openKylin 3.0（2026-08-31 リリース、ダウンロードページのミラーは 2026-09-18、RISC-V イメージは 2026-08-28 / 2026-10-29） · openKylin 2.0 SP2（2026-08-13 長期安定版、RISC-V イメージは 2025-08-26）

つまずきどころ

  • 3.0 の RISC-V イメージが対象とするのは SpacemiT K3（Server/Embedded）と V100 だけです。LicheePi 4A / Pioneer は 2.0 SP2 のままです
  • RISC-V イメージは汎用 ISO ではなくボードごとのカスタム版なので、自分のボードに合うものを選ぶ必要があります。RVA23 の qemu イメージがあるのは 2.0 SP2 だけです
  • 3.0 の RISC-V イメージはサーバー／組み込み寄り（Server、Embedded）で、デスクトップ体験とは別物です
  • ダウンロードリンクは download-smp.php?id=xxx のリダイレクトで、実体は cdimage.openkylin.top にあります
  • ドキュメントは中国語が中心で、英語のドキュメントサイトはほぼ空です。RISC-V の話題は主に中国語コミュニティ／SIG が対応します
