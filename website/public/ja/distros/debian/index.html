結論から

Debian は今回のリストで唯一、riscv64 を正式なリリースアーキテクチャに含めている独立系ディストリビューションです。派生には Deepin や RevyOS など、Debian をベースにした riscv64 システムもあります（個別の検証はしていません）。

アップストリーム
Debian 13（trixie）以降、riscv64 は公式リリースアーキテクチャになりました。公式発表の原文は「This release for the first time officially supports the riscv64 architecture」。メインアーカイブ deb.debian.org に入っており、ports の追加ツリーではありません（debian.org/ports の一覧でも riscv64 は 13/released と表示されます）。

対応ボード

  • QEMU virt 仮想マシン 公式対応 公式の riscv64 netinst を QEMU virt 上にインストールできます。d-i の主要ターゲットプラットフォームです
  • SiFive HiFive Unmatched コミュニティ対応 汎用 riscv64 イメージ＋ボード側の U-Boot/UEFI で起動します。Debian はボード専用イメージを配布していません
  • StarFive VisionFive 2 コミュニティ対応 同上。JH7110 ボードはベンダー U-Boot で UEFI を提供し、その上に汎用イメージを入れます
  • LicheePi 4A（ライチパイ 4A） 一部のみ TH1520 はベンダー U-Boot／カーネルが必要で、Debian のメインラインにはボード対応がありません
  • Milk-V Meles 一部のみ 同じ TH1520 プラットフォームで、状況は LicheePi 4A と同様です
  • SpacemiT K3（Pico-ITX / CoM260） 一部のみ SpacemiT K3 はベンダー BSP が必要です。Debian メインラインでの対応状況は未確認です
  • 知合計算 A210（XuanTie MelonPi 開発ボード） 一部のみ 知合 A210 はベンダーのファームウェア／カーネルが必要で、Debian の公式サポートはありません
  • Canaan K230（Kendryte K230 / CanMV-K230） 一部のみ Canaan K230 は MCU 系の SoC で、メインラインの対応は限定的です
  • Milk-V Megrez（ESWIN EIC7700X） コミュニティ対応 EIC7700 ボードは汎用 UEFI イメージで動く可能性がありますが、Debian のドキュメントでは確認できていません
  • Milk-V Titan（UltraRISC DP1000） コミュニティ対応 DP1000 も同様で、Debian のドキュメントでは確認できていません
  • Milk-V Pioneer（SG2042 サーバー向け） コミュニティ対応 SG2042 は汎用イメージで動く可能性がありますが、Debian のドキュメントでは確認できていません
  • Orange Pi RV2（Ky X1） コミュニティ対応 SpacemiT K1 ボード。汎用イメージ＋ボード側 U-Boot で動きます
  • Banana Pi BPI-F3（SpacemiT K1） コミュニティ対応 SpacemiT K1 ボード。汎用イメージ＋ボード側 U-Boot で動きます

つまずきどころ

  • 配布されるのは汎用の riscv64 イメージ（netinst/ISO）だけで、ボード専用イメージはありません。起動できるかどうかはボード側の U-Boot/UEFI ファームウェア次第です
  • 公式インストールマニュアル自身が「This installation guide has not been fully updated and fact checked for riscv64」と明記しており、一部の章は古い可能性があります
  • netinst でのインストールはネットワーク接続が必須で、パッケージを取得しながら進みます
