結論から

Arch の「公式」はこの移植プロジェクト自身の tested リストという意味でしかなく、Arch 本体の公式サポートではありません。ページにはコミュニティ port であることを明記します。

ベース
Arch Linux
アップストリーム
Arch Linux RISC-V はコミュニティによる移植です（archriscv.felixc.at、Felix Yan らが保守）。Arch のソースパッケージにパッチを当ててビルドしており、Arch 公式リポジトリには入っていません。公式サイトでも長期目標として「riscv64 can be added to Arch Linux itself as an alternative architecture」と書かれています。

つまずきどころ

  • ピュアな上流ではありません。すべてのパッケージは Arch のソースパッケージにパッチを当ててビルドしており、パッチは archriscv-packages リポジトリで管理されています
  • LicheePi 4A（TH1520）と Milk-V Pioneer（SG2042）は [unsupported] リポジトリの実験的カーネルしかありません
  • AX45MP 系のボードはほぼそのままでは使えません。公式の原文は「Other boards, except those with AX45MP, may work with a BSP or custom kernel」
  • rootfs の既定アカウントは root/archriscv です。インストール後は必ず変更してください
  • 今も alt アーキテクチャ扱いで、Arch 公式リポジトリには入っていません
