結論から

産業／量産向けです。個人で試すなら、まず Armbian か Buildroot から始めるのがおすすめです。

ベース
自前ビルド（BitBake ＋ oe-core ＋ meta-riscv）
アップストリーム
ビルドシステムです。oe-core に qemuriscv32/qemuriscv64 マシンと riscv64 tune が入っており、個々のボードは公式の RISC-V レイヤ meta-riscv（riscv/ オーガナイゼーション）が machine 設定として提供します。
バージョン
6.1 Blacksail（現行シリーズ） · 6.0 Wrynose（LTS、2030-04 までサポート）

en
派生ディストロ
SpacemiT / StarFive / T-Head などのベンダー Yocto BSP は、いずれも oe-core ＋ meta-riscv の形をとっています

対応ボード

  • QEMU virt 仮想マシン 公式対応 oe-core 標準の qemuriscv64/qemuriscv32
  • Banana Pi BPI-F3（SpacemiT K1） コミュニティ対応 meta-riscv の bananapi-f3（メインラインカーネル/U-Boot、ベンダー FSBL は依然必要）
  • SpacemiT K3（Pico-ITX / CoM260） コミュニティ対応 meta-riscv の k3-com260 / k3-pico-itx（-mainline 変体あり）
  • LicheePi 4A（ライチパイ 4A） コミュニティ対応 meta-riscv の licheepi-4a
  • StarFive VisionFive 2 コミュニティ対応 meta-riscv の visionfive2
  • Orange Pi RV2（Ky X1） コミュニティ対応 meta-riscv の orangepi-rv2（メインラインカーネル/U-Boot ＋ ベンダー FSBL）
  • 知合計算 A210（XuanTie MelonPi 開発ボード） コミュニティ対応 meta-riscv の zhihe-a210：OSU-OSL のメインラインカーネル、TFTP netboot のみ、bootloader recipe なし

つまずきどころ

  • 学習曲線が最も急です。BitBake の文法に加えて、レイヤのバージョンを厳密に合わせる必要があります（meta-riscv は master に追随）
  • 初回ビルドで数十 GB をダウンロードし、数時間かかります
  • 既成のイメージは提供されず、wic/sdimg を自分で生成します
  • ベンダーの FSBL/TEE は別途入手が必要で、純粋なオープンソースの手順だけでは通りません
