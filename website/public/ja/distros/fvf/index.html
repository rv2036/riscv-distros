結論から

FVF は別チームが Fedora のソースから独自に再ビルドした RISC-V イメージで、Fedora 公式リリースではありません。公式 SIG のイメージより対応ボードが広く、箱から出して動く Fedora 環境が欲しい場合に実用的です。

ベース
Fedora
アップストリーム
Fedora-V Force（多啦V盟）は独立したチーム／コミュニティのプロジェクトで、Fedora 36 から rawhide までの riscv64 ビルドを自前でコンパイルしてボードに合わせています。公式サイトの説明は「independently compiling releases from Fedora 36 to rawhide」で、Fedora の公式リリースプロセスとは関係がありません。
バージョン
Fedora 36 → rawhide（独自ビルド、複数の Fedora バージョンをカバー）

つまずきどころ

  • イメージはコミュニティによる独立ビルドで、Fedora 公式の署名／リリース手順を通りません。バージョンも上流の Fedora と完全には同期していません
  • ミラーサイトは JS のシングルページアプリで、スクリプトではボード一覧を取得できません。ボードの選択はページ上で手作業になります
