結論から

K1/K3 ボード（BPI-F3、Milk-V Jupiter、MUSE、Pico ITX）で唯一、公式のデスクトップ環境が用意されているシステムです。GNOME/LXQt が最初から入っており、中国語ドキュメントも揃っていて、初心者に最も向いたベンダー製ディストリビューションです。

ベース
Ubuntu 24.04 LTS（Bianbu 2.x、K1）／Ubuntu 25.04（Bianbu 3.x、K1）／Ubuntu 26.04（Bianbu 4.x、K3。ベンダーフォーラムの説明で、公式ドキュメントに版ごとの明記はなし）＋ ベンダー BSP カーネル 6.6 LTS / 6.18
アップストリーム
下流のカスタムディストリビューションです。SpacemiT の公式 OS で、「Ubuntu コミュニティのソースからビルド」と明記されており、APT ＋ deb パッケージ形式です。K1 は Ubuntu 24.04（2.x）／25.04（3.x）、K3 は Ubuntu 26.04（4.x）に対応します。

つまずきどころ

  • K1 と K3 ではバージョン系列がまったく別です。K1 は 2.x（Ubuntu 24.04）を長期保守、3.x は非 LTS の Ubuntu 25.04 ベース。K3 は 4.x（Ubuntu 26.04）のみです
  • RVA22 の K1 では、RVA23 向けにビルドされた Ubuntu 26.04／Bianbu 4.x は動きません。K3 は RVA22 のコードを下位互換で動かせます
  • イメージは .zip（中に .img）なので、展開してから dd か Etcher で書き込みます。ボードによっては UEFI 版もあるので間違えないでください
  • カーネルはメインラインではなくベンダー BSP（6.6 LTS / 6.18）です。差し替えるなら公式の kernel リポジトリからビルドします
  • MUSE シリーズ、BPI-F3、Milk-V Jupiter はボードごとにイメージが分かれており、間違えると起動しません。イメージサイズは約 2〜2.6GB です
