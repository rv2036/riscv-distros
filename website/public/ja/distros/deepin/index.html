結論から

デスクトップが最も美しい中国製ディストリビューションですが、RISC-V ブランチはコミュニティのプレビュー扱いでボード別に tar.xz を配布しています。評価や試用向けで、唯一の日常システムにはしないでください。

ベース
Debian 系 ＋ deepin 独自リポジトリ（deepin 25「crimson」）。カーネルはボードごとに 6.6/6.12/6.16、DP1000 はメインラインカーネル
アップストリーム
下流のカスタムディストリビューションです。deepin コミュニティ版は Debian のパッケージを引き継ぎつつ、独自リポジトリと玲珑（linglong）パッケージ体系を重ねています。RISC-V は deepin-ports SIG が保守し、公式には「技術プレビュー」と明記されています。

つまずきどころ

  • RISC-V は今も技術プレビュー（公式が明記）で、安定性と完成度は不十分です
  • ボード別イメージは ISO ではなく tar.xz なので、手動で展開して書き込みます。汎用 ISO 25.2.0 は UEFI 起動が必要です
  • インストーラ付きの liveimage-desktop は既定ユーザーを作りません。root の既定パスワードは deepin です
  • immutable（読み取り専用ルート）の変体があり、システムの改造方法が通常と異なります
  • deepin の RISC-V はコミュニティレベルのサポートのみで、商用サポートは統信 UOS になります
