結論から

サーバー／企業向けの RISC-V 基盤で、RVA23 ＋ Server Platform 仕様の整備が最も進んでいます。個人の開発ボード用途なら、サーバー検証をしたい場合を除いて RevyOS/Bianbu の方が楽です。

ベース
openEuler 24.03 LTS（RPM/dnf、自前リポジトリ）＋ RVCK 6.6 カーネル。RISC-V は RVA20 と RVA23 の 2 系統のビルドがあります
アップストリーム
独立したディストリビューション（それ自体が上流）です。openEuler コミュニティ（OpenAtom Foundation）が公式にマルチアーキテクチャを同源ビルドしており、RISC-V は OERV SIG が移植・保守しています。Debian/Ubuntu のカスタム版ではありません。

つまずきどころ

  • RVA20 と RVA23 のイメージは別々に公開されています。24.03 LTS SP4 の RISC-V は RVA23 の ISO だけで、rva20 ディレクトリは存在しません
  • UEFI/EDK2 ファームウェアとボード対応の DTB が必要で、古い U-Boot のボードでは起動しないことがあります
  • ドキュメントはバージョンごとにパスが分かれ、RISC-V のインストールページは 24.03_LTS の下にしかありません。SP3/SP4 のパスは 404 になります
  • サーバー指向です。既定は最小インストールで、デスクトップやマルチメディアの対応はベンダーのデスクトップ版より弱くなります
  • everything ISO は 20GB 級です。通常のユーザーは dvd/netinst で十分です
