結論から

中国製 RISC-V ボードが「買ってすぐ使える」ようになった最大の功労者です。K3 や BPI-F3 のような新しいボードは、まずこれを確認してください。

ベース
Debian/Ubuntu（Armbian build framework）
アップストリーム
公式のビルドフレームワーク（armbian/build）が riscv64 イメージを直接生成します。ボードは Platinum/Standard/Community の三段階に分類され、RISC-V ボードには公式サイトに専用のダウンロードページとイメージ一覧があります。

対応ボード

  • SpacemiT K3（Pico-ITX / CoM260） 公式対応 MusePi Pro は Platinum（カーネル 6.18.55 current / 6.6.100 legacy）。K3 Pico-ITX も Platinum です
  • Banana Pi BPI-F3（SpacemiT K1） 公式対応 Standard 級、カーネル 6.18.45。Bianbu の変体もあります
  • Orange Pi RV2（Ky X1） コミュニティ対応 Community 級、Debian 13 minimal（6.18.58）のみ
  • StarFive VisionFive 2 コミュニティ対応 Community 級、ベンダーカーネル 6.6.20、Ubuntu/Debian の 3 イメージ

つまずきどころ

  • 多くのボードは今もベンダーカーネル（6.6.x Bianbu）に縛られており、メインライン化の度合いはまちまちです
  • Community 級のボードは CLI イメージが 1 つだけで、デスクトップや更新はコミュニティ任せです
  • Meles / Pioneer / Megrez / K230 などのボードはありません
  • 同じバージョン番号でもボードによってカーネル版が違います。ドキュメントに固定値で書かないでください
