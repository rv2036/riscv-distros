結論から

Ubuntu はボード対応が最も細かいところです。公式がボード別に preinstalled イメージを出していますが、26.04 からはハードルが RVA23 に上がり、古いボードは 24.04 LTS に留まります。

ベース
Debian
アップストリーム
Canonical が riscv64 イメージを公式にビルド・ホストしています（「built and hosted by Canonical」）。riscv64 は Ubuntu の公式サポートアーキテクチャです。26.04 LTS から ISA のベースラインが RVA23S64 に上がりました。

対応ボード

  • QEMU virt 仮想マシン 公式対応 26.10 / 26.04.1 LTS は Desktop、Server の live installer と preinstalled イメージを提供しています。公式ページに QEMU のインストール手順があります
  • SiFive HiFive Unmatched 公式対応 24.04.5 LTS は ubuntu-24.04.5-preinstalled-server-riscv64+unmatched.img.xz を提供しています
  • StarFive VisionFive 2 公式対応 jh7110 イメージ（24.04.5 LTS +jh7110、VisionFive 2 / VisionFive 2 Lite をカバー）
  • LicheePi 4A（ライチパイ 4A） 一部のみ 公式のボード一覧に LicheePi 4A はありません（Sipeed LicheeRV Dock のみ）。自前ビルドかコミュニティイメージが必要です
  • Milk-V Meles 一部のみ 公式のボード一覧に Milk-V Meles はありません
  • SpacemiT K3（Pico-ITX / CoM260） 公式対応 SpacemiT K3 プラットフォーム（CoM260、picoITX、DeepComputing FML13V05）は 26.10 から対応しています
  • 知合計算 A210（XuanTie MelonPi 開発ボード） 一部のみ 公式のボード一覧に知合 A210 はありません
  • Canaan K230（Kendryte K230 / CanMV-K230） 一部のみ 公式のボード一覧に Canaan K230 はありません
  • Milk-V Megrez（ESWIN EIC7700X） 一部のみ 公式のボード一覧に Milk-V Megrez はありません
  • Milk-V Titan（UltraRISC DP1000） 一部のみ 公式のボード一覧に Milk-V Titan はありません
  • Milk-V Pioneer（SG2042 サーバー向け） 一部のみ 公式のボード一覧に Milk-V Pioneer はありません
  • Orange Pi RV2（Ky X1） 一部のみ 公式のボード一覧にあるのは Milk-V Mars（同じ K1）だけで、Orange Pi RV2 はありません
  • Banana Pi BPI-F3（SpacemiT K1） 一部のみ 公式のボード一覧に Banana Pi BPI-F3 はありません
  • Milk-V Jupiter2 一部のみ

つまずきどころ

  • 26.04 LTS から RVA23S64 が必須です。RVA23 非対応のハードウェア（VisionFive 2/JH7110、SiFive Unmatched など）は 24.04.5 LTS しか使えません。公式の原文は「Hardware that is not RVA23-ready continues to be supported by our 24.04.5 LTS release」
  • 一部のボード向けイメージは headless のみ（GPU なし、WiFi なし）です。公式ページでも DeepComputing FML13V01 の項目に明記されています
  • ボード向けイメージは +<board> のサフィックスで区別されます（+unmatched/+jh7110/+icicle/+nezha/+licheerv/+pic64gx）。間違ったイメージを書き込むと起動しません
